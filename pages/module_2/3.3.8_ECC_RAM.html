3.3.8 ECC RAM

Overview

ECC (Error Correction Code) RAM is used in workstations and servers where reliability is critical.

What ECC RAM Does

Error Type What Happens
Single-bit error Detects and corrects automatically
Multi-bit error Detects only, generates an error message, and halts the system

How It Works

  • Adds an 8-bit checksum to each data transfer
  • Requires a 72-bit data bus instead of the standard 64-bit data bus
  • The memory controller calculates and compares the checksum to detect errors

DIMM Types

Type Description Common Use
RDIMM (Registered) Includes a register to reduce electrical load on the memory controller, with a slight performance penalty Most ECC RAM, servers, and workstations
UDIMM (Unbuffered) Standard consumer DIMMs, typically no ECC Consumer PCs

Compatibility Rules

  • Both the motherboard and CPU must support ECC for it to work
  • Most motherboards support either UDIMMs or RDIMMs, not both
  • Mixing UDIMMs and RDIMMs causes the system not to boot
  • Mixing ECC and non-ECC UDIMMs causes system instability or failure to boot

DDR5 Note

Note: DDR5 has a built-in internal error-checking mechanism, but this is not the same as ECC. DDR5 still comes in ECC and non-ECC versions, and only the ECC version provides full error correction through the memory controller.
