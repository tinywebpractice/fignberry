3.4.1 CPU Architecture

Overview

The CPU executes program instruction code loaded into system memory using a 4-step cycle.

The Instruction Cycle

Step Name What Happens
1 Fetch Control unit retrieves the next instruction from system memory
2 Decode Control unit decodes it, then executes it directly or passes it to the ALU/FPU
3 Execute ALU or FPU carries out the instruction
4 Write-back Result is written to a register, cache, or system memory

Key Components Involved

Component Description
ALU (Arithmetic Logic Unit) Handles logical and arithmetic instructions
FPU (Floating-Point Unit) Handles floating-point math instructions
Register Temporary storage inside the CPU; runs at full CPU clock speed
Cache Small, fast memory block near the CPU; stores frequently used data and instructions to avoid slower RAM lookups

Cache Levels

Cache levels include L1, L2, and L3. Each level is progressively larger but slightly slower, while still being much faster than system RAM.

Why This Matters

  • Registers and cache reduce how often the CPU has to reach out to slower system memory
  • The control unit manages the fetch and decode steps
  • The ALU and FPU handle the actual execute step
