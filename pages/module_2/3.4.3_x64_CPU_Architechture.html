3.4.3 x64 CPU Architecture

x86 vs. x64

Architecture Bit Width Max RAM Notes
x86 32-bit 4 GB Standard through the 1990s; cannot run 64-bit software.
x64 (x86-64) 64-bit More than 4 GB 64-bit extension of x86. Developed by AMD (AMD64), adopted by Intel (Intel 64 / EM64T). Can run both 32-bit and 64-bit software.

Software and Driver Compatibility

  • Software (OS, drivers, applications) must be compiled specifically for x64 to take advantage of the architecture.
  • Device drivers must match the OS architecture: a 64-bit OS requires 64-bit drivers.
  • Windows 11 and most modern Linux distributions require 64-bit versions. 32-bit OS versions are becoming obsolete.
  • macOS Catalina dropped 32-bit application support entirely.

x64 Benefits

  • Performance: handles wider data paths and larger instruction sets.
  • Memory: supports more than 4 GB of RAM.
  • Virtualization: supports hardware-based virtualization via Intel VT-x and AMD-V, improving VM performance and efficiency.
  • Security: supports Data Execution Prevention (DEP), which prevents code from executing in non-executable memory regions.

Key Terms

x86
The 32-bit CPU instruction set architecture, standard through the 1990s. Cannot run 64-bit software.
x64 (x86-64)
The 64-bit extension of x86, developed by AMD as AMD64 and adopted by Intel as Intel 64/EM64T. Supports more than 4 GB RAM and can run both 32-bit and 64-bit software.
Device driver
Code that provides OS support for a specific hardware component. Must match the OS architecture (64-bit OS requires 64-bit drivers).
Intel VT-x / AMD-V
Hardware-based virtualization technologies supported by x64 CPUs that improve the performance and efficiency of virtual machines.
DEP (Data Execution Prevention)
A security feature on 64-bit systems that prevents code from executing in memory regions marked as non-executable, helping to block certain types of malware.
