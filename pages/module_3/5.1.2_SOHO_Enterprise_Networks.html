5.1.2 SOHO and Enterprise Networks

SOHO Networks

A small office/home office (SOHO) LAN uses a single networking appliance - commonly called a SOHO router, Internet router, or broadband router - to provide both LAN and Internet connectivity for a small number of users.

A typical SOHO router combines three functions in one device:

  • Switch ports - connect wired client devices on a local private network.
  • Wireless access point (AP) - extends the local network to wireless devices.
  • Digital modem - connects the local network to the ISP and public Internet.

Enterprise Networks

Enterprise networks serve larger businesses and institutions. They perform the same basic functions as a SOHO router, but each function is handled by a dedicated device to support more clients with greater reliability.

Enterprise network layout by zone:

  • Work areas - client computers and printers connect via cabling through wall conduit to wall ports, then to a patch panel, then to workgroup switches.
  • Wireless work areas - laptops and mobile devices connect via APs, which also link to workgroup switches.
  • Server room - network servers and printers are separated from client areas and connected through their own switch to core/distribution switches.
  • Core/distribution layer - switches aggregate traffic from all workgroup switches and route it to routers, firewalls, DMZ, and remote access/VPN.
  • DMZ / screened subnet - a protected border zone between the private LAN and public Internet; traffic is strictly filtered and monitored. Hosts internet-facing services.
  • Network border services - provide Internet access, email, remote access, WAN/VPN links, and web services for external clients.

SOHO vs. Enterprise Comparison

Feature SOHO Enterprise
Scale Small number of users Large number of users
Routing Built into SOHO router Dedicated router(s)
Switching Built into SOHO router Workgroup + core/distribution switches
Wireless Built into SOHO router Dedicated APs
Firewall Basic, built-in Dedicated firewall appliance
Servers Optional, may be absent Dedicated server room
Internet border Simple NAT/modem DMZ / screened subnet

Key Terms

SOHO router
An all-in-one networking appliance combining a switch, wireless AP, and modem/router for small networks. Also called an Internet router or broadband router.
Workgroup switch
A switch that connects client devices in a work area to the core/distribution layer of an enterprise network.
Core/distribution switch
A high-capacity switch that aggregates traffic from workgroup switches and connects to routers, firewalls, and other network border devices.
DMZ (Demilitarized Zone)
A screened subnet that sits between the private LAN and the public Internet. Hosts internet-facing services; traffic is strictly filtered and monitored.
VPN (Virtual Private Network)
An encrypted tunnel used to provide secure remote access or connect WAN branch offices over the public Internet.
Access point (AP)
A dedicated wireless networking device that connects wireless clients to the wired network infrastructure.
