5.2.11 Lesson Review - Q&A

Q1. What is the purpose of a patch cord?

  • It routes network traffic between different floors in a building.
  • ✓ It links a port on the patch panel to a port on the Ethernet switch.
  • It connects the computer directly to the Ethernet switch.
  • It terminates cables into insulation displacement connectors (IDCs).

A patch cord is a short cable connecting a patch panel port to a switch port. It does not route traffic — that's a router's job.

Q2. Which IEEE PoE standard is most suitable for devices requiring around 25 W of power, such as advanced wireless access points and pan-tilt-zoom security cameras?

  • ✓ 802.3at (PoE+)
  • 802.3bt Type 4
  • 802.3af
  • 802.3bt Type 3

802.3at (~30W) covers the 25W requirement. 802.3af (~13W) is too low; bt types are overkill.

Q3. Why is it important to label ports on a patch panel?

  • ✓ To reduce errors during troubleshooting
  • To increase network speed
  • To provide redundancy in case of failure
  • To prevent data collisions

Labels are purely organizational — they help identify which port connects to which location/device during troubleshooting.

Q4. Which of the following BEST describes how a switch functions?

  • It connects multiple cable segments for different architectures and translates data packets to forward them to the appropriate host.
  • ✓ It connects multiple cable segments or hosts and forwards data packets to the appropriate host.
  • It connects multiple cable segments or devices and broadcasts data packets to all of its connected hosts.
  • It connects multiple cable segments for different architectures and translates data packets to broadcast them to all connected hosts.

A switch uses MAC address tables to forward frames only to the intended recipient. Broadcasting to all hosts describes a hub.

Q5. What component allows PoE functionality when a switch does not support PoE?

  • Power adapter
  • Ethernet splitter
  • Endspan switch
  • ✓ PoE injector

A PoE injector sits inline between a non-PoE switch and the end device, adding power to the Ethernet cable. An endspan switch is a PoE-capable switch itself. A splitter separates power from data at the receiving end.

Q6. What is the main role of a rack-mounted switch?

  • ✓ To provide active data connections between devices
  • To terminate and label network cables
  • To amplify network signals
  • To split network connections into multiple signals

A rack-mounted switch is active networking equipment that forwards traffic between devices. Terminating/labeling cables is the patch panel's job.

Q7. Which of the following PoE standards is designed for use with biometric sensors?

  • 802.3af
  • Higher-power PoE
  • Super PoE
  • ✓ PoE+ (802.3at)

PoE+ (~30W, Mode A or B) is designed for biometric sensors and tablets. 802.3af (~13W) is for basic devices like VoIP phones. "Super PoE" is not a real standard. Higher-power PoE (~100W) is for laptops and TVs.

Q8. What is the purpose of uplink ports on a managed switch?

  • To replace unmanaged switches in small networks
  • To support wireless connections
  • To provide power to connected devices
  • ✓ To connect to other switches, expanding the network

Uplink ports are higher-speed ports used to connect switches together or to a router/core switch, allowing network expansion.

Q9. What is the purpose of bonding multiple Ethernet NIC ports?

  • To improve signal quality for distant connections
  • To connect both copper and fiber connections simultaneously
  • ✓ To create a higher-speed link by combining the speeds of multiple ports
  • To allow one port to function as a backup in case of a failure

NIC bonding (link aggregation/teaming) combines ports to increase throughput. The last option describes failover, which is a separate concept.

Q10. What function does an Ethernet switch perform when it receives a data frame?

  • It discards the frame if the destination is not in its MAC address table.
  • It stores the frame until the destination device requests it.
  • ✓ It decodes the frame and forwards it to the appropriate port based on the destination MAC address.
  • It broadcasts the frame to all ports.

A switch reads the destination MAC address and forwards the frame only to the correct port. Broadcasting to all ports is hub behavior. Unknown destinations are flooded, not discarded.

Q11. Which of the following network components is responsible for converting digital data into a signal that can be transmitted?

  • Transmission medium
  • ✓ Network interface
  • Protocol
  • Switch

The NIC converts digital data into electrical, optical, or radio signals. The transmission medium is just the physical path; a protocol is a set of rules, not hardware.

Q12. How is a MAC address typically represented?

  • As 48 hexadecimal digits in groups of six
  • As 16 decimal digits separated by dots
  • ✓ As 12 hexadecimal digits, each representing half a byte
  • As a series of binary digits only recognizable by the network hardware

A MAC address is 48 bits = 12 hex digits (each hex digit = 4 bits = half a byte), written as 6 colon- or hyphen-separated pairs (e.g. 00:1A:2B:3C:4D:5E).

Q13. You need to connect wires from office wall plates to the network rack. Which component should you use?

  • Ethernet router
  • UPS
  • ✓ Ethernet patch panel
  • Ethernet switch

The patch panel is the termination point for structured cabling. Wall plate runs connect to the back via IDCs; patch cords then link the panel to the switch.

Q14. Which of the following describes a benefit of using a patch panel?

  • It amplifies signals over long distances.
  • It reduces the need for network cables.
  • ✓ It prevents wear and tear on switch ports.
  • It eliminates the need for switches.

Plugging/unplugging happens at the patch panel, protecting the more expensive and harder-to-replace switch ports from repeated physical stress.

Q15. What is the function of a MAC address in Ethernet networking?

  • ✓ To specify the manufacturer and unique identifier for each network interface
  • To provide a numerical address that can be used across multiple networks
  • To identify the IP address of a computer on the network
  • To encrypt data sent over the network

A MAC address contains the OUI (manufacturer, first 6 digits) and a unique device identifier (last 6 digits). MAC addresses operate at Layer 2 (local network only) — IP addresses handle cross-network routing.
