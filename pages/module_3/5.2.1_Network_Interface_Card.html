5.1.3 Datacenters

Server vs. Client Roles

  • Server - dedicated to running network applications and hosting shared resources.
  • Client - used by end users to access those applications and resources.

On an enterprise LAN, servers are hosted in a dedicated server room. A company with high server requirements may instead operate a full datacenter.

Datacenters

A datacenter is an entire site dedicated to provisioning server resources, typically housed in a purpose-built facility. It provides a highly available environment for running critical applications through dedicated infrastructure in four areas:

  • Networking - dedicated high-capacity network infrastructure.
  • Power - redundant power systems to ensure uptime.
  • Climate control - cooling systems to manage heat generated by servers.
  • Physical access control - security measures to restrict unauthorized entry.

Key Terms

Server
A computer dedicated to running network applications and hosting shared resources for client devices.
Client
A computer used by end users to access applications and resources provided by servers.
Datacenter
A purpose-built facility dedicated to provisioning server resources, with dedicated networking, power, climate control, and physical access control for high availability.
