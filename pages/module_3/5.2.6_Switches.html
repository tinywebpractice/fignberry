5.2.6 Switches

How a Switch Works

An Ethernet switch connects multiple devices on a network, provisioning one port per device. When a device connects, the switch records its MAC address and the port it is on in a MAC address table. When a frame arrives, the switch decodes it, reads the destination MAC address, and forwards the frame only to the matching port via the high-speed backplane - creating a temporary virtual circuit.

Frame forwarding process:

  • Host sends a frame to the switch.
  • Switch buffers the frame and reads the destination MAC address.
  • Switch looks up the destination MAC in its MAC address table.
  • Switch forwards the frame out only the matching port.
  • All other devices are unaware of the exchange and remain free to transmit/receive simultaneously.

MAC Address Table

The switch builds its MAC address table dynamically: when a frame arrives, the switch reads the source MAC address and records it against the incoming port. If the destination MAC address is not yet in the table, the switch floods the frame out all ports until it learns which port the destination is on.

Collision Domains and Full Duplex

Each switch port is a separate collision domain, eliminating the negative effects of collisions. Every connected device gets a full duplex connection - it can send and receive simultaneously at the full speed supported by its NIC and cabling.

Key Terms

Ethernet switch
A network device that connects multiple devices and forwards frames only to the port matching the destination MAC address, using a MAC address table.
MAC address table
A table maintained by the switch that maps each known MAC address to the port it was learned on.
Flooding
When a switch receives a frame with an unknown destination MAC address, it sends the frame out all ports except the one it arrived on, until it learns the correct port.
Collision domain
A network segment where two devices transmitting simultaneously can cause a collision. Each switch port is its own collision domain, preventing collisions between ports.
Full duplex
A connection mode where a device can send and receive data simultaneously at full speed, made possible by switches eliminating shared collision domains.
Backplane
The high-speed internal bus of a switch used to transfer frames between ports.
