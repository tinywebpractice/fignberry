5.4.1 Access Points

Wireless LANs and Infrastructure Mode

Wireless LANs (WLANs) use radio waves as transmission media, with antennas tuned to specific frequencies. Most WLANs are based on IEEE 802.11 standards (Wi-Fi). The most common configuration is infrastructure mode, where each client device (station) connects to the network through an access point (AP).

In 802.11 documentation, this setup is called a Basic Service Set (BSS). The MAC address of the AP's radio is used as the Basic Service Set ID (BSSID).

Access Point Role

  • An AP can create a wireless-only network, or act as a bridge between wireless stations and a wired network.
  • The wired network the AP connects to is called the distribution system (DS).
  • The AP connects to the wired network the same way a host computer does: via a wall port and cabling to an Ethernet switch.
  • Enterprise APs are typically powered via PoE over the data cabling, eliminating the need for a separate power supply.

Key Terms

Access point (AP)
A wireless networking device that allows client stations to connect to a network via radio signals. Can operate as a wireless-only hub or as a bridge to a wired distribution system.
Infrastructure mode
A Wi-Fi network configuration where client devices connect to the network through a central access point rather than directly to each other.
BSS (Basic Service Set)
The 802.11 term for a Wi-Fi network in infrastructure mode, consisting of an AP and the stations associated with it.
BSSID (Basic Service Set ID)
The MAC address of the AP's radio interface, used to uniquely identify a BSS.
Distribution system (DS)
The wired network that an access point bridges wireless stations to.
Station
Any client device that connects to a Wi-Fi network through an access point.
