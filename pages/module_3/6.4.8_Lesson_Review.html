6.4.8 Lesson Review - Q&A

Q1. Legitimate emails from a domain are being marked as spam because recipient servers cannot verify the sender's authenticity. What is the most likely cause?

  • The domain's A record is missing
  • The domain's MX record is pointing to the wrong mail server
  • The domain's DNS server is down
  • The domain does not have an SPF record configured

SPF (Sender Policy Framework) is a DNS record listing which mail servers are authorized to send email for a domain. Without it, recipient servers can't verify authenticity and flag mail as spam. The A record maps hostnames to IPs. A wrong MX record affects incoming mail, not outbound authentication. A downed DNS server would cause complete delivery failure, not spam classification.

Q2. What is the primary purpose of a Virtual LAN (VLAN)?

  • To replace the need for a Domain Name System (DNS)
  • To assign static IP addresses to devices on a network
  • To logically segment a network into smaller, isolated broadcast domains
  • To physically separate devices on a network

VLANs divide a physical network into separate logical networks at the switch level, containing broadcast traffic and improving security without requiring separate hardware. VLANs have nothing to do with DNS or IP assignment. Physical separation requires separate switches and cabling -- VLANs are a logical separation.

Q3. What is the primary purpose of a DNS query in a network?

  • To resolve a hostname or FQDN to an IP address
  • To encrypt communication between a client and a server
  • To assign IP addresses dynamically to devices on the network
  • To establish a secure connection for web traffic

DNS translates human-readable names (e.g. www.example.com) into IP addresses that devices can route to. Encryption = TLS/SSL. Dynamic IP assignment = DHCP. Secure web connections = TLS/HTTPS.

Q4. Which port is used by a client to communicate with a DNS server during a DNS query?

  • Port 67
  • Port 53
  • Port 80
  • Port 443

DNS uses port 53 for both UDP (standard queries) and TCP (zone transfers and large responses). Port 67 = DHCP server (68 = DHCP client). Port 80 = HTTP. Port 443 = HTTPS.

Q5. After acquiring companyB.com, an administrator needs users typing www.companyB.com to be redirected to www.companyA.com. Which DNS record type should be used?

  • CNAME Record
  • AAAA Record
  • PTR Record
  • A Record

A CNAME (Canonical Name) record creates an alias from one domain name to another. AAAA maps a hostname to an IPv6 address. PTR is for reverse DNS (IP to hostname). A Record maps a hostname to an IPv4 address -- not for aliasing one domain to another.

Q6. Several devices have 169.254.x.x addresses and can't connect to the internet. The DHCP server is running and other devices are fine. What is the most likely cause?

  • The DHCP server is configured with an incorrect subnet mask for the network
  • The DHCP scope does not have enough available IP addresses to assign to new devices
  • The affected devices are using static IP addresses that conflict with the DHCP scope
  • The DNS server is misconfigured, preventing devices from resolving domain names

169.254.x.x is APIPA -- devices self-assign these when they can't get a DHCP lease. The server is running and other devices are fine, so the scope is likely exhausted. An incorrect subnet mask would affect all devices. Static IP conflicts cause IP conflicts, not APIPA. DNS issues cause name resolution failures, not APIPA assignment.

Q7. A remote employee needs to securely access the company network from a coffee shop's public Wi-Fi. Which solution should they use?

  • Use the coffee shop's DNS server to resolve company domain names securely
  • Set up a VLAN on the coffee shop's Wi-Fi network
  • Configure their device to use a static IP address assigned by the company
  • Connect to the company's network using a Virtual Private Network (VPN)

A VPN creates an encrypted tunnel over the public internet, securing all traffic regardless of the underlying Wi-Fi. A public DNS server provides no transmission security. The employee doesn't control the coffee shop's infrastructure to set up a VLAN. A static IP doesn't encrypt or protect the transmission.

Q8. What is the primary purpose of a DHCP server in a network?

  • To manually assign static IP addresses to all devices on the network
  • To act as a firewall and block unauthorized access to the network
  • To allocate IP addresses dynamically to devices on the network
  • To resolve domain names into IP addresses for devices on the network

DHCP automatically assigns IP addresses, subnet masks, default gateways, and DNS server info when devices join the network. Static assignment is the opposite of DHCP. Blocking unauthorized access = firewall. Resolving domain names = DNS.

Q9. Users can access a website by IP address but not by domain name. What is the most likely cause?

  • The DNS server is not resolving the domain name to its corresponding IP address
  • The MAC address of the client devices is not registered with the network
  • The VLAN configuration on the network switch is incorrect
  • The DHCP server is not assigning IP addresses to client devices

IP access works but domain name access doesn't -- the classic DNS failure symptom. Routing and connectivity are fine; only name resolution is broken. MAC addresses don't affect web access by domain name. A VLAN misconfiguration would affect all connectivity. If DHCP were failing, users wouldn't have IPs and couldn't reach the site by IP either.

Q10. How does a VPN ensure secure communication over an untrusted network?

  • By encrypting data transmitted between the client and the server
  • By resolving domain names into IP addresses for secure access
  • By dynamically assigning IP addresses to devices on the network
  • By dividing a network into smaller segments to isolate traffic

A VPN creates an encrypted tunnel so intercepted traffic cannot be read. Resolving domain names = DNS. Dynamically assigning IPs = DHCP. Dividing a network into segments = VLANs.

Q11. Which DNS record type specifies which mail servers are authorized to send emails on behalf of a domain?

  • SPF (Sender Policy Framework) Record
  • CNAME (Canonical Name) Record
  • AAAA (IPv6 Address) Record
  • A (Address) Record

SPF is a DNS TXT record that lists authorized mail servers for a domain, helping recipient servers reject spoofed senders. CNAME creates domain name aliases. AAAA maps hostnames to IPv6 addresses. A Record maps hostnames to IPv4 addresses.

Q12. Devices in the Sales VLAN cannot communicate with devices in the Finance VLAN, but inter-department communication is required. What is the most likely cause and resolution?

  • The devices are using different IP address ranges, which prevents communication
  • The VLANs are misconfigured and all devices should be assigned to the same VLAN
  • VLANs are designed to block all inter-VLAN communication and the network must use a single VLAN
  • The switch is not configured with a router or Layer 3 device to enable inter-VLAN communication

VLANs are isolated broadcast domains by design -- traffic between VLANs requires a router or Layer 3 switch. Different subnets across VLANs are normal and expected; a router handles that. Merging all devices into one VLAN defeats the purpose of VLANs. Inter-VLAN communication is possible via routing -- a single VLAN is not required.

Q13. Broadcast traffic from one department is affecting others on the same physical switch. VLANs are being implemented. Which configuration best solves the problem?

  • Create separate VLANs for each department and assign devices to their respective VLANs
  • Enable a single VLAN for all devices to centralize traffic management
  • Use VLANs to physically separate devices by connecting each department to a different switch
  • Configure the switch to assign IP addresses dynamically to reduce broadcast traffic

Segmenting departments into separate VLANs on a single switch contains each department's broadcast traffic. A single VLAN for all devices does nothing to reduce broadcast interference. VLANs are a logical separation -- physically connecting to different switches doesn't require VLANs. Switches don't assign IPs (that's DHCP), and dynamic IP assignment doesn't reduce broadcast traffic.

Q14. A DNS query for a domain returns an NXDOMAIN response, but other websites work fine. What is the most likely cause?

  • The domain name does not exist or is not registered in the DNS hierarchy
  • The user's local DNS cache is corrupted and needs to be cleared
  • The DNS server is down and not responding to any queries
  • The user's device has an incorrect subnet mask configured in its TCP/IP settings

NXDOMAIN means "Non-Existent Domain" -- the DNS server responded but has no record of that domain. Other sites resolve fine, confirming DNS is functional. A corrupted cache would return a wrong IP, not NXDOMAIN. If DNS were down, no sites would resolve and no response would come back at all. A subnet mask issue would break all internet connectivity.

Q15. A company wants to redirect traffic from an acquired company's domain to its own without maintaining two separate websites. Which DNS record type should be used?

  • A Record
  • CNAME Record
  • MX Record
  • AAAA Record

A CNAME creates an alias from one domain to another, redirecting traffic without maintaining two separate sites. An A Record maps a hostname to an IPv4 address -- requires pointing to a specific IP, not another domain. MX Records direct incoming email traffic, not web traffic. AAAA maps to an IPv6 address, not for domain aliasing.
