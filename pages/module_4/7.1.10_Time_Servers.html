7.1.10 Time Servers

NTP (Network Time Protocol)

Purpose
Allows networked systems to sync their clocks to a common source. Ensures accurate timestamps in network logs. Some communication protocols also rely on accurate clocks to control data transmission.
Port
UDP/123
Windows Default Server
time.windows.com. Check sync status with: w32tm /query /status

Stratum Levels

Stratum Source
Stratum-0 Atomic clock (most accurate; reference clock, not directly on network)
Stratum-1 NTP server synced directly to a Stratum-0 source
Stratum-2 NTP server synced to a Stratum-1 server

NTS (Network Time Security)

Purpose
Secure replacement/extension for NTP. Uses TLS encryption to protect time data in transit.
Approved
2020
Port
TCP/4460

Port Reference

Protocol Port Encrypted?
NTP UDP/123 No
NTS TCP/4460 Yes (TLS)
