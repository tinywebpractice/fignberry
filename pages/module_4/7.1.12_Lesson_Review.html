Question 1 — Network Monitoring Interpretation

A Network Monitoring Server reports a significant increase in network traffic during non-business hours, along with several failed login attempts from an unfamiliar IP address. How should you interpret these findings?

  • Assume the network monitoring server is malfunctioning and schedule a maintenance check.
  • Analyze the report to identify potential unauthorized access attempts and recommend implementing stricter access controls. ✓
  • Conclude that the increased traffic is due to legitimate after-hours work by employees, and no action is needed.
  • Determine that the failed login attempts are likely due to forgotten passwords and advise users to reset their credentials.

Assuming a malfunctioning server dismisses valid data. After-hours traffic combined with failed logins from an unknown IP is a security red flag, not a benign scenario. Forgotten passwords do not originate from unfamiliar external IP addresses. The two indicators together are classic signs of a potential intrusion attempt and must be investigated.

Question 2 — AAA Transit Component

Which component in the AAA server setup does not store authentication credentials but acts as a transit to forward data between devices?

  • NAP ✓
  • RADIUS
  • AAA
  • Supplicant

RADIUS is the AAA server protocol that stores and validates credentials. AAA is the overall framework. The supplicant is the client device requesting access. The NAP (Network Access Point) / NAS (Network Access Server) is the access appliance (switch, AP, VPN gateway) that forwards credentials between the supplicant and the AAA server without storing them.

Question 3 — Time Server Use Case

Your company has inconsistent timestamps on transaction logs across multiple servers, causing difficulties in tracking and auditing. Which action should you take?

  • Install and configure a centralized Time Server to synchronize the clocks of all network devices. ✓
  • Deploy a new Database Server to manage and store transaction logs more efficiently.
  • Implement HTTPS on all servers to secure data transmission and improve timestamp accuracy.
  • Set up an FTP server to regularly back up transaction logs for auditing purposes.

A database server manages data but cannot synchronize clocks. HTTPS provides encryption, not clock accuracy. FTP handles file transfers; backing up logs does not fix the root cause. The problem is unsynchronized clocks — the solution is NTP via a centralized time server.

Question 4 — Mail Server Primary Function

Which of the following is a primary function of a mail server?

  • Storing and managing large amounts of structured data
  • Facilitating the sending and receiving of email messages ✓
  • Hosting websites and web applications
  • Providing remote terminal access to network resources

Storing structured data = database server. Hosting websites = web server. Remote terminal access = SSH/RDP/Telnet server. A mail server handles email using SMTP for sending/transfer and POP3/IMAP for mailbox access.

Question 5 — Mailbox Server Role

Which of the following BEST evaluates the role of a mailbox server in a modern network environment?

  • A mailbox server primarily functions to store and manage email messages. ✓
  • A mailbox server primarily manages the authentication and authorization of users attempting to access network resources.
  • A mailbox server is responsible for filtering spam and malicious emails before they reach the user's inbox.
  • A mailbox server is used to host websites and web applications, providing HTTP and HTTPS access to users.

Authentication and authorization = directory/AAA server. Spam filtering = mail gateway, not a mailbox server. Web hosting = web server. A mailbox server receives messages from the SMTP server and makes them available to clients via POP3 or IMAP. Its role is storage and access.

Question 6 — Network Monitoring Server Function

Which of the following best describes the primary function of Network Monitoring Servers?

  • To enable secure communication over the internet using encryption protocols
  • To provide shared access to disk and print resources
  • To store, organize, and manage large amounts of structured and unstructured data
  • To monitor and analyze network traffic to ensure optimal performance and security ✓

Secure communication via encryption = TLS/HTTPS (web server). Shared disk and print access = file/print server. Storing structured/unstructured data = database server. Network monitoring servers use SNMP and syslog to collect device data, identify faults, and alert administrators.

Question 7 — Permanent Mail Server Connection

A network technician is configuring an email connection that will have a permanent connection to the mail server. What kind of email connection is the technician configuring?

  • POP3
  • SMTP
  • IMAP ✓
  • HTML

POP3 makes a temporary connection, downloads messages, and typically deletes them from the server. SMTP is for sending/relaying email, not mailbox access. HTML is a web markup language, not an email protocol. IMAP supports permanent, persistent connections and multiple simultaneous clients on the same mailbox.

Question 8 — Time Server Description

Which of the following BEST describes the primary function of a Time Server in a networked environment?

  • A Time Server is responsible for managing and storing large amounts of structured and unstructured data.
  • A Time Server synchronizes the clocks of computers and devices within a network. ✓
  • A Time Server facilitates the transfer of files between a client and a server using encrypted protocols.
  • A Time Server provides secure access to web applications and encrypts data transmitted over the network.

Managing data = database server. Encrypted file transfer = SFTP/FTPS. Secure web access = HTTPS/TLS. A Time Server runs NTP (UDP/123) to synchronize clocks across all networked devices, ensuring accurate timestamps for logs, auditing, and time-dependent protocols.

Question 9 — Port 3389 Protocol

A network technician securely connects to a remote server on port 3389. What protocol does the technician use?

  • SSH — TCP/22
  • Telnet — TCP/23
  • RDP ✓
  • LDAP — TCP/UDP 389

SSH = TCP/22 (encrypted CLI). Telnet = TCP/23 (unencrypted CLI). LDAP = TCP/UDP 389 (directory queries). Port 3389 = RDP (Remote Desktop Protocol), Microsoft's proprietary protocol for graphical remote access to Windows machines.

Question 10 — Website Encryption

You need to secure your company's website so that all data exchanged between clients and the server is encrypted and the server's identity is verified. Which action should you take?

  • Configure the website to use HTTP and ensure all data is transmitted over port 80.
  • Install a digital certificate from a trusted Certificate Authority (CA) on the web server and configure the website to use HTTPS. ✓
  • Set up the website to use FTP for data transmission and ensure that it operates over port 21.
  • Enable NetBIOS over TCP/IP on the web server to allow secure data transmission.

HTTP (port 80) is completely unencrypted and provides no server identity verification. FTP is a file transfer protocol, not a web protocol, and is also unencrypted. NetBT is an obsolete legacy protocol with no role in web encryption. HTTPS requires a digital certificate from a trusted CA, which both encrypts traffic via TLS and verifies the server's identity.

Question 11 — URL Components (Select three)

A web developer plans out a new website, including URLs for each page. What are parts of the URL that the web developer will need to consider? (Select three.)

  • File path ✓
  • Protocol ✓
  • FQDN ✓
  • File server

A file server is a network device/role that hosts shared files — it is not a component of a URL. URLs are composed of: Protocol (e.g., https://), FQDN (e.g., store.comptia.org), and File path (e.g., /bundles/aplus.html). Example: https://store.comptia.org/bundles/aplus.html.

Question 12 — Mail Server Connection Limit

Your organization is experiencing intermittent email delivery failures. Investigation reveals the mail server is frequently reaching its maximum capacity for concurrent connections. Which analysis would BEST help determine the root cause?

  • Examine the web server's bandwidth usage to identify potential network bottlenecks affecting email delivery.
  • Review the database server's query performance to check for delays in data retrieval impacting email processing.
  • Evaluate the file/print server's resource allocation to determine if it is affecting the mail server's performance.
  • Analyze the mail server's configuration settings to ensure they are optimized for handling the current volume of email traffic. ✓

Web server bandwidth, database query performance, and file/print server resources are all separate systems with no direct link to the mail server's connection limit. The identified problem is the mail server hitting its maximum concurrent connections — the direct fix is analyzing and optimizing the mail server's own configuration settings.

Question 13 — Telnet Security Concern

Which of the following statements BEST describes the primary security concern associated with Telnet?

  • Telnet requires multi-factor authentication, providing an additional layer of security against unauthorized access.
  • Telnet encrypts all data transmissions, ensuring secure communication between client and server.
  • Telnet uses a secure tunneling protocol to protect data integrity and confidentiality during transmission.
  • Telnet transmits data, including passwords, in plaintext. ✓

Telnet has no MFA capability. Telnet has zero encryption — the opposite of the claim. Telnet has no tunneling or security features; SSH is the secure replacement. Telnet's core security problem is that all data including credentials travels in plaintext and is vulnerable to packet sniffing and replay attacks.

Question 14 — Database Server Function

Which of the following statements correctly describes the primary function of database servers?

  • Database servers are designed to provide secure email communication and manage email storage for users.
  • Database servers primarily serve as a platform for hosting web applications and static web pages.
  • Database servers are mainly used to store, organize, and manage large amounts of structured and unstructured data. ✓
  • Database servers are primarily used to facilitate file sharing and printing services across a network.

Secure email and storage = mail/mailbox server. Web application hosting = web server. File sharing and printing = file/print server (SMB). Database servers (SQL and NoSQL) are specifically designed for storing and managing data in structured (relational/tables) or unstructured (documents, key-value, graphs) formats.

Question 15 — SMB Security Status

Which of the following statements about Server Message Block (SMB) accurately describes its current security status and implementation in modern networks?

  • SMB is only used for printer sharing on Windows networks and does not support file sharing functionalities.
  • SMB1 is the most secure version of SMB and is enabled by default on all current Windows versions.
  • SMB3 is the current version of SMB and is considered secure, while SMB1 has serious security vulnerabilities and is disabled by default on current Windows versions. ✓
  • SMB2 is the latest version of SMB and is primarily used for file sharing on UNIX-based systems.

SMB supports both file and printer sharing. SMB1 is the most vulnerable version and is disabled by default, not the most secure. SMB3 is the current version, not SMB2. UNIX/Linux support for SMB is provided by the Samba software suite, not a version of SMB itself.
