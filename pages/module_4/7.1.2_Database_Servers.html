7.1.2 Database Servers

Overview

Database servers store, organize, and manage large amounts of structured and unstructured data. Unlike flat files (e.g., spreadsheets), databases support querying for reports, modification for special purposes, and data-driven business decisions.

Relational Databases (SQL)

Structure
Stores data in tables using columns and rows. Links data points together based on their relationships to one another.
Query Language
SQL (Structured Query Language) is used to interact with the database. Also referred to as SQL databases.
Examples
Oracle, MySQL, MariaDB.

Non-Relational Databases (NoSQL)

Structure
Stores data flexibly using graphs, documents, or key-value pairs. No fixed table schema.
Best For
High flexibility with various data types; large volumes of data.
Examples
MongoDB, CouchDB, Amazon SimpleDB.

Comparison

Relational (SQL) Non-Relational (NoSQL)
Data Format Tables (rows and columns) Graphs, documents, key-value pairs
Schema Fixed/structured Flexible
Query Language SQL Varies by platform
Best For Structured, relational data Large volumes, varied data types
Examples Oracle, MySQL, MariaDB MongoDB, CouchDB, Amazon SimpleDB
