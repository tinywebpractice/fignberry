7.1.3 Web Servers

HyperText Transfer Protocol (HTTP)

HTTP
Enables clients (typically web browsers) to request resources from an HTTP server. Client connects on TCP/80 by default and submits a GET request. Server returns the requested data or responds with an error code.
HTTPS
Secure version of HTTP using TLS encryption. Runs on TCP/443.
GET
HTTP method used by the client to request a resource from the server.
POST
HTTP method used to submit data from the client to the server (e.g., form submissions).

HTML and Web Applications

HTTP typically serves HTML (HyperText Markup Language) pages. HTML is a plain text file with coded tags describing document formatting. Browsers interpret the tags and render text, images, and other media. HTML supports hyperlinks to related documents.

HTTP server functionality is often extended by scripting and programmable features, forming web applications.

Uniform Resource Locators (URLs)

Resources on the Internet are accessed using URLs. A URL contains all the information needed to identify and access an item.

URL Component Description Example
Protocol Access method or service type https://
Host (FQDN) Fully Qualified Domain Name; not case-sensitive. Can also be an IP address; IPv6 must be in square brackets. store.comptia.org
File Path Directory and file name of the resource. Case-sensitivity depends on server configuration. /bundles/aplus.html

Web Server Deployment

  • Organizations typically lease a web server or space on a server from an ISP.
  • Larger organizations with Internet-connected datacenters may self-host.
  • Intranet - private network using web technologies; permits local access only.
  • Extranet - private network using web technologies; permits remote access.
