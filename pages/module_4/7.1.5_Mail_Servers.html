7.1.5 Mail Servers

Overview

Two types of protocols process email: mail transfer protocols (move messages between servers) and mailbox access protocols (allow clients to retrieve messages).

Internet email addresses follow the format username@domain.com (local part + @ + domain name).

SMTP (Simple Mail Transfer Protocol)

Specifies how email is delivered from one mail domain to another. The sending SMTP server uses the domain portion of the recipient's address to look up the recipient's SMTP server via DNS MX and A/AAAA records.

MTA (Message Transfer Agent)
SMTP server that relays messages between mail domains. Uses TCP/25 (typically unencrypted, server-to-server).
MSA (Message Submission Agent)
SMTP server that accepts messages from mail clients for delivery. Uses TCP/587 with encryption and authentication.

IMAP (Internet Message Access Protocol)

Mailbox access protocol used by mail clients to retrieve and manage messages stored on the mail server. Supports folder synchronization (e.g., Sent Items, Inbox). Secure port: TCP/993.

POP3 (Post Office Protocol v3) is an older mailbox access protocol (TCP/110 unencrypted, TCP/995 encrypted). Unlike IMAP, POP3 typically downloads and deletes messages from the server rather than syncing.

Email Delivery Flow

  1. Step 1: Client submits message to local SMTP server via TCP/587 (secure). Message is copied to Sent Items on local IMAP server via TCP/993.
  2. Step 2: Local SMTP server uses DNS to look up the MX record for the recipient's domain and connects to the remote SMTP server via TCP/25 (unencrypted).
  3. Step 3: Remote SMTP server accepts the message and copies it to the recipient's Inbox on the remote IMAP server.
  4. Step 4: Remote mail client connects to its IMAP server via TCP/993 (secure) to download the message.

Port Reference

Protocol Port Use Encrypted?
