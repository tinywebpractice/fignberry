7.1.6 Mailbox Servers

Overview

SMTP delivers mail to server hosts that are permanently available. Once received, SMTP passes the message to a mailbox server (separate machine or process). A mailbox access protocol then allows the client email software to retrieve messages from the mailbox.

POP3 (Post Office Protocol v3)

Function
Early mailbox access protocol. Authenticates the user (username/password), then downloads mailbox contents to the local PC for processing.
Message Handling
Messages are typically deleted from the server after download. Some clients offer an option to leave messages on the server.
Ports
TCP/110 (unencrypted), TCP/995 (secure/TLS).
Clients
Microsoft Outlook, Mozilla Thunderbird.

IMAP (Internet Message Access Protocol)

Function
Mail retrieval protocol that addresses POP3 limitations. Messages remain on the server; clients sync with the server mailbox.
Key Features
Supports permanent server connections, multiple simultaneous clients on the same mailbox, server-side folder management, controlled deletion, and multiple mailboxes.
Ports
TCP/143 (unencrypted), TCP/993 (IMAPS / TLS-secured).

POP3 vs. IMAP

POP3 IMAP
