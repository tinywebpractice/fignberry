7.1.9 Remote Terminal Access Servers

Overview

TTY (Teletype)
The original terminal device. Handles text input/output between the user and the shell. The terminal accepts input and displays output; the shell performs the actual processing.
Terminal Emulator
Software that replicates TTY input/output function. A remote terminal emulator connects to the shell of a different host over the network.

SSH (Secure Shell)

Purpose
Principal means of secure remote access to UNIX/Linux servers and network appliances (switches, routers, firewalls). Provides encrypted terminal emulation.
Additional Uses
SFTP (file transfer over SSH) and other network configurations.
Port
TCP/22
Common Implementation
OpenSSH (openssh.com) - available on UNIX, Linux, Windows, and macOS.

Telnet

Purpose
Protocol and terminal emulation tool that transmits shell commands and output between client and remote host.
Port
TCP/23
Security
No encryption. Password and all communications sent in plaintext. Vulnerable to packet sniffing and replay attacks. Should NOT be used for device configuration; SSH should be used instead.

RDP (Remote Desktop Protocol)

Purpose
Microsoft's protocol for remote GUI connections to a Windows machine. Sends screen and audio from the remote host to the client; transfers mouse and keyboard input from the client to the host.
Port
TCP/3389
Platform Support
RDP clients available on Linux, macOS, iOS, and Android. Open-source RDP server: xrdp (xrdp.org).
Security
Administrator can specify connection permissions and configure encryption.
