Lab Scenario

Configure a Windows workstation to use the organization's manual proxy server. You will open the Windows proxy settings, enable manual proxy setup, enter the proxy server address and port, and save the configuration.

Step 1 - Access the Proxy Settings

  • Right-click Start and then select Settings.
  • Select Network & Internet.
  • From the left pane, scroll down and select Proxy.
  • Maximize the window for better viewing.

Step 2 - Configure a Manual Proxy

  • Under Manual proxy setup, slide the Use a proxy server button to On.
  • In the Proxy IP Address field, enter proxy.corpnet.local.
  • In the Port field, enter 9000.
  • Select Save.
  • Close the Settings app.

Step 3 - Verify the Configuration

  • Confirm that manual proxy setup is enabled.
  • Confirm that the address is proxy.corpnet.local.
  • Confirm that the port is 9000.

Connection Summary

Setting Value Purpose
Use a proxy server On Enables manual proxy settings for the workstation.
Proxy IP Address proxy.corpnet.local Identifies the proxy server the workstation should use.
Port 9000 Identifies the network port used by the proxy service.

Key Terms

  • Proxy server - An intermediary server that forwards client web requests to the destination network or internet resource.
  • Proxy address - The hostname or IP address of the proxy server.
  • Proxy port - The TCP port number the client uses to connect to the proxy service.

Important: Enter the proxy address and port exactly as shown: proxy.corpnet.local and 9000.
