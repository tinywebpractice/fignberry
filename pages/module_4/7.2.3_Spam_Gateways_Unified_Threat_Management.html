7.2.3 Spam Gateways and Unified Threat Management

Overview

Networks connected to the Internet use security scanners to protect against malicious threats. These can run as software on PC servers, but enterprise networks typically use purpose-built Internet security appliances.

Security Functions

Function Description
Firewall Allows or blocks traffic based on a network access control list (ACL) specifying source/destination IP addresses and application ports.
IDS (Intrusion Detection System) Uses scripts to identify known malicious traffic patterns; raises an alert on a match.
IPS (Intrusion Prevention System) Like IDS, but can also take action to block the source of malicious packets.
Antivirus/Anti-malware Scans files transferred over the network for matches against known malware signatures in binary data.
Spam Gateway Uses SPF, DKIM, and DMARC to verify mail server authenticity; filters spoofed, misleading, malicious, or unwanted messages before delivery to inbox.
Content Filter Blocks outgoing access to unauthorized websites and services.
DLP (Data Leak/Loss Prevention) Scans outgoing traffic for confidential or personal data; verifies authorization and blocks unauthorized transfers.

Spam Gateway: Key Protocols

SPF (Sender Policy Framework)
Verifies that the sending mail server is authorized to send on behalf of a domain.
DKIM (DomainKeys Identified Mail)
Uses cryptographic signatures to verify that a message was not altered in transit and originated from the claimed domain.
DMARC (Domain-based Message Authentication, Reporting, and Conformance)
Builds on SPF and DKIM; defines a policy for how failed authentication should be handled and enables reporting.

UTM (Unified Threat Management)

A UTM appliance combines multiple security functions into a single device, enforcing a variety of security policies and controls.

  • Replaces separate appliances or server applications each with their own configuration and logging.
  • Centralizes threat management for simpler configuration and unified reporting.
  • Typically includes: Firewall, IDS/IPS, Antivirus/Anti-malware, Spam Gateway, Content Filter, and DLP.
