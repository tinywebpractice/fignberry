7.2.4 Load Balancers

What Is a Load Balancer?

A load balancer distributes client requests across multiple server nodes in a farm or pool. It sits in front of the server network and forwards requests from the client network or Internet to the application servers.

  • The service address is advertised to clients as a virtual server.
  • Provides high-availability services that scale from light to heavy loads.
  • Used with web servers, email servers, web conferencing servers, and streaming media servers.

How It Works (3 Steps)

Step Action
1 Client connects to the virtual server (e.g., 203.0.113.1) over the Internet.
2 The load balancer selects a server node (e.g., 10.1.0.1, 10.1.0.2, or 10.1.0.3) and forwards the traffic.
3 A persistence mechanism can keep the client connected to the same server, if it is available.

Key Terms

Virtual Server
The single IP/address advertised to clients; the load balancer sits behind it and routes to real servers.
Server Farm / Pool
The group of backend servers that the load balancer distributes requests across.
Persistence (Session Persistence / Sticky Sessions)
Mechanism that ensures a client is routed to the same backend server for the duration of a session, if that server is still available.
