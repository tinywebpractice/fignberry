7.3.1 Troubleshoot Wired Connectivity

Typical Ethernet Link Components

For a single-host wired issue, isolate the physical location of the fault across these components:

  • NIC port on the host
  • RJ45 patch cord from host to wall port
  • Structured cable (permanent link) from wall port to patch panel, terminated to IDC (insulation displacement connector) blocks
  • RJ45 patch cord from patch panel port to switch port
  • Network transceiver in the switch port

Link LEDs on NIC and switch ports indicate whether the link is active and at what speed. LEDs flicker to show network activity.

Troubleshooting Steps: No / Intermittent Connectivity

Step Action Tools
1 Check patch cords are properly terminated and seated; substitute with a known good cable if suspect. Cable tester
2 If patch cords are good, test the transceivers for a bad port. Loopback tool
3 If no loopback tool, substitute known working hosts (connect a different PC or swap switch ports). Note: may disrupt network; port security can make this unreliable. Known good host
4 If patch cords and ports are ruled out, test the structured (permanent) cabling. May need new permanent link; could be a termination or interference issue. Cable tester / Certifier
5 If cabling is good, verify Ethernet speed/duplex settings on the switch interface and NIC (should be set to auto-negotiate). Consider updating the NIC driver. Switch config / Device Manager

Key Tools

Cable Tester
Verifies patch cords and structured cabling for continuity and correct termination.
Certifier
Advanced cable tester that reports detailed performance metrics and interference data.
Loopback Tool
Plugs into a port to test whether the NIC or switch port transceiver is functioning correctly.

Port Flapping

Port flapping is when a NIC or switch interface continually transitions between up and down states. Common causes: bad cabling, external interference, or a faulty NIC. Use the switch configuration interface to report how long a port remains in the up state.
