7.3.2 Troubleshoot Network Speed Issues

First Check: Duplex / Speed Mismatch

Mismatched duplex settings between the NIC and switch port can reduce transfer speeds. With Gigabit Ethernet, both should be set to autonegotiate. Check the NIC driver settings in the client OS and the switch port settings via switch management software.

Structured Troubleshooting Steps

Step Action Notes
1 Identify the specific network activity (web browsing, file transfer, authentication, etc.). Measure actual transfer rate independently of apps using a utility. Establish whether there is a true link speed problem vs. application issue.
2 If isolated to a single cable segment, check for interference or crosstalk. Inspect cable ends for excessive untwisting or improper termination. External interference sources: power lines, fluorescent lighting, motors, generators. Use a network tap/analyzer to check for damaged frames; view error rates via switch interface. Consider shielded cables.
3 If cabling is not the issue, check the NIC driver. Install updates if available; check if other hosts with the same NIC/driver version are also affected. Driver issues can throttle NIC performance.
4 Consider malware or faulty software on the host. Remove the host from the network for scanning. Substitute a different host on the same port to compare. If the substitute host performs normally, investigate what differs about the original host.
5 Determine the scope: single user, all users on the same switch, or all users accessing the Internet? Wider scope suggests congestion or a fault at the switch/router level; could also be caused by a user transferring large volumes of data.

Crosstalk

Crosstalk is interference caused by poorly installed cabling or improper connector termination. Excessive untwisting of wire pairs at cable ends is a common cause. High damaged frame counts in analyzer software or elevated switch error rates indicate this problem.
