Lab Scenario

A workstation has no internet connection. You will verify the reported problem, identify the unplugged network cable, connect the cable to the wall plate, configure a valid IPv4 address, and test connectivity from PowerShell.

Step 1 - Verify the Problem

  • From the notification area, right-click the network icon and select Network & Internet settings.
  • Notice that the computer shows no connection to the internet.
  • Select Advanced network settings.
  • Under Related Settings, select More network adapter options.
  • Notice that the network connection status is Network cable unplugged.
  • Close the Network Connections window.
  • Close the Settings app.

Step 2 - Connect the Cable

  • From the top left, select Office 1 to work with the computer hardware.
  • Switch to the Back view of the computer.
  • Observe that the computer has a network cable, but the link light is not on.
  • Select the network cable connected to the computer to see what is connected to the other end.
  • In the Selected Item pane, notice that one end is unconnected.
  • Select the unconnected end and drag it to the network connection on the wall plate.

Step 3 - Configure the IP Addresses

  • Select the monitor to switch to the operating system view.
  • Confirm that the notification area now shows a network connection.
  • Right-click Start and select Settings.
  • Select Network & internet.
  • Select Ethernet.
  • For IP assignment, select Edit.
  • If necessary, change the Edit IP settings dropdown to Manual.
  • For IPv4, make sure the button is slid to the On position.
  • Enter a valid IP address, subnet mask, gateway, and preferred DNS server.
  • Select Save.
  • Close the Settings app.

IPv4 Configuration

Field Value
IP address Valid IP address, such as 192.168.0.27
Subnet mask 255.255.255.0
Gateway 192.168.0.5
Preferred DNS 163.128.78.93 or 163.128.80.93

Step 4 - Verify Internet Connectivity

  • Right-click Start and select Terminal.
  • At the PowerShell prompt, type ping 163.128.78.93.
  • Press Enter.

Troubleshooting Summary

Symptom Cause Fix
No internet connection Network cable unplugged Connect the cable to the wall plate.
Cable connected but network needs valid addressing Manual IPv4 settings need configuration Enter a valid IP address, subnet mask, gateway, and DNS server.

Important: Fix the physical connection first, then configure IPv4 settings, then verify connectivity with ping.
