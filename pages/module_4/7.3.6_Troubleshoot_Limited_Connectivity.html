7.3.6 Troubleshoot Limited Connectivity

Limited Connectivity vs. No Internet Access

Windows Message Meaning IP Address State
Limited connectivity Physical connection established, but no IP lease received from DHCP server. APIPA address: 169.254.x.y
No Internet access IP configuration obtained (DHCP or static), but cannot reach Microsoft test site. Indicates a gateway or DNS issue. Valid IP assigned

On Linux, APIPA may also be used, or the IP may be set to 0.0.0.0 (unknown) or left unconfigured.

Troubleshooting Limited Connectivity (DHCP / APIPA)

Check Details
Scope of issue Multiple users affected = likely a DHCP server problem. DHCP leases take time to expire, so the problem may manifest gradually as clients try to renew. Possible causes: DHCP server offline, out of available leases, or forwarding misconfigured.
Patch cord / wall port Verify the wall port is connected to an appropriate switch port via the patch panel. Wrong switch port = no access to default gateway, DHCP, or DNS.
VLAN configuration If the switch port has an incorrect VLAN ID, the effect is the same as being connected to the wrong switch port.

Troubleshooting No Internet Access

  • Access the router management interface and check the Internet connection status page.
  • If the WAN link is down, contact your ISP.
  • Use router diagnostic tools to test connectivity to configured DNS servers.
  • Issue is either with Internet access at the gateway router or with name resolution (DNS).
