7.5.1 Client Server Relationship

Peer-to-Peer (Workgroup) vs. Client-Server

Peer-to-Peer (Workgroup) Client-Server
Roles Any computer can act as client or server depending on context Dedicated servers provide services; clients only consume them
Accounts Each user needs accounts on every other computer Centralized account management
Security Low; difficult to control access High; servers are secured and isolated
Scale Practical for fewer than ~10 devices Suitable for enterprise networks of any size
File sharing Shared directly from individual computers Stored on a dedicated file server

Peer-to-Peer: Role Is Perspective-Based

In a workgroup, client and server roles are not fixed. A computer sharing a folder is acting as a server to the computer requesting it. The same computer can simultaneously be a client to another shared resource. Example roles a single workstation might fill:

  • Server - sharing a folder others can pull from
  • Client - pulling files from another shared folder
  • Print server - forwarding print jobs to a locally attached printer
  • Gateway - using two NICs to connect the private network to the ISP

Client-Server: Dedicated Roles

In a client-server network, servers run specific services activated by an administrator. A freshly installed server OS offers only basic file services by default; additional services must be enabled.

Service Example
Web server (HTTP) IIS on Windows Server hosting an internal intranet site
DHCP server Assigns IP addresses to clients on boot
Mail server Handles email for network users
File server Centralized storage; users store/retrieve files instead of sharing from their own machines

Client computers in a client-server network do not act as servers. Keeping clients in a pure client role reduces security risk.
