7.5.3 Exercise: Server Comparison Project

This lesson is a research and presentation exercise. CompTIA asks you to pick two of the three server types below, compare their purposes and functions, and present your findings. The table below covers all three as reference.

Server Type Comparison

File Server Application Server Database Server
Primary Purpose Centralized storage and access to files across the network Hosts and runs applications that clients access remotely Stores, manages, and retrieves structured data for clients and applications
Key Functions File sharing, permissions management, storage allocation Application execution, session management, business logic processing Query processing, data integrity, transaction management
Real-World Examples Windows Server with shared drives; NAS devices Web app servers (Apache Tomcat, IIS); ERP systems MySQL, Microsoft SQL Server, Oracle DB
Common Software Windows Server, Samba (Linux) IIS, Apache Tomcat, JBoss MySQL, PostgreSQL, Microsoft SQL Server
Hardware Needs High storage capacity, RAID, fast network I/O High CPU and RAM for processing application logic Fast storage (SSD/NVMe), high RAM, fast I/O
Benefits Centralized backups, easy access control, simple to implement Centralized app management, reduces load on client devices Efficient data retrieval, supports complex queries, multi-user access
Limitations Single point of failure without redundancy; performance degrades with heavy use Server becomes bottleneck if underpowered; complex to configure Requires skilled administration; performance-intensive for large datasets

Exam Objective

This exercise supports A+ Core 1 (220-1201) Objective 2.3: Summarize services provided by networked hosts.
