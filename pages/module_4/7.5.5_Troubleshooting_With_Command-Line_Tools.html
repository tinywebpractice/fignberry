7.5.5 Exercise: Troubleshooting with Command-Line Tools

This lesson is a scenario-based exercise. CompTIA asks you to apply five command-line tools across five network troubleshooting scenarios and write up your findings. The reference material below covers each tool and its scenario.

Command-Line Tools Reference

Tool OS Purpose Key Command
ipconfig Windows Display IP address, subnet mask, default gateway, DNS ipconfig /all
ifconfig Linux / macOS Same as ipconfig; display and configure network interfaces ifconfig
nslookup Windows / Linux Query DNS to resolve domain names to IP addresses nslookup example.com
netstat Windows / Linux Display active connections, listening ports, network stats netstat -an
arp Windows / Linux View and manage ARP table (IP-to-MAC address mappings) arp -a
ping Windows / Linux Test connectivity; measure response time and packet loss ping <IP or hostname>

Scenarios and Expected Findings

Scenario Symptom Tool What to Look For Resolution
1 Cannot access the Internet ipconfig / ifconfig APIPA address (169.254.x.x) = no DHCP lease; missing default gateway = no route out Release/renew DHCP lease; check DHCP server; verify gateway config
2 Cannot reach a specific website nslookup Failure to resolve domain = DNS issue; if IP resolves but site unreachable = server/routing issue Correct DNS server settings; test alternate DNS (e.g., 8.8.8.8)
3 Slow network performance netstat Excessive open connections or unusual foreign addresses may indicate a bottleneck or malware Close unnecessary connections; investigate suspicious processes; scan for malware
4 Cannot connect to a local printer arp -a Printer IP not in ARP table or mapped to wrong MAC = ARP resolution failure Verify printer IP; clear stale ARP entry (arp -d); confirm printer is online
5 Intermittent connectivity ping Packet loss or high/variable response times to default gateway = unstable local connection Check cable/NIC; check switch port; contact ISP if gateway pings succeed but internet fails

Exam Objective

This exercise supports A+ Core 1 (220-1201) Objective 5.5: Given a scenario, troubleshoot network issues.
