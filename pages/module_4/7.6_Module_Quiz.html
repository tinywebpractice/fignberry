7.6 Module Quiz - Q&A

Question 1

A security technician is installing a doorbell/video entry system for a customer so that the customer can see and communicate with people who come to their home when they aren't there. What kind of device is the doorbell/video entry system?

  • OT
  • Hub and control system
  • Smart device
  • Zigbee

A video doorbell is a consumer IoT smart device - it connects to the internet and is controlled via a smartphone app. It is an endpoint device, not a hub, not an industrial OT device, and Zigbee is a protocol, not a device category.

Question 2

Your company has recently launched an e-commerce website currently using HTTP for data exchange. Customers are hesitant to make purchases due to security concerns. What should you do?

  • Implement HTTPS by installing a digital certificate on the server and redirecting all HTTP traffic to HTTPS to ensure encrypted data transmission.
  • Configure the website to use HTTP over port 443 to give the appearance of security without making any actual changes to data encryption.
  • Increase the server's bandwidth to improve data transmission speed and reassure customers about the website's performance.
  • Advise customers to use a VPN when accessing the website to secure their data independently of the website's configuration.

HTTPS encrypts data in transit using TLS. A digital certificate authenticates the server; redirecting HTTP to HTTPS ensures all traffic is encrypted. Running HTTP over port 443 provides no encryption. Bandwidth and VPN advice do not fix the server-side security gap.

Question 3

Which of the following statements best describes the function of Hypertext Transfer Protocol Secure (HTTPS)?

  • HTTPS is a secure version of HTTP that uses encryption to protect data transmitted between a client and a server.
  • HTTPS is a protocol that allows users to upload files to a web server without encryption.
  • HTTPS is a protocol used to establish a connection between two servers without verifying their identities.
  • HTTPS is a protocol used to transfer unencrypted data between a client and a server over the internet.

HTTPS = HTTP + TLS encryption. It authenticates the server via certificate and encrypts all traffic. Unencrypted transfers describe HTTP; no identity verification describes neither HTTPS nor any correct protocol; file uploads without encryption describes FTP.

Question 4

What is a common cause of reduced network speed in a cabled link?

  • Weak wireless signal strength
  • Incorrect network password
  • Outdated VoIP application
  • Mismatched duplex settings

A duplex mismatch between the NIC and switch port is a primary cause of reduced throughput on a cabled link; both should be set to autonegotiate. The other options are wireless or application-layer issues unrelated to cabled link speed.

Question 5

Company employees are accessing the same resources on the internet many times a day. As the network administrator, you configure a solution that forwards traffic to and from the internet and also caches content to improve performance and reduce bandwidth consumption. What solution are you implementing?

  • Proxy server
  • UTM
  • NAT
  • Load balancer

A proxy server forwards traffic on behalf of clients and caches frequently accessed content. UTM consolidates security functions but does not cache content. NAT translates addresses only. A load balancer distributes traffic across backend servers.

Question 6

You are an IT administrator setting up email access for remote employees who need to download their emails to their local devices and read them offline. Which protocol would you apply to configure their email clients to meet this requirement?

  • Simple Mail Transfer Protocol (SMTP)
  • Hypertext Transfer Protocol Secure (HTTPS)
  • Internet Message Access Protocol (IMAP)
  • Post Office Protocol (POP3)

POP3 downloads emails to the local device for offline access. SMTP is for sending email. HTTPS is a web protocol. IMAP keeps email on the server and syncs across devices but is not designed for offline reading.

Question 7

Which of the following functions are performed by proxy servers? (Select two.)

  • Block unwanted packets from entering your private network.
  • Store client files.
  • Cache web pages.
  • Block employees from accessing certain websites.
  • Filter unwanted email.

Proxy servers cache content and act as content filters. Blocking unwanted packets is a firewall function. Storing files is a file server function. Filtering email is a spam gateway function.

Question 8

You are an IT technician tasked with resolving a wired connectivity issue for a workstation in an office. The user reports intermittent connectivity problems. Upon inspection, you notice that the link LEDs on the network adapter and switch port are flickering inconsistently. What is the BEST next step to troubleshoot and resolve the issue?

  • Use a loopback tool to test the switch port.
  • Substitute the current patch cord with a known good cable.
  • Update the NIC's device driver software.
  • Replace the network adapter (NIC) on the workstation.

Inconsistently flickering LEDs indicate an unstable physical link. Step 1 is always to substitute the patch cord. Loopback testing is Step 2, driver updates are Step 5, and NIC replacement is a last resort.

Question 9

A network technician troubleshoots a computer on the wired network that is experiencing slow network speeds. Which of the following would NOT be a possible cause for the technician to troubleshoot?

  • Improperly terminated patch cords
  • Improper speed/duplex configuration
  • Another radio source broadcasting at the same frequency
  • External interference on the cable

RF interference from competing radio sources is a wireless issue only; it does not affect cabled Ethernet links. Improperly terminated patch cords cause crosstalk, duplex mismatch reduces throughput, and external EMI degrades copper cabling - all are valid wired causes.

Question 10

Your company is experiencing issues with email delivery, and employees are unable to send or receive emails. As the network administrator, you suspect there might be a problem with the mail server. Which of the following actions would be the MOST appropriate first step to diagnose and resolve the issue?

  • Review the database server's performance metrics for any anomalies.
  • Check the web server logs for any error messages related to email delivery.
  • Inspect the file/print server for any disk space issues that might affect email storage.
  • Verify the mail server's network connectivity and ensure it is online.

When the mail server is suspected, confirm it is reachable and online first. Database, web, and file/print servers are separate roles unrelated to email delivery.

Question 11

A company has recently experienced performance issues with its web application during peak usage times. The application is hosted on multiple servers, but users report slow response times and occasional timeouts. Which solution would BEST address the company's performance problems?

  • Implement a load balancer to distribute incoming requests evenly across all servers.
  • Install a firewall to block unnecessary traffic and reduce server load.
  • Set up a spam gateway to filter out unwanted email traffic.
  • Deploy an intrusion detection system to monitor and alert on suspicious activities.

A load balancer distributes requests across all available servers, preventing overload during peak times. Firewalls, spam gateways, and IDS are security tools that do not address server performance distribution.

Question 12

What is the first step in troubleshooting a limited connectivity issue for a single host in a wired network?

  • Update the NIC's device driver software.
  • Use a cable tester to verify the structured cabling.
  • Verify that the patch cords are properly terminated and connected to the network ports.
  • Check the switch configuration for port security settings.

Step 1 is always to check patch cord termination and connection. Structured cabling testing is Step 4; driver updates are Step 5; port security is a secondary consideration.

Question 13

As a network engineer, you are tasked with improving the security of a legacy network that still uses older Windows systems. The network currently relies on NetBIOS over TCP/IP for name resolution and session services. What should you do to enhance the network's security while maintaining necessary functionality?

  • Enable NetBIOS over TCP/IP on all devices to ensure consistent name resolution across the network.
  • Maintain the current configuration of NetBIOS over TCP/IP, as it is essential for supporting file sharing on all Windows versions.
  • Upgrade all systems to use SMB1 for improved security and disable NetBIOS over TCP/IP.
  • Disable NetBIOS over TCP/IP and implement DNS for name resolution, ensuring compatibility with modern systems.

NetBIOS over TCP/IP is an older, insecure protocol. DNS is the modern, secure standard for name resolution and is compatible with all current systems. SMB1 is deprecated and highly insecure (associated with ransomware exploits); upgrading to it would worsen security.

Question 14

A user reports that their file transfers over the network are significantly slower than usual. Upon investigation, you find that the issue is isolated to this user's workstation. You check the cabling and find no visible damage or interference. What should you do next to troubleshoot the issue?

  • Reposition the user's workstation closer to the router.
  • Check the duplex settings on the user's network adapter and the switch port.
  • Replace the user's Ethernet cable with a shielded cable.
  • Update the firmware on the router.

Cabling cleared; issue is single-host. The next step is checking for a speed/duplex mismatch. Repositioning is a wireless fix. Shielded cable addresses interference that was not found. Router firmware affects all users, not just one.

Question 15

As a network administrator for your company, you want to set up a network device that manages traffic leaving and entering your network from the outside. Which of the following proxy server configurations would BEST meet your requirements?

  • VPN
  • Transparent proxy
  • Non-transparent proxy
  • Content filter

A transparent proxy intercepts all inbound and outbound traffic inline without requiring client-side configuration. A non-transparent proxy requires manual client configuration. VPN creates encrypted tunnels for remote access. A content filter is a feature, not a proxy configuration type.
