8.1.1 Hypervisors

Key Terms

Virtualization
The ability to run multiple operating systems simultaneously on one physical system. Supported by most modern computers; not available on entry-level models.
Hypervisor
Software that manages virtual machines (VMs) by emulating hardware resources (CPU, memory, storage, peripherals) so each guest OS functions as if it has exclusive access to the system.
Virtual Machine (VM) / Guest OS
An OS instance running within the hypervisor. VMs require drivers for the emulated hardware. Hypervisors may limit which guest OS types are supported.
