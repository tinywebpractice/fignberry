Lab Scenario

Use Windows settings and Hyper-V Manager to identify the operating system edition installed on the base computer and on each virtual machine.

Step 1 - Check the Base Computer OS

  • From the taskbar, select Start.
  • Select Settings.
  • Under System, scroll down and select About.
  • Under Windows specifications, use the Edition field to answer Question 1.
  • Close the Settings app.

Step 2 - Launch a Virtual Machine

Perform these steps for each of the three virtual machines.

  • In Hyper-V Manager, select ITADMIN on the left side of the application.
  • Double-click the VM you want to launch.
  • In the Virtual Machine Connection window, select the Start button.
  • Select Settings using the gear icon.
  • Select System.
  • On the left side of the screen, scroll down and select About.
  • Scroll down to Windows specifications and use the Edition field to answer the question that corresponds with the VM you have open.
  • Close the Virtual Machine Connection window.
