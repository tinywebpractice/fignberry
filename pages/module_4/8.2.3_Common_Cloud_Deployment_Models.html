Cloud Deployment Models

Public (Multitenancy)
Offered over the Internet by a cloud service provider (CSP) to multiple tenants. Includes subscription, pay-as-you-go, and free tier options. Shared resource model carries performance and security risks. Multicloud architectures use services from multiple CSPs.
Private
Cloud infrastructure exclusively owned and managed by a single organization. A dedicated business unit manages it while other units consume it. Greater control over privacy and security; ideal for banking and government requiring strict access control.
Community
Several organizations share the costs of a hosted private or fully private cloud. Resources are pooled for common concerns such as standardization and security policies.
Hybrid
Combines public, private, and/or community cloud elements. Example: a travel org uses private cloud most of the year, bursting to public cloud during peak times. Sensitive data stays on-premises while public cloud handles other functions.
