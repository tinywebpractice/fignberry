8.2.4 Lab: Use the Azure Interface

Required Actions

  • Configure the project details for the resource group.
  • Configure the resource details for the resource group.

Resource Group Settings

Field Value
Subscription CorpNet Production
Resource group CorpNetCloud
Resource details (US) West US2

Step 1 - Access the Azure Portal

  • From the taskbar, select Google Chrome.
  • In the browser address field, type https://portal.azure.com and press Enter.
  • Maximize the window for better viewing.

Step 2 - Start a Resource Group

  • Under Navigate, select Resource groups.
  • From the Resource groups menu bar, select Create.

Step 3 - Configure Project Details

  • For Subscription, select CorpNet Production.
  • For Resource group, type CorpNetCloud.

Step 4 - Configure Resource Details

  • For Region, select (US) West US2.
  • From the bottom menu bar, select Review + create to validate the configuration.
  • Select Create.

Step 5 - Review the Created Resource Group

  • From the Resource groups page, select CorpNetCloud.
  • Review the available options for the created resource group.

Important: Enter the resource group name manually as CorpNetCloud and use (US) West US2 for the region.
