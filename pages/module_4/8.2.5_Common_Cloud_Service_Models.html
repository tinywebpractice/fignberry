8.2.5 Common Cloud Service Models

Cloud Service Models Overview

Cloud service models are differentiated by the level of complexity and preconfiguration provided, in addition to the deployment model. The four most common models are IaaS, SaaS, PaaS, and DaaS.

Service Model Definitions

Infrastructure as a Service (IaaS)
Provision and manage IT resources, including virtual servers, storage, networking, and load balancers, from a cloud provider without owning physical hardware. Resources deploy and scale quickly. Examples include Amazon EC2, Microsoft Azure Virtual Machines, and OpenStack.
Software as a Service (SaaS)
Software applications delivered over the internet on a subscription or pay-as-you-go basis. No local installation is required. Supports single-tenancy for one user or multi-tenancy for multiple specified users. Examples include Microsoft 365, Salesforce, and Google Workspace.
Platform as a Service (PaaS)
A development environment that includes infrastructure, such as servers and storage, plus tools for building, testing, and deploying applications. No pre-built application is included. Developers create, secure, and manage their own software while the provider maintains platform availability and infrastructure integrity. Platforms may be based on Oracle, MS SQL, PHP, or MySQL. Examples include Oracle Cloud, Microsoft Azure SQL Database, and Google App Engine.
Desktop as a Service (DaaS)
Virtual desktops delivered to end users over the internet, accessible from any device and location. The desktop environment is managed entirely by a third-party provider.
