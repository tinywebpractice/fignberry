8.2.6 Lab: Manage IaaS Virtual Machines in Azure

Lab Scenario

You are the network administrator for your company. You have decided to begin the configuration of Azure to help manage your network. As part of this setup, you need to create a virtual server in Azure.

Required Configuration

Category Setting Value
Virtual machine type Type Azure virtual machine
Project details Subscription CorpNet Production
Project details Resource group CorpNetCloud
Instance details Virtual machine name CorpCloud1
Instance details Region (US) West US2
Instance details Image Windows Server 2022 Datacenter: Azure Edition - Gen2
Instance details Size Standard_D4s_v3 - 4 vcpu, 16 GiB memory ($327.04/month)
Administrator account Username CorpAdmin
Administrator account Password corpP@ssw0rd
Administrator account Confirm password corpP@ssw0rd
Disk options OS disk type Standard HDD
Disk options Delete with VM Selected
Networking Virtual network (new) CorpNetCloud-vnet
Networking Subnet (new) default (10.0.0.0/24)
Networking Public IP (new) CorpCloud1-ip

Step 1 - Configure Basic Settings

  • Maximize the Google Chrome window for better viewing.
  • Under Azure Services, select Virtual machines.
  • From the menu bar, select Create > Azure virtual machine.
  • For Subscription, select CorpNet Production.
  • For Resource group, select CorpNetCloud.
  • For Virtual machine name, enter CorpCloud1.
  • For Region, select (US) West US2.
  • For Image, select Windows Server 2022 Datacenter: Azure Edition - Gen2.
  • For Size, select Standard_D4s_v3 - 4 vcpu, 16 GiB memory ($327.04/month).
  • For Username, enter CorpAdmin.
  • For Password, enter corpP@ssw0rd.
  • For Confirm password, enter corpP@ssw0rd.

Step 2 - Configure Disks

  • From the bottom menu bar, select Next: Disks.
  • Under Disk options, set OS disk type to Standard HDD.
  • Make sure the Delete with VM box is selected.

Step 3 - Configure Networking

  • From the bottom menu bar, select Next: Networking.
  • Under Network Interface, verify Virtual network is (new) CorpNetCloud-vnet.
  • Verify Subnet is (new) default (10.0.0.0/24).
  • Verify Public IP is (new) CorpCloud1-ip.

Step 4 - Review and Validate

  • From the bottom menu bar, select Review + create.
  • Review the virtual machine details.

Step 5 - Create the Virtual Machine

  • From the bottom menu bar, select Create.
  • Monitor the creation process until the deployment is complete.
  • After the deployment is complete, select Go to resource.
  • Verify that the virtual machine has been created.

Important: Use the exact VM name, account name, password, image, size, disk, network, and region values shown in the configuration table.
