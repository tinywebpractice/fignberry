Q1. A mid-sized e-commerce company is experiencing rapid growth and needs to expand its IT infrastructure to handle increased website traffic during seasonal sales. The company has a limited budget and prefers a solution that minimizes upfront costs while allowing it to scale resources as needed. Security is important, but they are willing to accept some shared infrastructure risks to save costs. Which cloud deployment model would BEST meet their needs?

  • Private Cloud
  • Public Cloud ✓
  • Community Cloud
  • Hybrid Cloud

Public cloud minimizes upfront costs, scales on demand, and accepts shared infrastructure risk -- the exact trade-off profile described. Private cloud is too costly; community cloud requires multi-org coordination; hybrid adds management complexity not warranted here.

Q2. Which of the following BEST describes the Platform as a Service (PaaS) cloud computing service model?

  • PaaS delivers everything a developer needs to build an application on the existing cloud infrastructure. ✓
  • PaaS delivers software applications to the client either over the internet or on a local area network.
  • PaaS stores and provides data from a centralized location without the need for local collection and storage.
  • PaaS delivers infrastructure to the client, such as processing, storage, networks, and virtualized environments.

PaaS provides infrastructure plus development tools for building, testing, and deploying applications. Delivering finished apps over a network is SaaS; raw infrastructure only is IaaS; centralized data storage describes cloud storage/SaaS.

Q3. For security reasons, an organization needs to ensure that its information is isolated and managed only by its employees. What cloud model should this organization adopt?

  • Public
  • Community
  • Hybrid
  • Private ✓

Private cloud is exclusively owned and managed by a single organization, ensuring only its own employees have access. Public shares infrastructure with all tenants; community shares among multiple orgs; hybrid still includes a public component.

Q4. Which of the following BEST describes a community cloud implementation?

  • Designed to be shared by several organizations ✓
  • Designed to be used by a single organization
  • Designed to be a combination of public and private cloud resources
  • Designed to be accessed by the general public

Community cloud is shared among multiple organizations with common concerns (e.g., regulatory compliance, security policies). Single org = private; public + private combination = hybrid; general public access = public.

Q5. Which of the following cloud computing solutions delivers software applications to a client either over the internet or on a local area network?

  • PaaS
  • DaaS
  • IaaS
  • SaaS ✓

SaaS delivers ready-to-use software applications over the internet or LAN with no local installation required. PaaS provides a development environment; DaaS delivers a full virtual desktop; IaaS delivers raw infrastructure.

Q6. A law firm is transitioning to a cloud-based infrastructure to ensure minimal downtime for its critical legal applications. The firm has strict requirements for maintaining service availability, as even a few minutes of downtime could result in significant financial and reputational losses. Which of the following cloud features would BEST meet the firm's need for high availability?

  • Five Nines (99.999%) availability ✓
  • Scalability through horizontal scaling
  • Shared resource pooling for cost efficiency
  • Rapid Elasticity for handling demand changes

Five Nines means roughly 5 minutes of downtime per year, directly addressing the strict uptime requirement. Horizontal scaling addresses load, not uptime; resource pooling targets cost; rapid elasticity handles demand fluctuation, not availability.

Q7. A network technician configures a foundational cloud setup that will allow the developers to start all application development using a standardized server and database setup. What type of cloud service model is the technician configuring?

  • SaaS
  • PaaS ✓
  • IaaS
  • DaaS

A standardized server and database environment for application development is the definition of PaaS. SaaS delivers finished apps; IaaS delivers raw infrastructure with no development tooling; DaaS delivers virtual desktops.

Q8. Google Cloud, Amazon Web Services, and Microsoft Azure are some of the most widely used cloud storage solutions for enterprises. Which of the following factors prompt companies to take advantage of cloud storage? (Select two.)

  • Need for a storage provider to manage access control
  • Need for a platform to develop applications
  • Growing demand for storage ✓
  • Need for software to manage enterprise applications
  • Need to bring costs down ✓

Growing storage needs and cost reduction are the primary drivers for cloud storage adoption - it eliminates hardware purchases and offers tiered pricing. Access control management is a security concern; developing applications describes PaaS; managing enterprise apps describes SaaS.

Q9. A global e-commerce company is experiencing delays in file access for its employees located in different regions. The company uses a cloud file storage solution but has noticed that employees in regions far from the primary datacenter experience slower access times. After analyzing the situation, the IT team identifies that the current solution does not utilize replication or Content Delivery Networks (CDNs). Which action should the company take to resolve the issue?

  • Restrict file access to employees located near the primary datacenter
  • Switch to an on-premises file storage solution for all employees
  • Implement file replication across multiple datacenters and use CDNs ✓
  • Increase the storage capacity of the primary datacenter

The scenario identifies the exact problem: no replication or CDNs. CDNs store files closer to download locations; replication across datacenters ensures fast regional access. Restricting access ignores remote users; on-premises remains centralized; adding capacity at one site does not reduce latency for remote employees.

Q10. A cloud administrator configures a cloud instance to increase its resources during times of high utilization and decrease its resources when peak utilization times end. What cloud characteristic does this represent?

  • HA
  • Rapid elasticity ✓
  • Scalability
  • Metered utilization

Rapid elasticity is the ability to automatically scale resources up during high demand and back down when demand drops. HA refers to minimizing downtime; scalability describes general growth capacity without implying automatic scale-down; metered utilization is a billing model, not a resource adjustment characteristic.
