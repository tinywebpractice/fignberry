Exercise Overview

CompTIA A+ Core 1 (220-1201) Exam Objective: 4.2 Summarize cloud computing concepts.

Goal: Identify core differences between IaaS, PaaS, and SaaS; provide real-world examples; and determine practical applications in computer networks and business environments.

Cloud Service Model Comparison

IaaS PaaS SaaS
What the provider delivers Raw compute, storage, and networking infrastructure Infrastructure plus development tools, databases, and runtime environments Fully built and managed software applications
What the customer manages OS, middleware, apps, data Application code, data, security of the app Data and user access only
Key benefits Maximum control and flexibility; no physical hardware cost Accelerates development; no infrastructure setup required No installation or maintenance; accessible from any device
Best for IT teams needing custom environments; startups scaling infrastructure Development teams building and deploying applications End users and businesses needing ready-to-use software
Examples AWS EC2, Google Compute Engine Google App Engine, Microsoft Azure App Service Microsoft 365, Dropbox

Real-World Examples

AWS EC2 (IaaS)
Provides on-demand virtual servers with configurable CPU, RAM, and storage. Organizations use EC2 to host websites, run batch processing jobs, and build custom server environments without owning physical hardware. Aligns with IaaS because the customer controls the OS and everything above it.
Google Compute Engine (IaaS)
Google's scalable virtual machine service. Used by enterprises to run large workloads and migrate on-premises infrastructure to the cloud. The customer manages OS configuration, middleware, and applications.
Google App Engine (PaaS)
A fully managed platform for deploying web applications. Developers write and upload code; Google handles servers, scaling, and availability. Aligns with PaaS because infrastructure management is abstracted away, letting developers focus on the application.
Microsoft Azure App Service (PaaS)
Hosts web apps, REST APIs, and mobile backends on Azure infrastructure. Supports multiple languages and frameworks. Developers deploy code without configuring underlying VMs or networking.
Microsoft 365 (SaaS)
Delivers Word, Excel, Outlook, Teams, and other productivity tools over the internet on a subscription basis. No installation required. Used by organizations of all sizes to support communication and document collaboration.
Dropbox (SaaS)
Cloud file storage and synchronization service. Files are accessible from any device and can be shared with collaborators. The provider manages all infrastructure, storage, and the application itself.

Summary

IaaS, PaaS, and SaaS represent increasing levels of abstraction in cloud service delivery. IaaS gives organizations the most control by providing raw infrastructure, making it ideal for IT teams that need to configure custom environments or migrate existing workloads. PaaS removes infrastructure management from the equation and lets development teams focus entirely on writing and deploying application code, significantly reducing time to deployment. SaaS delivers finished, ready-to-use applications over the internet, requiring no setup from the end user and making it the most accessible model for businesses and individuals. The right model depends on how much control an organization needs versus how much management overhead it wants to offload to the provider.
