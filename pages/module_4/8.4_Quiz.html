Q1. Which term refers to a software implementation of a computer system that executes programs like a physical machine?

  • Virtual machine ✓
  • Hypervisor
  • Workload management
  • Physical host

A virtual machine (VM) is a software implementation of a computer system that runs programs just like a physical machine, with its own allocated CPU, RAM, storage, and network access. The hypervisor creates and manages VMs; the physical host is the hardware the hypervisor runs on.

Q2. Which of the following BEST describes the Platform as a Service (PaaS) cloud computing service model?

  • PaaS delivers everything a developer needs to build an application on the existing cloud infrastructure. ✓
  • PaaS delivers software applications to the client either over the internet or on a local area network.
  • PaaS stores and provides data from a centralized location without the need for local collection and storage.
  • PaaS delivers infrastructure to the client, such as processing, storage, networks, and virtualized environments.

PaaS provides infrastructure plus development tools, databases, and runtime environments for building and deploying applications. Delivering finished apps over a network is SaaS; raw infrastructure only is IaaS; centralized data storage describes cloud storage/SaaS.

Q3. Which of the following BEST describes a community cloud? (Select two.)

  • Designed to be shared by several organizations ✓
  • Provides a combination of cloud resources from different service providers.
  • Commonly hosted externally by a third party ✓
  • Access is granted only to the users within a single organization.
  • Platforms, applications, and storage are made available to the general public.

Community cloud is shared among multiple organizations with common concerns and is commonly hosted by a third-party provider. Combining resources from different providers describes multicloud; single-org access is private cloud; general public access is public cloud.

Q4. Your company currently has an on-premises cloud solution that provides services to its employees. However, the company would like to begin offering some services to the public from the cloud. Which of the following cloud computing solutions would BEST meet your company's new cloud computing requirements?

  • Community cloud
  • Private cloud
  • Hybrid cloud ✓
  • Public cloud

Hybrid cloud combines private and public cloud elements. The company keeps its existing on-premises private cloud for employees while extending to a public cloud for external services. Community cloud requires multi-org coordination; private cloud is internal only; switching entirely to public cloud would abandon the existing solution.

Q5. Which of the following cloud computing solutions delivers software applications to a client either over the internet or on a local area network?

  • PaaS
  • DaaS
  • IaaS
  • SaaS ✓

SaaS delivers ready-to-use software applications to clients over the internet or a LAN with no local installation required. PaaS provides a development environment; DaaS delivers a full virtual desktop; IaaS delivers raw infrastructure.

Q6. A mid-sized marketing agency is looking to improve collaboration among its remote teams. They want a solution that allows team members to work on the same documents simultaneously, track changes, and ensure that files are always accessible from multiple devices. Additionally, they want to ensure that the solution provides fast access to files for team members located in different regions. Which cloud file storage solution feature would BEST meet their needs?

  • Cloud storage with limited access to mobile devices
  • Single datacenter file storage with no replication
  • Automated file synchronization with change tracking and commenting ✓
  • On-premises file storage with manual synchronization

Automated cloud file sync with change tracking and commenting directly satisfies all requirements: simultaneous collaboration, change tracking, multi-device access, and regional availability via CDN and replication. The other options either restrict access, lack replication, or require manual processes incompatible with real-time collaboration.

Q7. You are reviewing the security setup of a client-side virtualization environment at a law firm. During your analysis, you notice: the hypervisor is not updated regularly; guest OSes are configured with unrestricted network access; snapshots of VMs are stored on a shared drive accessible to all employees. Which of the following actions would most effectively address the ROOT cause of potential security vulnerabilities in this environment?

  • Limit the number of guest OSes running simultaneously to reduce resource strain.
  • Regularly update the hypervisor and host OS to patch known vulnerabilities. ✓
  • Implement access controls to restrict who can access VM snapshots on the shared drive.
  • Disable network access for all guest OSes to prevent external threats.

The hypervisor is the foundation of the entire virtual environment. An unpatched hypervisor is the root vulnerability -- if compromised, all guest OSes are exposed regardless of other controls. The other issues are misconfigurations that should also be addressed, but patching the hypervisor resolves the root cause.

Q8. What is another name for virtual machines?

  • Guest operating systems ✓
  • Sandbox
  • Hypervisors
  • Host machines

Virtual machines are referred to as guest OSes because they run inside the hypervisor on top of the host. The hypervisor creates and manages VMs; the host machine is the physical hardware; a sandbox is an isolated testing environment, not a synonym for VMs in general.

Q9. You are tasked with setting up a client-side virtualization workstation to run multiple guest operating systems for software testing. The host machine has a CPU without virtualization extensions enabled, 8 GB of RAM, and 500 GB of storage. Which of the following actions should you take first to ensure optimal virtualization performance?

  • Install a 64-bit hypervisor to support 64-bit guest OSes.
  • Enable Intel VT-x or AMD-V in the system firmware. ✓
  • Increase the storage capacity to 1 TB.
  • Upgrade the system memory to 16 GB.

Hardware virtualization extensions (Intel VT-x or AMD-V) must be enabled in BIOS/UEFI before the hypervisor can properly manage guest OSes. This is the prerequisite for all other steps. Installing a hypervisor without extensions enabled will result in poor performance or failure; storage and RAM upgrades may help later but do not address the identified blocking issue.

Q10. As the network engineer for a large financial institution, you have been given the responsibility to provide a new financial desktop to the financial advisors in all company branch offices. Requirements: it must be a virtualization solution, hosted in the cloud by a third party, and must run on a tablet. Which of the following virtualization types BEST meets your desktop software requirements?

  • Type 2 hypervisor
  • VDI ✓
  • Type 1 hypervisor
  • Container virtualization

VDI (Virtual Desktop Infrastructure) delivers a virtualized desktop hosted in the cloud by a third party, accessible from any device including tablets -- matching all three requirements. Type 1 and Type 2 hypervisors are infrastructure components, not desktop delivery solutions. Container virtualization virtualizes application environments, not full desktops.
