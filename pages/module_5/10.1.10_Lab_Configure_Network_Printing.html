10.1.10 Lab: Configure Network Printing

Required Actions

  • On Office1, share the HP Photosmart Plus printer.
  • On Office2, add the shared HP Photosmart Plus printer.
  • On Office2, set the shared printer as the default printer.

Configuration Values

Setting Value
Printer to share HP Photosmart Plus
Share name HP Photosmart Plus
Client rendering option Render print jobs on client computers checked
Shared printer on Office2 HP Photosmart Plus on Office1

Step 1 - Share the Printer on Office1

  1. On the Office1 computer, right-click Start, then select Settings.
  2. Select Bluetooth & devices.
  3. Select Printers & scanners.
  4. Select HP Photosmart Plus.
  5. Select Printer properties.
  6. Select the Sharing tab.
  7. Select Share this printer.
  8. Use the default share name: HP Photosmart Plus.
  9. Verify that Render print jobs on client computers is checked.
  10. Select OK.

Step 2 - Add the Shared Printer on Office2

  1. From the top navigation area, select Floor 1 Overview.
  2. Under Office 2, select Office2.
  3. Right-click Start, then select Settings.
  4. Select Bluetooth & devices.
  5. Select Printers & scanners.
  6. Select Add device.
  7. For HP Photosmart Plus on Office1, select Add device.
  8. Wait for the printer to install.

Step 3 - Set the Default Printer on Office2

  1. Select HP Photosmart Plus on Office1.
  2. Select Set as default.
