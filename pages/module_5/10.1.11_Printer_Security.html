10.1.11 Printer Security

User Authentication

Restricts print job submission to authorized accounts only. In Windows, configure permissions via the Sharing and Security tabs in Printer Properties.

Local authentication
Usernames and passwords stored directly on the printer.
Network authentication
Printer communicates with a directory server (e.g., Active Directory) to verify users.

Secured Print and Badging

Secured print holds a job on the device until the user authenticates at the printer, preventing confidential output from sitting unattended in the output tray.

Authentication Method How It Works
PIN entry User enters a password or code on the device control panel to release the job.
Badging Device has a smart card reader; user presents their ID badge to release the job.
  • Can be set as a default or configured per job.
  • Cached jobs are deleted after a time limit if not released.
  • Device may require additional memory or storage to cache encrypted print jobs.

Audit Logs

Print servers and print devices can log each job, recording which user printed what document and from which device. Useful for tracking missing documents or unauthorized information release. Logs generated on the device can be forwarded to a centralized server using syslog.
