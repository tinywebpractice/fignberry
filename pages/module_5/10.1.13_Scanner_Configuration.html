10.1.13 Scanner Configuration

Overview

Multi-function devices (MFDs) combine printing, scanning, copying, and faxing. Scanners create digital bitmap files from physical flat objects (documents, receipts, photos). Optical character recognition (OCR) software can convert scanned text into editable documents.

Scanner Types

Flatbed Scanner
Object is placed on a glass surface; a bright light shines on it. Mirrors reflect the image onto a lens, which splits it into RGB via a prism or focuses it onto imaging sensors with color filters. Output is a bitmap file.
Automatic Document Feeder (ADF)
Paper is passed over a fixed scan head. Efficiently scans multi-page documents without manual page placement.

Network Scan Services

An MFD or standalone scanner can be configured as a network device and directed to deliver scan output to various destinations:

Scan Destination How It Works Requirements
Scan to Email Scan is sent as an email attachment. MFD must be configured with the IP address of an SMTP server; SMTP server typically authenticates the user before sending.
Scan to SMB (Server Message Block) Scan is saved to a shared network folder. MFD must be configured with the file server path and share name; users must have write permissions to the share.
Scan to Cloud Scan is uploaded to a cloud storage service (e.g., OneDrive, Dropbox). MFD offers preset options or custom templates; users authenticate to their cloud account through the scan dialog.
