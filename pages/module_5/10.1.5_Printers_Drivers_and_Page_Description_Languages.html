10.1.5 Printer Drivers and Page Description Languages

Printer Drivers

Printer drivers serve as the interface between the print device and the OS, enabling WYSIWYG output. Each client on a network must have a suitable driver installed for the printer it uses. 64-bit OSes require 64-bit drivers -- many older printers are unusable because vendors never released 64-bit versions.

Driver installation is typically automatic via Plug and Play (PnP). When a driver is not available through Windows Update, download it from the vendor's website, extract it to a local folder, and use the Have Disk option in the Add Printer Wizard to install it manually.

Page Description Languages (PDLs)

A PDL converts print commands from applications into a raster file -- a dot-by-dot description of where ink is placed. PDLs support:

  • Scalable fonts: Vector-based (TrueType, OpenType); can be resized without quality loss. All Windows printers support these.
  • Vector graphics: Describe how lines are drawn rather than storing pixel-by-pixel data.
  • Color printing: Uses the CMYK (cyan, magenta, yellow, black) color model. Differs from RGB used by displays. "K" stands for "key" (black).

PDL Comparison

PDL Developer Strengths Weaknesses Best For
PostScript (PS) Adobe Device-independent; consistent output across devices Slower than PCL/XPS Graphic design, desktop publishing, brochures/posters
PCL (Printer Control Language) HP Fast processing; widely supported Output may vary by printer model High-volume office text printing
XPS (XML Paper Specification) Microsoft Better Microsoft app integration; fast in some cases Less universal compatibility than PCL/PostScript Windows-centric environments

A single print device can support more than one PDL. The correct driver must match the desired PDL -- select from Add Printer Wizard or use Have Disk with the extracted vendor driver.
