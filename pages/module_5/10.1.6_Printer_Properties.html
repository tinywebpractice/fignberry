10.1.6 Printer Properties

Overview

Each logical printer object has default configuration settings managed through its driver or app. In Windows, printers are managed via Settings > Devices > Printers & Scanners, where you can open the queue, manage settings, or remove the device.

Windows provides two distinct configuration dialogs for a local printer: Printer Properties and Printing Preferences.

Printer Properties vs. Printing Preferences

Dialog Scope Key Settings
Printer Properties Printer object and hardware configuration Update driver, change port, sharing and permissions, install/configure duplex unit or finisher unit, set default paper types per tray, printer memory, font substitution, job separator
Printing Preferences Default job-level settings for print output Paper size, orientation, quality, color, duplex mode per print job

Printer Properties - Device Settings Tab

The Device Settings tab exposes hardware-level installable options. Example settings from the HP LaserJet 200 MFP:

  • Form to Tray Assignment: Maps paper sizes to specific trays (e.g., Printer auto select, Manual Feed, Tray 1 - all set to A4).
  • Font Substitution Table / External Fonts: Controls font handling at the device level.
  • Installable Options: Automatic Configuration, Printer Status Notification, Allow Manual Duplexing, Printer Memory, Job Separator.

The About tab contains driver version info, vendor details, and links to support and troubleshooting resources.
