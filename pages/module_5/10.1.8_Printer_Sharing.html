10.1.8 Printer Sharing

Sharing Models

Integrated print server
Printer connects directly to the network without requiring a server computer. Clients install via vendor tools, which discover the printer by IP, hardware address, and hostname.
Public printer
No access controls - any guest can print. Modern implementations typically add some security such as network segmentation, user authentication, or a dedicated guest Wi-Fi network.
Windows print server (shared printer)
Any Windows computer with an installed printer can share it. The print server connects to the printer via USB or network and enforces permissions so only authenticated users can submit jobs.

Windows Print Server Configuration

Configure sharing via Printer Properties > Sharing tab. Key options:

  • Share this printer - enables the share and sets the share name (network-visible name).
  • Render print jobs on client computers - offloads rendering from the server to the client.
  • Additional Drivers - install x86 (32-bit) and/or x64 (64-bit) drivers so clients on different Windows architectures can download the correct driver automatically when connecting.

Driver type notes:

  • Type 2 - requires specific driver versions per Windows release.
  • Type 3 - add x86/x64 variants for mixed-architecture networks.
  • Type 4 (Windows 10+) - print class driver framework; one driver works with multiple devices. Client can pull the driver from Windows Update instead of the print server.

Connecting to a Shared Printer (GUI)

File Explorer > Network > [server name] > right-click the printer > Connect. Requires appropriate permissions.

PowerShell Printer Management

Cmdlet Purpose Key Switches
Set-Printer Modify properties of an existing printer -Name - local printer name
-Shared $true/$false - enable/disable sharing
-ShareName - network-visible share name
-RenderPrintJobsOnClient $true/$false - client ($true) or server ($false) renders jobs
Add-Printer Connect a computer to an existing shared network printer -ConnectionName \\ServerName\SharedPrinterName (UNC path)
Set-DefaultPrinter Set the default printer -Name - local or network printer name
