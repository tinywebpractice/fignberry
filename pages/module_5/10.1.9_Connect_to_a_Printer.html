10.1.9 Connect to a Printer

Steps to Connect and Set a Default Printer (Windows)

  1. Open Settings: Start > Settings > Bluetooth & Devices > Printers & Scanners.
  2. Disable automatic default printer management: Turn off "Let Windows manage my default printer" to allow manual default selection.
  3. Add the network printer: Select Add Device. When the printer appears in the list, select Add Device again to install it.
  4. Set as default: Select the newly installed printer and choose Set as Default. The printer status updates to "Default."
