10.5.1 Connecting Printers

USB Connection

USB is the most common local connection method. The USB-B connector plugs into the printer; USB-A connects to the computer. Driver installation order matters: always consult the printer manual, as some older printers require the driver to be installed before connecting the USB cable. Connecting first can cause the OS to load an incorrect driver, which must then be fully uninstalled before the correct one can be applied.

Ethernet Connection

Many modern printers include a built-in NIC for direct connection to a TCP/IP network. An IP address is required; it can be assigned via DHCP or set statically.

  • Static IP is preferred for network printers on large networks: the address does not change, allowing registration in DNS with a fully qualified domain name (FQDN) so clients can resolve the printer by name
  • DHCP can cause issues if the lease changes and DNS is not updated, making the printer unreachable by name
  • Local configuration utilities (often from the manufacturer) allow management of the printer from a connected computer, including ink/toner status monitoring
  • Network management suites support larger deployments: device monitoring, print permissions, and queue control across multiple printers

Bluetooth Connection

Bluetooth printers support direct printing from nearby devices. Effective range is approximately 30 feet. Multiple computers can discover and print to the same Bluetooth printer.

Wi-Fi Connection

Wi-Fi printers support two modes:

Infrastructure mode
The printer associates with a wireless access point and joins the network. All devices on the network can print to it. This is the standard and recommended mode.
Wi-Fi Direct
A device connects directly to the printer without going through an access point, similar to an ad hoc link. Less common; bypasses normal network infrastructure.

Printer Drivers

  • Drivers provide OS-level communication and unlock printer features; keep them current
  • High-end and network printers may also have firmware updates for new functionality and security patches
  • If a new driver causes problems, roll it back via Device Manager
  • Check the manufacturer's website for compatibility notes before applying major OS or driver updates

Sharing Printers

Method How it works Best for
Built-in print server Printer has an onboard server; manages its own queue and accepts jobs directly over the network Most deployments; simplest setup
Computer as print server Printer connects via USB to a host computer; that computer manages the queue and shares the printer to other network users Older printers without network capability; small networks

Printer Preferences

Accessible by right-clicking the printer object in the OS. Common configurable options include:

  • Paper orientation (portrait/landscape)
  • Paper source/feeder selection
  • Duplex (double-sided) printing
  • Print quality settings
  • Specialty media handling (envelopes, labels, etc.)

Available options vary by manufacturer and installed driver.
