9.1.4 Lab: Manage Mobile Devices

Required Actions

  • Connect the iPad to the CorpNet Wi-Fi network.
  • Turn on the iPad's Bluetooth.
  • Configure the iPad's VPN settings for future use.

Configuration Values

Setting Value
Wi-Fi network CorpNet
Wi-Fi password @CorpNetWeRSecure!&
VPN protocol PPTP
VPN description CorpNet VPN
VPN server 198.10.20.12
VPN account akimbly

Step 1 - Connect to CorpNet Wi-Fi

  • On Arlene's iPad, select Settings.
  • From the left menu, select Wi-Fi.
  • From the right pane, slide the Wi-Fi button to the on position.
  • Under NETWORKS, select CorpNet.
  • In the Password field, enter @CorpNetWeRSecure!&.
  • Select Join.

Step 2 - Turn on Bluetooth

  • From the Settings pane, select Bluetooth.
  • From the right pane, slide the Bluetooth button to the on position.

Step 3 - Configure the VPN

  • From the Settings pane, select General.
  • From the right pane, select VPN.
  • Select Add VPN Configuration.
  • Select PPTP.
  • For Description, enter CorpNet VPN.
  • For Server, enter 198.10.20.12.
  • For Account, enter akimbly.
  • Select Save.

Important: The Wi-Fi password ends with an ampersand: @CorpNetWeRSecure!&.
