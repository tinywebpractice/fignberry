Wi-Fi on Mobile Devices

  • All modern laptops, smartphones, and tablets include a Wi-Fi radio
  • Devices default to Wi-Fi when available; signal strength shown in the status bar
  • Each wireless radio (Wi-Fi, cellular, Bluetooth, NFC, GPS) can be toggled independently via iOS Control Center (swipe up) or Android notification shade (swipe down)
  • Settings menu allows selecting a network or manually connecting to a hidden SSID

Airplane Mode

  • Disables some or all wireless features: cellular data, Wi-Fi, GPS, Bluetooth, and NFC
  • Used to comply with airline restrictions on radio-based devices
  • Some carriers require devices fully powered off during take-off and landing
  • On some devices, individual services (e.g., Wi-Fi) can be selectively re-enabled while airplane mode remains active

Wi-Fi Antenna Connector/Placement

On mobile devices, the Wi-Fi antenna consists of two wires connected to the Wi-Fi chip that run around the edges of the device display, maximizing signal reception.
