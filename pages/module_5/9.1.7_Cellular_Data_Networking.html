Cellular Data Networking

Cellular data networking connects a device to the Internet via its cellular radio and network provider. Data rates depend on the technology supported by both the device and the cell tower. Usage charges apply, and can be especially high during international roaming.

Generation Technology Max Download Speed (Theoretical)
3G 3rd Generation ~7.2 Mbps
4G LTE (Long-Term Evolution) ~300 Mbps
5G 5th Generation ~10 Gbps

Note: All speeds above are theoretical maximums. Actual speeds vary based on network coverage, signal strength, device capabilities, and network congestion.

SIM and eSIM

SIM (Subscriber Identity Module)
Small physical card that identifies the device on the mobile network. Enables calls, texting, and mobile data. Tied to the device's phone number; transferable to a new phone. Can store contacts and a limited number of texts, though data is typically stored in device memory or cloud services.
eSIM (Embedded SIM)
A chip embedded inside the device that performs the same functions as a physical SIM. Provisioned and activated over the air for faster setup. Supports multiple eSIM profiles on a single device, allowing multiple phone numbers or data plans simultaneously.

Enabling and Disabling Cellular Data

  • Toggle cellular data via the notification shade or Settings menu
  • Settings allow setting data usage warnings and caps
  • Individual apps can be restricted from using cellular data
  • Dual-SIM handsets allow choosing which SIM to use for data networking
  • International roaming can be enabled or disabled via Mobile Data Options
