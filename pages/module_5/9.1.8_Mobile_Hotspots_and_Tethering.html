Tethering

Tethering connects another device (e.g., a laptop) to a mobile device to share its cellular data connection.

Tethering Method Description
USB Tethering Device connected via USB cable; typically the most stable and fastest method
Bluetooth Tethering Shares connection over Bluetooth; lower speed than USB or Wi-Fi
Wi-Fi Hotspot Device broadcasts a Wi-Fi access point; other devices connect wirelessly as they would to any AP

Mobile Hotspot Configuration

Tethering over Wi-Fi is called a hotspot. To enable it, configure the following access point settings:

  • Network name (SSID)
  • Security type (WPA2 PSK recommended; password minimum 8 characters)
  • AP band (e.g., 2.4 GHz)

Once configured, other devices connect to the hotspot the same way they connect to any Wi-Fi access point.
