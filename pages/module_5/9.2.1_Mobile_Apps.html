Mobile Apps Overview

An app is an installable program that extends the functionality of a mobile device. Apps must be written and compiled for a specific mobile OS - an iOS app cannot be directly installed on Android. Developers must produce a separate version for each platform.

iOS vs. Android App Ecosystem

iOS Android
Distribution Apple App Store only (walled garden model) Google Play Store and third-party stores (e.g., Amazon App Store)
App Approval Apps must be submitted to and approved by Apple before release More relaxed; apps available without Apple-style mandatory review
Security Model Walled garden prevents malware and faulty code More open; greater risk from third-party sources
Development IDE Xcode (macOS only) Android Studio (Linux, Windows, macOS)
Language Swift Java-based
Commercial Models Free, free with in-app purchases, or paid

App Permissions

  • On both iOS and Android, apps run in a sandbox and only have privileges granted by the user
  • Apps prompt the user when requesting permissions (e.g., camera, microphone, contacts, storage)
  • Permissions can be granted, denied, or revoked at any time via the app's Settings page
