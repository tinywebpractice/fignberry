Email Configuration Methods

Autodiscover
The mail service publishes special DNS records identifying how the account for a domain should be configured. To connect, select the provider (Exchange, Gmail, Yahoo, Outlook.com, iCloud, etc.) and enter email address and credentials -- no manual server entry needed.
Manual Configuration
Used when the provider does not support autodiscovery (ISP or corporate mail gateway). Select "Other" and enter server addresses manually.

Manual Configuration Fields

Setting Details
Incoming mail server FQDN or IP of the IMAP or POP3 server. Use IMAP for multi-device access (mail stays on server); use POP3 to download mail to the device and remove it from the server.
Outgoing mail server FQDN or IP of the SMTP server
TLS Enable to encrypt credentials and data. Required when connecting over public/open Wi-Fi. Only available if the mail provider supports it.
Ports Leave at defaults for IMAP, POP3, and SMTP unless the provider uses custom ports

Exchange ActiveSync (EAS)

  • Microsoft Exchange uses its own proprietary protocol (EAS), not IMAP or POP3 (though it can support them)
  • Manual Exchange ActiveSync setup requires: email address, username, host address (from Exchange admin), password, TLS option, and optionally a domain field (usually left blank)
  • If a single "Domain\Username" field is present, prefix the email address with a backslash: \me@company.com
