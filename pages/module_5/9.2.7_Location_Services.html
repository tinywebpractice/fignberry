Location Services

Geolocation uses network attributes to identify or estimate the physical position of a device. Location data is highly personal and apps must be explicitly granted permission to access it.

System How It Works Notes
Global Positioning System (GPS) Determines latitude and longitude using signals from orbital satellites via a GPS sensor Not all mobile devices include a GPS sensor
Indoor Positioning System Triangulates location based on proximity to cellular radio towers, Wi-Fi access points, and Bluetooth/RFID beacons Used indoors or where GPS signal is unavailable
Magnetometer (optional) Measures magnetic field to determine compass direction Fitted on some devices; enables more accurate compass readings

Configuring Location Permissions

  • iOS: Settings → Privacy → Location Services; per-app permissions configurable individually
  • Android: Settings → Location → App access to location; also controls Wi-Fi and Bluetooth scanning, Google Location Accuracy, and carrier location access
  • Apps must request and receive user permission before accessing location data
