9.3.4 Disk Upgrades and Replacement

Data Strategies Before Upgrading

A laptop typically supports only one internal mass storage device, so upgrading the fixed disk requires a plan for existing data. Two approaches:

Migration
Use backup software to create an image or clone of the old drive on USB media, then restore it to the new drive. System images are technology-neutral (an HDD image can apply to an SSD). The new drive must be the same size or larger, unless a cloning tool that can shrink the source image is used. A disk enclosure can connect the new SSD as an external drive so the image is migrated directly before swapping drives.
Replacement
Back up user data only from the old drive. Install the new drive, reinstall the OS and apps, then restore user data from backup.

Laptop HDD Form Factors

  • Laptop HDDs are usually 2.5" form factor; sometimes 1.8".
  • 2.5" magnetic HDDs are slower (typically 5400 rpm) and lower capacity than 3.5" desktop drives.
  • Z-height variants within 2.5": standard = 9.5 mm; thin = 7 mm; ultrathin = 5 mm.
  • Magnetic drives use SATA data and power connectors; connectors mate directly to the drive bay port (no cable). 1.8" bays may require micro SATA (uSATA / uSATA).

SSD Interfaces

SSDs can use SATA connectors but are more likely to use an adapter card interface:

Interface Bus Max Speed Notes
mSATA (Mini-SATA) SATA 6 Gb/s Resembles Mini PCIe cards but not physically compatible with Mini PCIe slots
M.2 PCIe Much higher than SATA Available lengths: 42, 60, 80, 110 mm; most common laptop size is 80 mm (M.2 2280)

M.2 form factor notation is xxyy: xx = width in mm, yy = length in mm. Example: 2280 = 22 mm wide, 80 mm long.
