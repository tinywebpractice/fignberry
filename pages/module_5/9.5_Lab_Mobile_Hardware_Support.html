9.5 Lab: Mobile Hardware Support

Required Actions

  • Turn off airplane mode and connect the iPad to the CorpNet wireless network.
  • Turn off Bluetooth on the iPad.
  • Turn on the iPad passcode and configure passcode security options.
  • Configure VPN settings on the iPad for future use.
  • Install the fastest USB wireless adapter on the Office2-Lap computer.
  • Configure the Office2-Lap power-saving options.

Step 1 - Connect the iPad to CorpNet

  • On the iPad, select the button at the bottom of the iPad to view the screen.
  • Select Settings.
  • From the left pane, slide the Airplane Mode button to the off position.
  • Select Wi-Fi.
  • From the right pane, slide the Wi-Fi button to the on position.
  • Under NETWORKS, select CorpNet.
  • In the Password field, enter @CorpNetWeRSecure!&, and then select Join.

Step 2 - Turn Off Bluetooth

  • From the Settings pane, select Bluetooth.
  • From the right pane, slide the Bluetooth button to the off position.

Step 3 - Turn On Passcode

  • From the Settings pane, select Touch ID & Passcode.
  • Select Turn Passcode On.
  • Enter 1542 and select Next.
  • Re-enter 1542 and select Done.

Step 4 - Configure Passcode Security

  • Select Require Passcode.
  • Select After 15 minutes.
  • At the top, select Passcode Lock.
  • From the Touch ID & Passcode pane, slide the Erase Data button to the on position.
  • Select Enable.

Step 5 - Configure iPad VPN Settings

  • From the Settings pane, select General.
  • From the right pane, select VPN.
  • Select Add VPN Configuration.
  • Select PPTP.
  • For Description, enter Office2VPN.
  • For Server, enter 198.28.56.110.
  • For Account, enter mbrown.
  • Select Save.

Step 6 - Install the USB Wireless Adapter

  • From the top left, select Floor 1 Overview, then select Hardware under Office 2.
  • Switch to the Back view of the laptop.
  • Under Inventory, expand Networking Devices.
  • Drag the 802.11a/b/g/n/ac USB Adapter to an open USB port on the laptop.
  • Hover over inventory items as needed to verify the full adapter description before installing it.

Step 7 - Configure Power-Saving Options

  • Switch to the Front view of the laptop and click the screen.
  • Right-click Start and select Settings.
  • From the right, select Power & battery.
  • Select Screen and sleep.
  • For On battery power, turn off my screen after, select 10 minutes.
  • For When plugged in, put my device to sleep after, select 30 minutes.
  • For Power mode, select Best power efficiency.
  • Close the Settings app.

Important: The Wi-Fi password ends with an ampersand: @CorpNetWeRSecure!&. Install the 802.11a/b/g/n/ac USB Adapter because it is the fastest listed USB wireless adapter.
