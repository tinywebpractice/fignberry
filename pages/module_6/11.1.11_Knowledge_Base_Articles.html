11.1.11 Knowledge Base Articles

Why Knowledge Base Articles Matter

Knowledge base articles allow team members to perform operations they would not otherwise know how to do. They are especially critical when specialized knowledge exists in only one person and that person leaves the organization.

Real-World Example: Web Development Crisis

A web developer who managed all Azure web services left the company. Six months later the company website stopped working. No remaining team members had web development experience. Because the departing employee had written a knowledge base article documenting the entire process, the team was able to restore the site within an hour.

The issue turned out to be an Azure web app with a custom domain requiring a bound SSL certificate in .PFX format. The article documented every step: opening the web service in Azure, configuring the custom domain, retrieving the SSL certificate from the registrar (GoDaddy), and using OpenSSL on the command line to convert the certificate to the .PFX format required by Azure before uploading.

Building a Documentation Culture

Following this incident, the team established a policy requiring each employee to write knowledge base articles covering their specific functions, with emphasis on specialized or non-obvious tasks. Examples from the team's knowledge base include:

  • Creating a virtual machine and joining it to an Azure Managed Domain Service (for legacy applications) or performing an Azure domain join (for modern applications)
  • Creating a SharePoint list and building a Power App
  • Help desk basics for interns: connecting a computer using HDMI, DVI, and VGA ports

The key principle is that documentation should cover all levels of complexity, from advanced cloud architecture tasks down to the most basic hardware connection procedures, so that any team member can perform any function when needed.
