11.1.13 Lab: Create a Ticket

This is a CompTIA exercise. The activity involves creating a help desk ticket in the Issue Trax ticketing system to request installation of software the user cannot install themselves due to lacking local administrative rights.

Scenario

A new employee on a computer named Office1 needs the audio editor Audacity installed. Attempting to install it triggers a UAC prompt requiring administrator credentials. Since the user has not been granted local admin rights, a help desk ticket must be submitted requesting the installation.

Ticket Details

Field Value
Summary Need Audacity installed
Description User-written explanation of the need for Audacity (digital audio editor) for work tasks; installation blocked by UAC prompt requiring admin credentials not assigned to this account.
Contact Info 435-555-1234
Device Info HP Laptop/Win11
Priority High
Assignee Joshua Anderson
Due Date Tomorrow's date
Category Software

Steps

  • From Office1, open Issue Trax: Start, All apps, Issue Trax. Maximize the window.
  • Select New to create a new ticket.
  • Fill in all fields per the ticket details table above.
  • Select Save.
