11.1.1 Standard Operating Procedure

Policies, SOPs, and Guidelines

Policy
An overall statement of intent. Sets the organizational goal or requirement without specifying exact steps.
Standard Operating Procedure (SOP)
A step-by-step list of actions that must be completed for a given task to comply with policy. Most IT procedures should be governed by SOPs.
Guideline
Used where no formal procedure exists, either because the situation has not been fully assessed, the decision-making process is too complex for a fixed SOP, or to describe circumstances where deviation from an SOP is appropriate.

Typical SOP Examples

SOP Type Typical Tasks
Custom software installation Verify system requirements; validate download/installation source; confirm license validity; add to change control/monitoring; develop support and training documentation
New-user setup (onboarding) Identification and enrollment with secure credentials; allocation of devices; allocation of permissions and assignment to security groups
End-user termination (offboarding) Return and sanitize devices; release software licenses; disable account permissions and access
