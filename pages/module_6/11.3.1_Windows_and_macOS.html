11.3.1 Windows and macOS

OS Market Segments

Segment Purpose
Business client Client in a centrally managed business domain network; often called a workstation
Network Operating System (NOS) Runs servers in business networks
Home client Standalone use or workgroup networks in home or small office environments
Cell phone (smartphone) / Tablet Handheld devices with touch-operated interfaces

Note: "Workstation" is used in two senses - it can mean any business client PC, or (in hardware vendor terminology) a high-performance PC used for tasks such as graphic design, video editing, or software development.

Microsoft Windows

Windows covers all four market segments.

Product Segment Notes
Windows 10, Windows 11 Business client, Home client, Tablet Editions for both business workstations and home PCs; touch support for tablets and laptops; Windows smartphones discontinued
Windows Server 2019, 2022, 2025 NOS Optimized for server roles; shares underlying code and desktop interface with client versions

Apple macOS

  • Exclusively available on Apple-built hardware: Mac desktops, iMac all-in-ones, and MacBooks. Cannot be purchased or installed on non-Apple PCs.
  • Derived from a UNIX kernel with additional code for its graphical interface and system utilities.
  • Supports the Magic Trackpad; does not support touch screens.
  • Apple provides free periodic updates. Each release has specific hardware requirements; compatibility with older Mac models varies.
