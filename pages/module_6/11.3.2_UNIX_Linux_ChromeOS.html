11.3.2 UNIX, Linux, and Chrome OS

UNIX

Origin
Developed at Bell Laboratories in the late 1960s; "UNIX-systems" is a trademark for this OS family.
Architecture
Kernel/shell architecture - the kernel manages CPU, RAM, and I/O devices; the shell provides the user interface.
Portability
Can run on diverse hardware platforms from personal computers to mainframes, unlike Windows and macOS.

Linux

Created by Linus Torvalds. Open-source OS kernel derived from UNIX. Includes a shell command interpreter, desktop environment, and app packages. Available in numerous distributions (distros), each with its own package set and licensing model.

Distro Support / Licensing Model
SUSE Subscription-based
Red Hat Enterprise Linux (RHEL) Subscription-based
Ubuntu Free installation; paid enterprise support available
Fedora Community-supported
Debian Community-supported
Mint Community-supported
Arch Community-supported

Linux distro release models:

Standard Release
Uses versioning for updates; some versions offer long-term support (LTS).
Rolling Release
Updates are delivered as they become stable, with no version distinctions.

Linux use cases: desktop OS in schools and universities; dominant web server OS; widely used in smart appliances and Internet of Things (IoT) devices.

Chrome OS

Developer
Google. Proprietary OS derived from the open-source Chromium OS, which is based on Linux.
Hardware
Designed for specific devices: Chromebooks (laptops) and Chromeboxes (PCs). Targets budget and education markets.
Design focus
Built primarily for web applications. Relies on server-hosted software accessed via a browser, reducing the need for powerful client hardware.
Performance
Minimal environment reduces interference from other software or drivers, enhancing browser performance.
App support
Supports offline "packaged" apps; can also run Android and Linux apps.
