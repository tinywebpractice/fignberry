11.3.4 Windows File System Types

Overview

High-level formatting prepares a disk partition for use with an OS by creating a file system on it. Each OS is associated with specific file system types.

File System Comparison

File System Bits Max Volume Size Max File Size Key Use Cases Notable Limitations
NTFS 64-bit Up to 8 PB (8,000 TB) with latest Windows updates; theoretical max 16 EB Very large (volume-limited) Windows OS partition; additional partitions; Windows-used removable drives Not fully supported by non-Windows OSes; macOS can read but not write; Home editions lack dynamic disks and EFS
ReFS N/A Millions of TB Very large Specialized enterprise workloads requiring high availability, resiliency, and scalability Not the default for general users; NTFS remains predominant
FAT32 32-bit ~2 TB 4 GB minus 1 byte System partition (boot loader); removable drives and memory cards for cross-OS use No reliability or security features (no journaling, permissions, or encryption)
exFAT 64-bit 512 TB (recommended max) Very large Removable hard drives and flash media; cross-OS compatibility with large file support Supports access permissions but not encryption

NTFS Features

Journaling
Data written to an NTFS volume is re-read, verified, and logged. Bad sectors are marked and data relocated. Makes recovery after crashes and power outages faster and more reliable.
Snapshots
Volume Shadow Copy Service (VSS) creates read-only copies of files at given points in time, even if files are locked by another process. Supports file version history and backup operations.
Security
File permissions and ownership, file access audit trails, quota management, and Encrypting File System (EFS). Windows Home editions do not support dynamic disks or EFS.
POSIX Compliance
Supports case-sensitive naming, hard links, and other features required by UNIX/Linux applications. Windows preserves case but does not enforce case-sensitivity.
Indexing
Indexing Service creates a catalog of file and folder locations and properties to speed up searches.
Dynamic Disks
Allows space on multiple physical disks to be combined into volumes. Not supported on Windows Home editions.

ReFS Features

Resiliency
Detects and repairs corrupted files and data while the volume is online and in use, including in virtualized environments.
High Performance
Optimized for large data sets and workloads through configuration of two logical storage tiers.
Scalability
Supports millions of terabytes without impacting performance.
