11.3.5 Linux and macOS File System Types

Linux File Systems

File System Description Notes
ext4 Latest version of the extended (ext) file system; default for most Linux distros Better performance than earlier ext versions; supports journaling
XFS High Performance Scalable File System; introduced 1993; 64-bit journaling Default for Red Hat Enterprise Linux (RHEL); supported by other distros
VFAT (FAT/FAT32) Linux designation for FAT/FAT32 support Alternative to ext; useful for cross-OS removable media
NFS (Network File System) Protocol for mounting remote storage devices to the local Linux file system Allows a remote file resource to appear as if directly attached to the local system

Apple File System (APFS)

APFS is the proprietary file system used on Apple Mac workstations and laptops. It supports journaling, snapshots, permissions/ownership, and encryption.

Default File System by OS

OS Default File System
Windows NTFS
Linux (most distros) ext4
