11.3.7 Vendor Life-cycle Limitations

Life-cycle Phases

A vendor life cycle describes the policies and procedures an OS developer or device vendor uses to support a product. Policy specifics vary by vendor, but the following phases are typical:

Phase Description Updates / Upgrades
Public Beta Pre-release phase used to gather user feedback. Example: Microsoft Windows Insider Program provides access to early-release Windows versions and feature updates. Early/preview builds only
Supported Product is actively marketed. Vendor releases regular patches for critical security and operational issues, plus feature upgrades to expand OS functionality. Regular patches and feature upgrades; OS upgrade versions available
Extended Support Product is no longer commercially available but vendor continues issuing critical patches. Critical patches only; OS upgrades may or may not be available
End of Life (EOL) Product is no longer supported by the developer or vendor. No further security updates are issued. EOL systems in active use represent a critical security vulnerability. None

Note: Windows 10 reached end of life on October 14, 2025. Microsoft provides no free support or updates after this date.
