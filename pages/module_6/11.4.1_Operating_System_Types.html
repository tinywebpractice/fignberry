11.4.1 Operating System Types

Five Requirements of an Operating System

To qualify as an operating system, software must provide all five of the following:

Requirement Description
Communication with hardware Translates user instructions into commands that interact with physical hardware (storage, printers, peripherals, etc.)
User interface (UI) Provides either a graphical user interface (GUI) using images and clicks, or a command line interface (CLI) using typed commands
File system Creates and manages a default directory structure (home, pictures, videos, music, etc.) upon installation; users do not have to build it manually
Platform for applications Provides the environment in which applications run, giving them access to hardware resources; programs run inside the OS, not independently
Security Provides security mechanisms such as user accounts, password policies, and lockout policies; a modern addition to the original four core OS functions

Major Desktop / Computer OS Families

Microsoft Windows
Dominant desktop and server OS family; covers business client, home client, NOS, and tablet segments.
macOS
Apple's OS for Macintosh computers; UNIX-derived; exclusive to Apple hardware.
Linux
Open-source, UNIX-derived; widely used in system administration, servers, and IoT; available in many distributions.
UNIX
Developed by Bell Labs in the 1960s; multitasking and multi-user from its inception; primarily used on servers today; the foundation from which Linux and macOS are derived.

Mobile Operating Systems

Mobile OSes (iOS, Android) fulfill the same five OS requirements on smartphones and tablets: hardware communication, UI (touch-based), file system, app platform, and security. Mobile devices represent the most common way most users interact with the internet and digital resources.
