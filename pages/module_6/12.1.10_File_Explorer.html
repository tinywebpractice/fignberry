12.1.10 File Explorer

Overview

File Explorer (explorer.exe) is the Windows file management application. It allows users to open, copy, move, rename, view, and delete files and folders. It is often referred to simply as "Explorer."

System Objects (Left Navigation Pane)

System objects mediate access to data files and are displayed in File Explorer's left-hand navigation pane.

User account
Personal data folders belonging to the signed-in account profile.
OneDrive
Visible when signed in with a Microsoft account; shows files and folders in cloud storage.
This PC
Contains personal profile folders plus fixed disks and removable storage drives attached to the PC.
Network
Contains computers, shared folders, and shared printers available over the network.
Recycle Bin
Allows recovery of files and folders marked for deletion.

Drives and Folders

Within This PC, drives are identified by letters and optional labels. A drive can be:

  • A single physical disk or a partition on a disk
  • A shared network folder mapped to a drive letter
  • A removable disk

By convention: A: = floppy disk (rarely seen); C: = primary fixed disk partition containing the Windows installation.

Every drive contains a root directory, represented by the backslash (\). Example: the root of C: drive is C:\. Below the root is a hierarchy of subdirectories (folders), each of which can contain subfolders and files.

Typical Windows Directory Structure

PathDescription
C:\Root directory of the primary drive
C:\UsersProfile settings and data for all user accounts
C:\Program FilesInstalled 64-bit applications
C:\Program Files (x86)Installed 32-bit applications (64-bit Windows only)
C:\WindowsSystem root; contains drivers, logs, fonts, config files
C:\Windows\System32Core system and configuration files

System Files and Key Folders

Windows
The system root. Contains drivers, logs, add-in applications, system and configuration files (notably System32), and fonts.
Program Files / Program Files (x86)
Subdirectories for installed application software. On 64-bit Windows, Program Files (x86) stores 32-bit applications separately.
Users
Storage for user profile settings and data. Each user account has a named subfolder containing NTUSER.DAT (registry data), personal data subfolders, and hidden subfolders for application settings, favorites, shortcuts, and temp files.

File and Folder Management Operations

OperationMethodNotes
Create new folder Right-click in folder > New > Folder, then type name and press Enter
Copy a file Select file > Ctrl+C, navigate to destination > Ctrl+V Leaves original in place; places a copy at destination
Rename a file Right-click file > Rename, type new name
Delete a file Select file > Delete Sends to Recycle Bin; does not permanently remove
Restore from Recycle Bin Open Recycle Bin > right-click file > Restore Returns file to its original location
Empty Recycle Bin Right-click Recycle Bin on desktop > Empty Recycle Bin Permanently deletes all contents; frees disk space; icon changes to empty bin
