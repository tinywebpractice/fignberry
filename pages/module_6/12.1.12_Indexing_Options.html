12.1.12 Indexing Options

Overview

File search behavior is configured in two places: the Search tab of the File Explorer Options dialog, and the Indexing Options applet (Control Panel). Indexing Options allows you to define indexed locations and rebuild the index. Indexed locations can include folders and email data stores. A corrupted index is a common cause of search problems.

Indexing Options: Main Dialog

  • Displays the number of items currently indexed and indexing status.
  • Modify: Add or remove indexed locations (folders, email stores).
  • Advanced: Opens the Advanced Options dialog.
  • Default index storage location: C:\ProgramData\Microsoft

Key Troubleshooting Point

A corrupted index is a common cause of file search failures. Use Advanced > Rebuild to delete and regenerate the index from scratch.
