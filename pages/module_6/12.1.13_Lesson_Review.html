12.1.13 Lesson Review

Question 1

How does the Windows 11 desktop improve accessibility and usability compared to the Windows 10 desktop?

  • By removing the notification area to simplify the interface
  • By introducing a touch-optimized Start menu
  • By eliminating the taskbar to maximize screen space
  • By providing better spacing for touch control and rounded corners

Windows 11's UI changes include better touch-friendly spacing between elements and rounded window corners, improving accessibility and usability. The notification area was not removed, the taskbar was not eliminated, and while the Start menu was redesigned it is not specifically described as "touch-optimized" in the context of this accessibility improvement.

Question 2

A user needs to access a hidden system file to troubleshoot an issue on their computer. They open File Explorer but cannot see the file in the directory. What should the user do to make the hidden file visible?

  • Open the Control Panel and enable "Show system files" under System Settings.
  • Use the Task Manager to locate and unhide the file.
  • Open File Explorer Options and enable the "Show hidden files, folders, and drives" option.
  • Right-click on the directory and select "Unhide System Files" from the context menu.

The View tab of File Explorer Options contains the "Show hidden files, folders, and drives" radio button under Hidden files and folders. There is no "Show system files" option under System Settings, Task Manager has no file visibility controls, and no "Unhide System Files" context menu option exists in Windows.

Question 3

Which of the following BEST describes the purpose of Indexing Options in Windows?

  • To configure user account permissions and security settings.
  • To adjust the display resolution and screen brightness.
  • To enable or disable system updates and patches.
  • To manage how and where Windows searches for files and folders.

Indexing Options defines which locations are indexed, allows rebuilding the index, and controls file type and advanced search settings. User account permissions are in User Accounts/Local Security Policy, display settings are in Display settings, and updates are managed by Windows Update.

Question 4

Which of the following options can be configured in the File Explorer Options in Windows?

  • Manage user accounts.
  • Adjust screen resolution.
  • Enable dark mode for File Explorer.
  • Hide extensions for known file types.

"Hide extensions for known file types" is a View tab setting in File Explorer Options. User accounts are managed in Control Panel or Settings > Accounts, screen resolution is a Display setting, and dark mode is configured in Settings > Personalization > Colors.

Question 5

A user is having difficulty navigating between multiple open applications on their Windows 10 computer. They want to quickly switch between program windows without using the mouse. Which of the following actions should the user take?

  • Use the keyboard shortcut Alt + Tab.
  • Press the Windows logo key to open the Start menu.
  • Right-click on the desktop and select "Switch Applications."
  • Open the Control Panel and navigate to "Task Manager."

Alt+Tab is the standard Windows keyboard shortcut for cycling through open application windows without the mouse. The Windows key opens the Start menu, no "Switch Applications" context menu option exists, and Task Manager is not located in Control Panel nor used for window switching.

Question 6

A user reports that their computer is not functioning as expected. The text on their screen is too small to read, the clock is displaying the wrong time, and when they close the lid of their laptop, the system does not turn off, causing the battery to drain. Which of the following actions would BEST address all of the user's issues using the appropriate Windows 10 administrative interface?

  • Use the Windows Settings app to adjust the Ease of Access settings, update the system date and time, and modify power and sleep settings.
  • Use the Command Prompt to execute commands for changing display settings, updating the system time, and modifying power settings.
  • Use the Control Panel to adjust the display resolution, change the system time, and configure power settings.
  • Use the Task Manager to adjust display settings, update the system time, and configure power options.

Each issue maps to a Windows Settings category: text size is under Ease of Access, the clock is under Time & Language, and lid behavior is under System > Power & Sleep. Command Prompt is not the appropriate user-facing interface. Control Panel's "display resolution" option does not address text scaling (an accessibility issue). Task Manager has no display, time, or power configuration.

Question 7

A user reports that their laptop is not behaving as expected when they close the lid. Instead of going into sleep mode, the laptop continues to run, draining the battery. What should you do?

  • Use the Task Manager to force the laptop into sleep mode when the lid is closed.
  • Open Windows Settings, navigate to Display Settings, and enable "Sleep Mode on Lid Close."
  • Open the Control Panel, navigate to Power Options, and adjust the "Choose what closing the lid does" settings.
  • Open File Explorer and enable the "System Sleep Mode" option under File Explorer Options.

Control Panel > Power Options > "Choose what closing the lid does" is the correct location to configure lid close behavior. Task Manager has no power management, Display Settings does not contain lid behavior options, and File Explorer Options has no power management settings.

Question 8

Which of the following is the primary purpose of File Explorer in Windows?

  • To manage and organize files and folders on the computer.
  • To troubleshoot hardware and software issues.
  • To monitor system performance and resource usage.
  • To configure system settings and user accounts.

File Explorer's primary purpose is file management: opening, copying, moving, renaming, viewing, and deleting files and folders. Hardware troubleshooting uses Device Manager and Event Viewer, performance monitoring uses Task Manager, and system/account configuration uses Control Panel and Settings.

Question 9

You are working on your computer when a person from the shipping department delivers a new external solid-state drive (SSD) you ordered. When you plug the drive into your USB port, Windows cannot find a suitable device driver for the drive. Which of the following Windows consoles would you access Device Manager from to resolve the issue?

  • System Configuration
  • Control Panel
  • Component Services
  • Services

Device Manager is accessible through Control Panel > Hardware and Sound > Device Manager. System Configuration (msconfig) manages startup and boot options, Component Services manages COM+ and DCOM configuration, and the Services console manages Windows background services; none of these handle device drivers.

Question 10

An enthusiastic computer user wants to test out the new Windows 11 desktop. Which of the following has become more easily accessible using Windows 11?

  • Instant Search
  • Task View
  • Notification area
  • Multiple desktops

Windows 11 made multiple desktops (virtual desktops) more easily accessible, prominently surfaced via Task View with improved management options. Instant Search and the notification area predate Windows 11 without specific accessibility improvements, and Task View itself was introduced in Windows 10.

Question 11

A user is having difficulty using their keyboard and mouse due to a physical disability. They need to enable features like Sticky Keys and Mouse Keys to make interaction with their computer easier. Which section of the Ease of Access settings should they navigate to in order to configure these options?

  • Privacy settings
  • Display settings
  • Interaction settings
  • Audio settings

Sticky Keys and Mouse Keys are keyboard and mouse input accessibility features found under the Interaction section of Ease of Access. Privacy settings control app permissions, Display settings under Ease of Access covers visual options, and Audio settings covers captions and audio alerts.

Question 12

Which of the following is a primary purpose of the Accounts Settings menu in Windows?

  • To configure display resolution and color settings.
  • To enable or disable background processes.
  • To adjust indexing options for faster file searches.
  • To manage user accounts and sign-in options.

Settings > Accounts manages the signed-in Microsoft or local account, sign-in options (PIN, password, Windows Hello), and other user account settings. Display settings are under System, background app behavior is under Privacy/Task Manager, and indexing is managed in the Indexing Options applet in Control Panel.

Question 13

Which of the following is a feature found under the Ease of Access settings menu in Windows?

  • Managing user accounts
  • Configuring the system date and time
  • Enabling the Narrator tool
  • Adjusting the screen resolution

Narrator is a built-in screen reader configured under Settings > Ease of Access > Narrator. User accounts are under Settings > Accounts, date and time are under Settings > Time & Language, and screen resolution is under Settings > System > Display.

Question 14

A user wants to add a new family member to their Windows computer so that the family member can have their own personalized settings and files. Which action should the user take in the Accounts Settings menu?

  • Navigate to "Family & other users" and select "Add a family member."
  • Go to "Access work or school" and connect to a school account.
  • Open the "Sign-in options" section and enable biometric authentication.
  • Open "Sync your settings" and enable synchronization for all accounts.

Settings > Accounts > Family & other users is the correct location to add a new user with their own profile, settings, and files. "Access work or school" is for domain/Azure AD accounts, Sign-in options manages the current user's authentication methods, and Sync your settings syncs the current user's preferences across devices.

Question 15

A security-conscious user limits what usage data Windows permits to collect. They also limit what device functions it enables and for which apps. Where does the user accomplish this?

  • Privacy settings
  • VESA
  • User accounts
  • Instant Search

Settings > Privacy controls what diagnostic and usage data is sent to Microsoft, and which device functions (camera, microphone, location, etc.) are permitted per app. VESA is a hardware display standards body, User accounts manages credentials and account types, and Instant Search relates to file indexing.
