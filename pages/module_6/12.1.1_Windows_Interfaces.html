12.1.1 Windows Interfaces

OS Interface Overview

An OS consists of kernel files and device drivers (hardware interface) plus programs providing a user interface and configuration tools.

DOS
Microsoft's Disk Operating System; early PCs used its command-line interface or simple menu systems.
GUI
Graphical user interface; introduced with Windows to make computing accessible to non-technical users. The desktop GUI style is a major factor in OS customer preference.
Shell
The OS interface layer through which the user configures and operates hardware and software.

Windows 10 Desktop

The desktop is the top level of the Windows user interface, displayed after login. It provides the Start menu, taskbar, and shortcut icons for launching and switching between applications.

Component Description
Start menu Touch-optimized in Windows 10; activated via the Start button or the START/Windows logo key.
Taskbar Contains the Start button, instant search box, Task View button, notification area, and open/pinned app icons.
Notification area Holds icons for background processes; located at the right end of the taskbar.
Taskbar icons (middle) Shows icons for apps with open windows; app icons can be pinned for quick access. Used to switch between program windows.
Instant search box Provides quick search from the taskbar.
Task View button Accessible from the taskbar; used to manage open windows and virtual desktops.

Keyboard shortcuts are important for navigating the desktop and program windows efficiently. Full list: support.microsoft.com

Windows 11 Desktop

Windows 11 refreshes the desktop UI with several changes:

  • Center-aligned taskbar (vs. left-aligned in Windows 10)
  • Improved spacing for touch control
  • Rounded corners throughout the UI
  • More accessible multiple desktops feature

Multiple desktops allow separate workspaces, for example one desktop for business apps and another for personal apps and games.
