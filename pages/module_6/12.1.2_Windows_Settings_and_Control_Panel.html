12.1.2 Windows Settings and Control Panel

Overview

Windows Settings and Control Panel are the two main interfaces for administering Windows. Administration tasks include configuring options, managing user accounts, and adding/removing devices and software. All configuration data is stored in the registry. Both interfaces provide graphical pages and applets to modify registry settings.

Windows Settings App

Windows Settings is a touch-enabled interface and the preferred administrative tool. Configuration options are organized into heading groups.

Windows 11 Settings Differences

  • No "home" page; navigation uses sidebar menu icons instead.
  • Heading groups include: System, Bluetooth & devices, Network & internet, Personalization, Apps, Accounts, Time & language, Gaming, Accessibility, Privacy & security, Windows Update.
  • Gaming and Accessibility are new top-level groups compared to Windows 10.

Control Panel

Control Panel is a legacy interface still used for settings not available in Windows Settings. Each icon represents an applet for a specific configuration task. Most applets are added by Windows; third-party software (such as antivirus) may add its own applets.
