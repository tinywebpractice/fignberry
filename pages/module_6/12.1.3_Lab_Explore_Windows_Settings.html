12.1.3 Lab: Explore Windows Settings

CompTIA hands-on lab activity. This page serves as a reference for the tasks and steps completed in the lab.

Lab Tasks and Configuration

Setting Value
Display resolution1920 x 1080
Screen saverRibbons
Idle timeout10 minutes
Require logon on resumeEnabled

Steps: Set Display Resolution

  1. Right-click the desktop, then select Display Settings.
  2. Choose 1920 x 1080 from the Display resolution dropdown.
  3. When prompted, select Keep Changes.

Steps: Set Screen Saver

  1. In Settings, select Personalization from the left sidebar.
  2. Select Lock Screen, then Screen Saver.
  3. Select Ribbons from the screen saver dropdown.
  4. Set the wait time to 10 minutes.
  5. Check "On resume, display logon screen."
  6. Select OK.
