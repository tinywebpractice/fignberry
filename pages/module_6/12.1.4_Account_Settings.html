12.1.4 Accounts Settings

User Account Fundamentals

A user account controls access to the computer. Accounts are assigned rights/privileges for OS configuration changes and permissions on files, folders, and printers. Access is protected by authentication (username/password, facial recognition, etc.). Each account is associated with a profile containing personal folders (documents, pictures, videos, music) and application configuration data.

Administrator account
Has privileges to change any aspect of system configuration. The first user of a computer is set up as the default administrator.
Standard user account
Has privileges on their own profile only, not the whole computer. Additional accounts beyond the first are usually standard users.
Local account
Can only sign in on a single computer.
Microsoft account
Gives access to Microsoft cloud services; syncs desktop settings and profile data across multiple devices.

Windows Account Settings App

Section Function
Your info Manage the current user account. Microsoft accounts link to a web portal.
Email & accounts Add sign-in credentials for email or social networking accounts for quick access.
Sign-in options Configure fingerprint, PIN, or password authentication. Set automatic lock. To change a password: Settings > Accounts > Sign-in options > Password > Change, then enter current password, new password, confirm, and optional hint.
Access work or school Join the computer to a centrally managed domain network.
Family and other users Permit other local or Microsoft accounts to log on. Additional users should generally be configured as standard users.
Sync settings Use the cloud to apply the same personalization and preferences across devices signed in with a Microsoft account.

User Accounts Control Panel Applet (Legacy)

The User Accounts applet in Control Panel is the legacy interface. Many functions are obfuscated or hidden; it is not well suited for adding new accounts. It does allow:

  • Adjusting the account name
  • Changing account privilege level (administrator vs. standard user)
  • Changing User Account Control (UAC) settings
UAC (User Account Control)
A system to prevent unauthorized use of administrator privileges. At the default level, making an administrative change requires the user to confirm a prompt or enter administrator credentials.
