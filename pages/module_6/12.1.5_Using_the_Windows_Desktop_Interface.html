12.1.5 Using the Windows Desktop Interface

User Account Types

Account Type Capabilities
Administrator Full system configuration privileges; can manage, delete, and modify any account.
Standard user Can change own password and manage own profile settings; no system-wide changes.
Guest Limited account sometimes created by administrators; minimal privileges.
Backup/install accounts Special-purpose accounts that may exist alongside standard and admin accounts.

User Profiles

When a new user account is created, Windows automatically generates a profile containing default folders and files associated with that account. Access to those files is restricted to the account owner and administrators (local or domain).

Permissions on profile files are assigned to the account owner by default. An administrator of the local computer or the domain the computer is joined to can also access them.

Accessing Account Settings

  • Click the username in the Start menu to switch users or access account settings.
  • Account settings allow changes to profile picture, personal information, and security settings.
  • The Control Panel User Accounts applet can be used to view account types, change passwords, and manage accounts.

Personalization

Users can customize their Windows environment via right-click on the desktop and selecting Personalize, or through Settings > Personalization. Customizable options include background image, color themes, and other personal preferences.
