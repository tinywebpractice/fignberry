12.1.7 Desktop Settings

Time and Language Settings

Purpose Details
Date, time, and time zone Keeping the PC synchronized to an accurate time source is important for authentication and backup processes.
Region and language Sets spelling/localization, keyboard input method, and speech recognition. Multiple languages can be enabled; toggle the active language via the notification area icon or START+SPACE.

Language settings are found under Settings > Time & Language > Language. The Windows display language controls the language used in Windows features such as Settings and File Explorer. Preferred languages determine what language apps and websites display (first supported language in the list is used).

Personalization Settings

Personalization Settings allow selection and customization of themes, which control the overall appearance of the desktop environment. Configurable items include:

  • Desktop wallpaper
  • Screen saver
  • Color scheme
  • Font
  • Start menu and taskbar properties
