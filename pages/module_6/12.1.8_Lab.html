12.1.8 Lab: Require a Screen Saver Password

Lab Overview

This is a CompTIA A+ CertMaster Learn exercise. The objective is to configure Windows screen saver settings to require a password on resume, improving physical security on an unattended workstation.

Required Actions

  • Enable the screen saver
  • Set the screen saver to activate after 10 minutes of inactivity
  • Require the logon screen when the computer wakes from the screen saver

Procedure

  • Open Screen Saver Settings
    • Right-click Start and select Settings
    • Select Personalization
    • Scroll down in the right pane and select Lock Screen
    • Scroll down and select Screen saver
  • Configure the Screen Saver
    • Under Screen Saver, use the drop-down menu to select any screen saver
    • Set the Wait field to 10 minutes
    • Check On resume, display logon screen
    • Click OK

Key Terms

Screen Saver Settings
Windows dialog (Settings > Personalization > Lock Screen > Screen saver) used to configure screen saver type, timeout, and resume behavior.
On resume, display logon screen
Setting that forces the user to authenticate after the screen saver activates, preventing unauthorized access to an unattended machine.
