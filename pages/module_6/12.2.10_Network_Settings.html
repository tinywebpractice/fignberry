12.2.10 Network Settings

Network Adapters and Profiles

A Windows host can have one or more network adapters. Adapter types include Ethernet, Wi-Fi, cellular radio, and VPN. Each adapter requires IP address configuration. Each network connection must be assigned a trust profile that determines firewall policy:

Profile Firewall Policy Typical Use
Public Most restrictive Untrusted networks (coffee shops, hotels)
Private Less restrictive Home or trusted networks
Domain Managed by domain policy Corporate networks joined to a Windows domain

Network Configuration Utilities

Tool Location Purpose
Network & Internet settings Settings > Network & Internet View network status, change IP address properties per adapter, access other tools
Network Connections (ncpa.cpl) Control Panel Manage adapter devices and IP address information
Network and Sharing Center Control Panel View network status and connection details
Advanced sharing settings Control Panel Configure network discovery; enable/disable file and printer sharing

Windows Defender Firewall

Determines which processes, protocols, and hosts are permitted to communicate with the local computer over the network.

  • Windows Security settings app and the Control Panel applet allow the firewall to be enabled or disabled.
  • Windows Defender Firewall with Advanced Security (MMC snap-in) is used to configure complex inbound and outbound firewall rules.

Internet Options (Control Panel)

The Internet Options applet exposes configuration settings for web browsers installed on Windows. The Security tab restricts what types of potentially risky active content are allowed to run. These settings affect all installed browsers, though modern browsers (Microsoft Edge, Google Chrome, Mozilla Firefox, Apple Safari) also have their own built-in settings menus.
