12.2.11 Administrative Tools

Overview

Administrative Tools (Windows 10) / Windows Tools (Windows 11) is a Control Panel shortcut to a folder of advanced configuration consoles. Many of these are Microsoft Management Console (MMC) snap-ins used to modify advanced settings for OS subsystems.

Key Administrative Tools

Tool Executable / File Purpose
Computer Management compmgmt.msc Default MMC console; snap-ins for Task Scheduler, Event Viewer, Shared Folders, Local Users and Groups, Performance, Device Manager, Disk Management, Services and Applications
Defragment and Optimize Drives dfrgui.exe Maintain disk performance by optimizing file storage patterns
Disk Cleanup cleanmgr.exe Regain disk capacity by deleting unwanted files
Event Viewer eventvwr.msc Review system, security, and application logs
Local Security Policy secpol.msc View and edit local security settings
Resource Monitor resmon.exe View real-time performance statistics (CPU, memory, disk, network)
Performance Monitor perfmon.msc View and log performance statistics over time
Registry Editor regedit.exe Make manual edits to the Windows configuration settings database
Services console services.msc Start, stop, and pause background processes (services)
Task Scheduler taskschd.msc Run software and scripts on calendar or event triggers
System Configuration msconfig.exe Manage startup options and boot settings
Windows Defender Firewall with Advanced Security MMC snap-in Configure complex inbound/outbound firewall rules
Remote Desktop Connection mstsc.exe Connect to remote computers via RDP
Quick Assist Built-in app Remote support tool for helping other users
Windows Memory Diagnostic Built-in tool Test RAM for errors
Windows PowerShell / PowerShell ISE powershell.exe Command-line scripting environment
Command Prompt cmd.exe Legacy command-line interface
Component Services MMC snap-in Manage COM+ applications and DCOM configuration
ODBC Data Sources (32-bit / 64-bit) odbcad32.exe Configure database connectivity

Steps Recorder psr.exe Record and annotate user steps for troubleshooting documentation

Microsoft Management Console (MMC)

The MMC is a framework that hosts one or more snap-ins, each providing an advanced management interface for a specific OS subsystem (disks, users, services, etc.). Snap-ins can be combined into a custom console saved as a .msc file. Computer Management (compmgmt.msc) is the primary pre-built MMC console.
