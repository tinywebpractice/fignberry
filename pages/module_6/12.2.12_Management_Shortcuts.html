12.2.12 Management Shortcuts

Quick Access Methods

Method How Opens / Accesses
WinX menu Win+X or right-click the Windows button Shortcut menu with links to: Installed apps, Power Options, Event Viewer, System, Device Manager, Network Connections, Disk Management, Computer Management, Terminal, Terminal (Admin), Task Manager, Settings, File Explorer, Search, Run, Shut down or sign out, Desktop
Instant Search Press Win, then type program name, utility name, or file path Executes programs, configuration options, or opens files/unregistered programs by path
Run dialog Win+R Execute programs with switches, open Settings pages, open Control Panel applets
Object context menus Right-click system objects or notification area icons Shortcuts to configuration tools (e.g., right-click This PC > Properties opens System settings; right-click This PC > Manage opens Computer Management)

Run Dialog - Useful Commands

Command Opens
ms-settings:system System page of the Settings app (pattern works for any Settings page)
control ncpa.cpl Network Connections (pattern: control <applet.cpl> for Control Panel applets)
compmgmt.msc Computer Management
eventvwr.msc Event Viewer
services.msc Services console
regedit.exe Registry Editor
perfmon /comp Performance Monitor (computer view)
msconfig System Configuration
secpol.msc Local Security Policy
taskschd.msc Task Scheduler
resmon.exe Resource Monitor
dfrgui.exe Defragment and Optimize Drives
cleanmgr.exe Disk Cleanup
