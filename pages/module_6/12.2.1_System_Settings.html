12.2.1 System Settings

Overview

The System Settings page (Settings app) provides options for configuring input/output devices, power, remote desktop, notifications, and clipboard. The About page displays key hardware and OS version information.

System Settings Categories

AboutDevice specifications and Windows specifications

About Page

The About page shows two groups of information:

  • Device specifications: Device name, Processor, Installed RAM, Device ID, Product ID, System type, Pen and touch support
  • Windows specifications: Edition, Version, Installed on (date), OS build, Experience pack

Also provides buttons to Copy device specs and Rename this PC.

Related Settings Links (Bottom of About Page)

The bottom of the About page provides shortcuts to:

  • BitLocker disk encryption settings
  • System protection (System Restore)
  • Advanced system settings

Advanced System Settings

Performance options
Configure desktop visual effects for best appearance or best performance; manually configure virtual memory (paging file); set operation mode to favor foreground or background processes. Desktop PCs should always be optimized for foreground processes.
Startup and recovery options
Configure boot behavior and what happens when a system failure occurs (e.g., kernel memory dump settings).
Environment variables
Set file path variables used by the OS and applications. Example: %SYSTEMROOT% expands to C:\Windows by default.
User profiles
Manage profile data stored for each user account.

Legacy Access

In earlier Windows versions these options were managed via the System Applet in Control Panel. In current Windows, the System Applet redirects directly to the System Settings menu.
