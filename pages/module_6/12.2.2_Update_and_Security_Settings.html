12.2.2 Update and Security Settings

Overview

The Update & Security section of Settings (Windows 10) / Privacy & Security (Windows 11) provides a unified interface for patch management, security, backup, recovery, and activation. Key concepts:

  • Patch / update: A file containing replacement system or application code that fixes reliability, security, or performance issues.
  • Security apps: Detect and block threats such as viruses, malware, and unauthorized network traffic.

Windows Update

  • Hosts critical updates, security patches, optional software updates, and hardware driver updates.
  • In the basic interface, Windows Update can only be paused temporarily, it cannot be completely disabled.
  • Supports manual check for updates and selection of optional updates.
  • Feature Updates: Released periodically; introduce changes to OS features and tools. Can be used to perform an in-place upgrade from Windows 10 to Windows 11 if hardware is compatible.
  • Update logging: Activity is recorded in Event Viewer at Applications and Service Logs > Microsoft\Windows > WindowsUpdateClient > Operational. Failed updates produce an error code that can be looked up on the Microsoft Knowledge Base.

Key options on the Windows Update page:

  • Check for updates (manual)
  • View optional updates
  • Pause updates for 7 days (Advanced Options to change pause duration)
  • Change active hours (window when Windows will not reboot for updates)
  • View update history
  • Advanced options

Windows Security

Provides shortcuts to management pages for the built-in Windows Defender virus/threat protection and firewall. Use this section to identify which antivirus tool is active on the system. In Windows 11, Privacy & security settings are grouped under the same heading, with Windows Update as a separate heading.

Firewall and Network Protection Profiles

Windows Firewall settings are divided into three network profiles:

ProfileWhen AppliedNotes
DomainSystem is joined to a Windows domainTypically managed by organizational policy
Private networkHome or trusted networksLess restrictive firewall rules
Public networkAway from home (coffee shops, hotels, etc.)More restrictive rules recommended; stricter settings than Private

Activation

Microsoft Product Activation is an anti-piracy technology that verifies software is legitimately purchased. Windows must be activated within a grace period after installation; after the grace period, certain features are disabled until activated over the Internet using a valid product key or digital license. The Activation page shows current status and allows entry of a different product key.
