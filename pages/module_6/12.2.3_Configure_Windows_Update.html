12.2.3 Configure Windows Update

Task Summary

This lab configures Windows Update settings for a workstation. The required tasks are to check for updates, include updates for other Microsoft products, and set active hours.

Required Actions

  • Check for Windows updates
  • Provide updates for other Microsoft products when Windows is updated
  • Set the active hours for the workstation

Lab Questions

Question 1

Which option allows the computer to restart as soon as needed for updates?

  • Get me up to date

Question 2

What is the most extended amount of time you can pause updates?

  • 5 weeks

Procedure

Access Windows Update

  1. Right-click Start and select Settings.
  2. Maximize the window for better viewing.
  3. From the left pane, select Windows Update.
  4. From the right, select Check for updates.
  5. Wait for the updates to download and install.

Include Other Microsoft Product Updates

  1. From Windows Update settings, scroll down and select Advanced options.
  2. For Receive updates for other Microsoft products, slide the toggle switch to On.

Set Active Hours

  1. From Windows Update settings, scroll down and select Advanced options if you are not already there.
  2. Select Active hours.
  3. Select a value in the current Start time.
  4. In the left column, select 6 so the start time is 6:00 AM.
  5. Select the checkmark.
  6. Select a value in the End time.
  7. In the left column, select 6 so the end time is 6:00 PM.
  8. Select the checkmark.

Answer and Score

  1. From the top right, select Questions.
  2. Answer the questions.
  3. Select Score Lab.
