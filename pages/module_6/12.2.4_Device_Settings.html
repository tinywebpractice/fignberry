12.2.4 Device Settings

Plug and Play

Most Windows-compatible hardware uses Plug and Play (PnP). Windows automatically detects new devices, locates drivers, and configures them with minimal user input. Drivers are most commonly supplied via Windows Update; in some cases the vendor provides a setup program to install drivers before connecting the device.

Important: On a 64-bit edition of Windows, you must use 64-bit device drivers. 32-bit drivers will not work.

Device Management Interfaces

Interface Location Used For
System settings Settings > System Display and Sound device configuration
Bluetooth & Devices Settings > Bluetooth & devices (Windows 11) Input devices (mice, keyboards, touch), printers/scanners, Bluetooth/USB peripherals, cameras, AutoPlay, USB
Mobile Devices Settings > Bluetooth & devices > Mobile devices Link a smartphone to the PC
Devices and Printers Control Panel > Devices and Printers Add devices/printers manually; shortcuts to configuration pages for connected devices
Device Manager Control Panel > Device Manager (or via System settings) Advanced management of system and peripheral devices; device properties, driver settings, events, troubleshooting

Bluetooth & Devices (Windows 11) - Subcategories

  • Bluetooth - Toggle on/off; shows discoverable name and paired devices
  • Devices - Mouse, keyboard, pen, audio, displays, docks, and other devices; Add device button
  • Printers & scanners - Preferences and troubleshooting
  • Mobile devices - Link smartphone to PC
  • Cameras - Connected cameras and default image settings
  • Mouse - Buttons, pointer speed, scrolling
  • Pen & Windows Ink - Handedness, pen button shortcuts, handwriting
  • AutoPlay - Defaults for removable drives and memory cards
  • USB - Notifications, USB battery saver

Scenario - Correct Tool Selection

Scenario Correct Tool
Add a new wireless printer to a workstation Bluetooth & Devices > Printers & scanners (or Devices and Printers in Control Panel)
Link a smartphone to a PC Bluetooth & Devices > Mobile devices
Update or manage the driver for a USB keyboard Device Manager
