12.2.5 Display and Sound Settings

Display Settings

Accessed via Settings > System > Display. Principal configuration options:

Scale
Makes the system use proportionally larger fonts and UI elements. Useful on large high-resolution screens where default font sizes would be too small to read.
Color
Monitor calibration to ensure colors match the designer's intent. Important for graphics design workflows.
Multiple displays
When the desktop is extended across multiple screens, set relative positions so the cursor moves between them in a predictable pattern.
Resolution and refresh rate
TFT and OLED displays are designed to operate only at their native resolution and refresh rate. Windows should auto-detect this, but can be manually adjusted if necessary. Path: Settings > System > Display > Advanced display settings.

Screen Saver

Path: Settings > Personalization > Lock screen > Screen saver. Options include:

  • Select a screen saver type from the drop-down list
  • Set the wait time (minutes of inactivity before activation)
  • Enable On resume, display logon screen to require credentials to dismiss the screen saver

Sound Settings

Accessed via Settings > System > Sound or the Sound Applet in Control Panel. Used to select and configure audio input and output devices.

Section Purpose
Output Choose where to play sound (speakers, headphones, display audio); set volume; toggle Mono audio; add output device
Input Choose a device for speaking or recording (microphone); set input level; add input device

Volume can also be controlled via the speaker icon in the Notification Area (system tray).
