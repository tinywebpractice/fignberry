12.2.6 Power Options

Overview

Power management allows Windows to selectively reduce or cut power to hardware components to save energy and extend battery life. The Advanced Configuration and Power Interface (ACPI) specification ensures software and hardware compatibility across power-saving modes.

ACPI Power Modes

ACPI State Name Description
S0 Powered on Normal operating state
S1-S3 Standby / Suspend to RAM Cuts power to CPU, monitor, disks, and peripherals; maintains power to RAM
S4 Hibernate / Suspend to Disk Saves RAM contents to disk as hiberfil.sys in the root of the boot volume, then powers off
S5 Soft power off Powered off via OS (still draws standby power)
G3 Mechanically powered off No power drawn

Windows Power-Saving Modes

Sleep (laptop)
Enters standby (S1-S3). If battery runs low, automatically switches to hibernate before power is exhausted.
Hybrid sleep (desktop)
Creates a hibernation file, then enters standby. Can be configured to transition to full hibernate after a defined period. Protects against power loss.
Modern Standby
Uses S0 low-power idle mode to maintain network connectivity while consuming minimal energy. Allows the device to receive updates and notifications while appearing "asleep."
Fast Startup
Uses the hibernation file to restore the previous system RAM state on boot, making startup faster than traditional hibernate. Enabled/disabled via Power Options applet.

Configuration Interfaces

Interface Location Options
System Power settings Settings > System > Power & sleep Screen turn-off timer; sleep timer
Power Options applet Control Panel > Power Options Power plans; power button/lid behavior; Fast Startup; component sleep timers; advanced settings

Power Plans

A power plan is a collection of hardware and system settings (display brightness, sleep timers, etc.) that manages how the computer uses power. Windows includes three built-in plans:

Plan Behavior
Balanced (recommended) Automatically balances performance with energy consumption on capable hardware
Power saver Saves energy by reducing performance where possible
High performance Favors performance; may use more energy

Advanced power plan settings allow fine-grained control over CPU states, display brightness, search and indexing behavior, and USB selective suspend (cuts power to idle USB peripheral devices).

Power Button and Lid Actions

Configured via Control Panel > Power Options > Choose what the power buttons do. Options for pressing the power button or closing the laptop lid include: Do nothing, Sleep, Hibernate, or Shut down. Settings can differ for on-battery vs. plugged-in states.
