12.2.7 Lab: Edit Power Options

Lab Overview

This is a CompTIA A+ CertMaster Learn exercise. The objective is to configure laptop power and battery settings for an executive office workstation using Control Panel Power Options.

Path: Control Panel > Hardware and Sound > Power Options

Required Configuration

Power Button Action (all existing power plans)

State Action
On battery Hibernate
Plugged in Shut down

Lid Close Action (all existing power plans)

State Action
On battery Sleep
Plugged in Do nothing

Wake Password

Require a password when the computer wakes from sleep or hibernate.

High Performance Plan - Display and Sleep Timers

Setting On battery Plugged in
Turn off the display 5 minutes 1 hour
Put the computer to sleep 30 minutes 5 hours

Procedure

  • Open Power Options: Control Panel > Hardware and Sound > Power Options
  • Set power button and lid actions:
    • Select Choose what the power buttons do from the left pane
    • Set power button action: On battery = Hibernate; Plugged in = Shut down
    • Set lid close action: On battery = Sleep; Plugged in = Do nothing
    • Under Password protection on wakeup, select Require a password
    • Click Save changes
  • Select and modify the High Performance plan:
    • Back in Power Options, select High performance (expand "Show additional plans" if needed)
    • Click Change plan settings next to High performance
    • Set Turn off the display: On battery = 5 minutes; Plugged in = 1 hour
    • Set Put the computer to sleep: On battery = 30 minutes; Plugged in = 5 hours
    • Click Save changes
