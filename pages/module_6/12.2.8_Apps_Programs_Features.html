12.2.8 Apps, Programs, and Features

Software Types in Windows

Type Description Admin Rights Required?
Windows Features OS components that can be enabled or disabled (e.g., Hyper-V virtualization platform in supported editions) Yes
Store apps Installed via the Microsoft Store; tied to a Microsoft account and transferable across devices. Run in a sandbox that prevents system-wide changes and OS crashes from faulty apps. No. Standard user permissions sufficient; no UAC prompt
User-context applications Installed into the user's AppData folder rather than System or Program Files folders No. No admin credentials needed
Desktop apps Installed via a setup program or MSI installer; install into Program Files or System folders Yes. Administrator privileges required
Windows Subsystem for Linux (WSL) Allows installation of a Linux distribution and use of Linux applications without a VM or dual-boot configuration Yes (to enable WSL)

Key Points

  • Store apps run in a restrictive sandbox. They cannot make system-wide changes or crash the OS.
  • Store apps do not require UAC confirmation or administrator privileges to install.
  • Desktop apps installed via setup.exe or .msi do require administrator privileges.
  • User-context apps installed to AppData bypass the need for admin credentials entirely.
  • WSL enables Linux app usage on Windows without virtualization overhead or dual-boot complexity.
