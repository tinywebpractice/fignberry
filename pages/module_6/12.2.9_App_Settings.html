12.2.9 Apps Settings

Apps Settings (Settings > Apps)

The Apps Settings group is used to view and remove installed apps and Windows Features, configure default apps for file types, and manage startup apps.

Subcategory Purpose
Installed apps Uninstall and manage apps on the PC
Advanced app settings Choose where to get apps, archive apps, uninstall updates
Default apps Set defaults for file types, link types, and other defaults
Offline maps Downloads, storage location, map updates
Apps for websites Configure websites that open in an app instead of a browser
Video playback Video adjustments, HDR streaming, battery options
Startup Manage apps that start automatically when the user signs in

Uninstalling Programs - Best Practices

  • Exit all applications or files that may lock files used by the app before uninstalling; otherwise a restart may be required.
  • Disable antivirus software if it interferes with the uninstall process.
  • If locked files cannot be removed, the uninstaller will prompt you to check its log file; those files and directories can then be deleted manually.

Programs and Features (Control Panel)

Programs and Features is the legacy software management applet in Control Panel. It can be used to install, modify, and uninstall desktop applications and enable/disable Windows Features.

Mail Applet (Control Panel)

The Mail Applet appears in Control Panel when Microsoft Outlook is installed. It provides basic configuration for:

Email Accounts
Set up email accounts and directory service connections.
Data Files
Manage .OST (offline/cached) and .PST (archive) data files that Outlook uses to store messages and documents.
Profiles
Set up multiple profiles of email accounts and data files. Typically only one profile is needed. Managed via Show Profiles.

Detailed account configuration, sync settings, and data file selections are managed within the Outlook Settings menu itself; the Mail Applet contains only basic settings.

Gaming Settings

The Gaming settings page toggles Game Mode on and off. When enabled, Game Mode suspends Windows Update and dedicates system resources to 3-D performance and frame rate for the active game, rather than background services or other software.

Additional options include managing captures, recording preferences, and in-game chat/broadcast features.
