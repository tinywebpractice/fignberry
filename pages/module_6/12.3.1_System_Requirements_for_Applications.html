12.3.1 System Requirements for Applications

Overview

System requirements for applications refers to the PC specification required to run third-party software. App vendors should publish requirements as support information. Key requirement categories: CPU, RAM, storage, graphics, and external hardware tokens.

CPU Requirements

Requirement Details
32-bit vs. 64-bit A 64-bit application requires a 64-bit CPU and 64-bit OS; cannot run on 32-bit platforms. 32-bit applications can usually run on 64-bit platforms.
Generation / clock speed / core count Some apps define minimum CPU generation, clock speed, or number of cores.
CPU features May require hardware-assisted virtualization or a Trusted Platform Module (TPM). If a required feature is not detected, check the system setup (BIOS/UEFI) to confirm it has not been disabled.

RAM Requirements

Published RAM requirements typically assume no other foreground software is running simultaneously. Running multiple programs at the same time will require more RAM than the stated minimum.

Storage Requirements

Refers to the installation footprint on the fixed disk. Additional space must also be provisioned for user-generated data, temporary files, and log files beyond the base installation size.

Dedicated Graphics Card Requirements

Integrated graphics
Graphics subsystem built into the CPU or motherboard chipset; shares system RAM. Sufficient for basic desktop use.
Dedicated graphics card
A separate GPU with its own video RAM (VRAM), independent of system RAM. Required by demanding applications such as graphic design software, 3-D rendering tools, and games. If the GPU does not meet minimum requirements, the application will fail to launch.

External Hardware Token Requirements

Some applications require or recommend an external hardware token for stronger authentication than a password alone. A hardware token is a smart card or USB form factor device that stores cryptographic user identification data. Authentication requires both the physical token and a password, PIN, or fingerprint scan (multi-factor authentication).
