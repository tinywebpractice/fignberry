12.3.2 OS Requirements for Applications

Application to OS Compatibility

Every software application is designed to run under a specific operating system. Key compatibility considerations:

  • An app built for macOS will not run on Windows and vice versa. Always select the version that matches your OS.
  • An app may not be supported under newer OS versions; upgrading the OS may require upgrading the application as well.
  • On Linux, different package formats exist per distro, but cross-distro compatibility is generally not a significant issue. Apps not available in a compatible package can be compiled from source code manually.

32-bit vs. 64-bit Compatibility

App Type Requires Can run on 64-bit platform?
64-bit application 64-bit CPU + 64-bit OS Yes (only)
32-bit application 32-bit or 64-bit CPU + OS Yes, via WOW64
WOW64 (Windows on Windows 64-bit)
A special application environment in 64-bit Windows that replicates the 32-bit environment expected by an application and translates its requests into operations the 64-bit CPU, memory, and file subsystems can process. Many Windows applications are still 32-bit and run via WOW64.

File System Locations on 64-bit Windows

Content Location
64-bit application files Program Files
32-bit application files Program Files (x86)
64-bit shared system files (DLLs, EXEs) %SystemRoot%\system32
32-bit system files (on 64-bit Windows) %SystemRoot%\syswow64

Note: The naming is counterintuitive. system32 holds 64-bit files and syswow64 holds 32-bit files on a 64-bit Windows installation.

Viewing Compatibility Settings

To view or configure application compatibility settings: locate the .exe file > right-click > Properties > select the Compatibility tab. This allows you to run the program in compatibility mode for an older OS version.
