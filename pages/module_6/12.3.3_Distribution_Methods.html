12.3.3 Distribution Methods

Overview

A distribution method is the means by which a vendor makes an application available to install. Many apps are published through app stores where installation is handled automatically. Desktop applications are installed from a setup file.

Setup File Formats by OS

OS Setup File Format(s) Notes
Windows .EXE, .MSI Packs executables, config files, and media; extracts to application directory during install
macOS .DMG, .PKG
Linux (Debian-based) .DEB Managed with APT package manager
Linux (RPM-based) .RPM Managed with Dandified YUM (DNF)

Distribution Methods

App store
Vendor publishes app in a curated store (e.g., Microsoft Store); installation mechanics are handled automatically.
Physical media
Setup file distributed on CD/DVD or USB thumb drive.
Internet download
Setup file downloaded directly from vendor. Must verify authenticity and integrity before installing and scan for malware. Windows uses digital signatures to identify valid developers. Linux uses hash values. Download the package, generate your own hash, and compare it to the value published by the package maintainer.
ISO file
Contains the complete contents of an optical disc in a single file. Used to install virtual machine OSes and complex applications (e.g., databases) with many components. In Windows: right-click the ISO file > Mount; it appears in File Explorer with the next available drive letter.
Image deployment (network push)
Enterprise method where a complete system image is pushed to workstations over the network. The image contains OS settings and files, application settings and files, and licensing/activation settings. Deploys as a complete installation unit rather than installing one application at a time.

UAC and Unknown Publishers

When running a setup file from an unknown or unverified publisher, Windows UAC displays a warning prompt ("Do you want to allow this app from an unknown publisher to make changes to your device?"). Exercise caution. Only proceed if the source is trusted and the package integrity has been verified.
