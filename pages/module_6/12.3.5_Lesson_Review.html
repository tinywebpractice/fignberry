12.3.5 Lesson Review

Question 1. A server administrator tests an application migration from a 32-bit server to a 64-bit server, but the application is still 32-bit. Where will Windows run the application?

  • PXE
  • WOW64
  • OEM
  • SED

WOW64 (Windows on Windows 64) is the compatibility subsystem built into 64-bit Windows that allows 32-bit applications to run. PXE is a network boot environment. OEM refers to licensing, not execution. SED (Self-Encrypting Drive) is a storage security feature.

Question 2. Why is it important to verify the authenticity and integrity of an application installer downloaded from the Internet?

  • To check if the application requires a dedicated graphics card.
  • To confirm the installer is free from malware and has not been tampered with.
  • To determine if the application is 32-bit or 64-bit.
  • To ensure the application is compatible with the operating system.

Verifying authenticity (via digital signature/code signing) and integrity (via hash comparison) ensures the file came from the legitimate publisher and was not modified in transit or at rest. Hardware requirements, bit-width, and OS compatibility are separate checks unrelated to integrity verification.

Question 3. A graphics artist is starting to get into 3D animation and wants to ensure their computer can adequately handle the work. What should the graphics artist use?

  • Dedicated graphics
  • LPL
  • Integrated graphics
  • Hardware token

3D animation is GPU-intensive and requires a dedicated graphics card with its own VRAM. Integrated graphics shares system RAM and is insufficient for demanding 3D rendering. LPL is not a standard graphics term. A hardware token is a security authentication device.

Question 4. A project manager implements a new ticketing system that allows the helpdesk to record knowledge, streamline efficiencies, and automate solutions. Which of the following is the least concern for the support team?

  • Support
  • Licensing
  • Distribution method
  • Training

Distribution method is a procurement/IT concern handled before implementation and is not an ongoing concern for the support team using the system. Support, licensing, and training are all directly relevant to the team operating the ticketing system day to day.

Question 5. Which of the following scenarios best evaluates whether a computer system meets the CPU, System Memory, and Storage Requirements for installing a new application?

  • The system has a 64-bit CPU and OS, 8GB of RAM, and 500GB of free storage space, meeting all the application's requirements.
  • The system has a 64-bit CPU and OS, 4GB of RAM, and 50GB of free storage space, but the application requires 8GB of RAM and 100GB of free storage space.
  • The system has a 64-bit CPU and OS, 16GB of RAM, and 1TB of free storage space, but the application requires a dedicated graphics card.
  • The system has a 32-bit CPU, 4GB of RAM, and 100GB of free storage space, but the application requires a 64-bit CPU and OS.

Only the first scenario satisfies all three checked requirements (CPU architecture, RAM, and storage). The second fails on RAM and storage. The third fails due to a missing dedicated GPU. The fourth is blocked by CPU architecture, which is a hard incompatibility.

Question 6. Which of the following statements BEST describes the importance of OS requirements for applications?

  • Applications designed for macOS can run on Windows without compatibility issues.
  • A 64-bit application requires both a 64-bit CPU and a 64-bit OS to function.
  • Linux applications are always compatible with all Linux distributions without any modifications.
  • 32-bit applications cannot run on a 64-bit operating system.

A 64-bit application requires a 64-bit OS because the OS must provide the necessary instruction set and memory addressing support. macOS and Windows apps are not cross-compatible. Linux app compatibility varies across distros due to library and kernel differences. 32-bit apps can run on 64-bit Windows via WOW64.

Question 7. Your organization is planning to deploy a new application to all employees. The application setup file is available as an ISO image. Which of the following would be the MOST efficient and secure approach for deployment?

  • Distribute the ISO file via email and instruct employees to install it themselves.
  • Copy the ISO file to USB drives and distribute them to employees for installation.
  • Use a network-based installer to deploy the application during non-critical hours.
  • Mount the ISO file on each individual computer and manually install the application.

A network-based deployment pushes the application centrally, ensures consistency, minimizes user error, and scheduling during non-critical hours avoids business disruption. Email distribution is insecure and inconsistent. USB distribution is slow and introduces physical security risks. Manual per-machine installation is the least efficient option at scale.

Question 8. Don is an accountant who receives permission to install a new accounting application, but the OS will not allow him to. A helpdesk technician later installs it on the same machine without issue. Which of the following is the MOST likely reason Don could not install the application?

  • Insufficient permissions
  • Insufficient system RAM
  • Insufficient disk space
  • Incorrect service pack level
  • Failed device driver

The technician installed successfully on the same machine, ruling out any hardware or OS-level issue. Only the user account changed, indicating Don lacked the administrative privileges required to install software. RAM, disk space, service pack level, and driver issues would have blocked the technician equally.

Question 9. You are an IT administrator tasked with deploying a new accounting application across 200 desktops. The application requires a network-based installer and must not disrupt normal business operations. What is the BEST approach?

  • Install the application on one computer at a time to minimize network congestion.
  • Deploy the application during business hours to ensure immediate feedback from users.
  • Allow each user to manually install the application from a shared network folder.
  • Use Group Policy Objects (GPOs) to automate the deployment during non-critical times.

GPOs allow centralized, automated software deployment to all domain-joined machines without user interaction. Scheduling during non-critical hours satisfies the no-disruption requirement. Serial manual installs are impractical at 200 machines. Deploying during business hours directly violates the stated requirement. Self-service installs introduce inconsistency and permission issues.

Question 10. Cindy wants to install a new application that requires the operating system to have 1 gigabyte of working memory to function properly. Which of the following system requirements does Cindy need to check for compatibility?

  • RAM capacity
  • VRAM capacity
  • CPU capacity
  • SSD storage capacity

Working memory refers to RAM (Random Access Memory). The application requires 1GB of RAM, so Cindy must verify available RAM. VRAM is dedicated graphics card memory used for rendering, not general application execution. CPU capacity addresses processing speed, not memory. SSD storage is where the application is installed, not where it runs.
