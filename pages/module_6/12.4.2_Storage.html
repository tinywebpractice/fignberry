12.4.2 Storage

Cloud Storage Overview

Cloud storage allows files and documents to be stored remotely and accessed from any location and device with internet access. Many providers include a file management application for easy access and organization.

  • iCloud (Apple)
  • Google Drive (Google)
  • OneDrive (Microsoft)

Synchronization

  • Selected files and folders on a local device can be configured to sync changes to the cloud automatically.
  • Ensures files are current and accessible from other devices and locations.
  • Sync status is visible in File Explorer (e.g., OneDrive shows a green checkmark icon for fully synced files).
  • Synchronization can be paused or suspended. This is useful on metered connections where bandwidth is limited or data has an increased monetary cost.
