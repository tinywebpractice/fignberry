12.4.3 Collaboration Tools

Cloud-Based Document Collaboration

Cloud application suites allow multiple users to edit and manage the same document simultaneously in real time, regardless of physical location. Changes are tracked per user.

  • Microsoft Office 365: cloud-based Word, Excel, PowerPoint, etc.
  • Google Docs / Google Slides: browser-based real-time document editing

Videoconferencing and Messaging

Tool Features
Microsoft Teams Video/audio calls, instant messaging, reactions
Slack Video/audio calls, instant messaging, reactions
Zoom Video/audio calls

Instant messaging features support quick questions and status updates. Some applications (e.g., Outlook) support emoji reactions to messages such as thumbs up or OK.

Permissions and Hardware Access

Collaboration software installations may require adjusted permissions to function properly:

  • Access to local files for synchronization
  • Access to webcam and microphone for video/audio calls
  • Access to other hardware resources as needed

Web vs. Desktop Application Versions

Some cloud collaboration tools run directly in the browser and offer an option to switch to the locally installed desktop version. The desktop version may include features not available in the web-based version (e.g., Office 365 web portal vs. installed Office apps).
