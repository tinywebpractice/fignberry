12.4.4 User Licensing

License Types

Software licenses define the terms, conditions, and limitations of use. Most applications offer both individual and commercial/business license tiers.

License Type Description
Single-user / single-installation Authorized for one system, one user. Installing on multiple systems or sharing with multiple users is a license violation.
Individual Personal use license with personal-use terms.
Commercial / business Covers organizational use; may include volume or per-seat terms.

Cloud Licensing Considerations

  • Cloud licenses may include terms around ownership of works created by the software, especially relevant when cloud storage is also used to store those works.
  • Always read and understand license terms before use in personal or commercial contexts.
  • Using the wrong license type should be corrected by reassigning the correct license or performing an uninstall and reinstall with the correct license.

Enterprise License Management

Cloud application licenses for employees can be managed centrally through an administrative portal. Example: Microsoft Entra admin center allows administrators to assign, review, and modify license assignments per user across products such as Office 365, Enterprise Mobility + Security, and Azure services.
