12.4.7 Lesson Review

Question 1. What is a key consideration when purchasing a license for a cloud-based application?

  • Cloud-based application licenses do not require users to read the terms and conditions.
  • Cloud-based application licenses may include terms about ownership of works created using the software.
  • Cloud-based application licenses are only available for individual users, not businesses.
  • Cloud-based application licenses allow unlimited installations on multiple devices.

Cloud licenses can differ from traditional licenses specifically around ownership of works produced by the software, which becomes more complex when cloud storage is also used. Terms and conditions must always be read. Cloud apps offer both individual and business license tiers. Installation limits still apply and violating them is a license violation.

Question 2. Your organization uses Microsoft Azure for cloud services and an on-premise Active Directory for local resource management. The IT team wants employees to use the same credentials for both cloud and on-premise resources. Which solution would BEST address this requirement?

  • Disable authentication for cloud resources to simplify access.
  • Create separate user accounts for cloud and on-premise resources to maintain security.
  • Configure identity synchronization between Azure and the on-premise Active Directory.
  • Use a third-party password manager to store and manage multiple credentials for users.

Microsoft Entra Connect syncs on-premises AD identities with Microsoft Entra ID so users authenticate once and access both environments with the same credentials. Disabling authentication removes security. Separate accounts are the problem being solved, not the solution. A password manager still requires multiple credentials.

Question 3. Your organization uses a cloud-based project management application under a business license. A team member stored project files created using the application in a personal cloud storage account. The license includes a clause about ownership of works created using the software. What should you infer about this situation?

  • Ownership of the project files is irrelevant as long as the files are accessible to the team.
  • The cloud storage provider automatically owns the project files once they are uploaded to personal storage.
  • The team member owns the project files because they created them, and storing them in personal cloud storage is acceptable.
  • The organization retains ownership of the project files, and they should not be stored in personal cloud storage.

Under a business license, works created belong to the organization, not the individual employee. Storing those files in personal cloud storage raises ownership and data security/compliance concerns. Ownership terms have legal implications and cannot be dismissed. Uploading to a storage service does not transfer IP ownership to that provider.

Question 4. Which of the following is an example of a cloud-based collaboration tool that allows multiple users to edit documents in real-time?

  • Adobe Photoshop
  • iCloud
  • Microsoft Exchange Server
  • Microsoft Office 365

Office 365 is a cloud-based suite enabling simultaneous real-time multi-user editing of Word, Excel, and PowerPoint documents with per-user change tracking. Adobe Photoshop is a locally installed image editor. iCloud is a storage/sync service, not a document collaboration platform. Microsoft Exchange Server is an on-premises email server.

Question 5. Your company is moving its email system to the cloud to improve accessibility and synchronization across devices. Employees switch between desktops, laptops, and mobile devices and need emails and folders to stay updated in real-time. Which solution would BEST meet these requirements?

  • Configuring Microsoft Outlook as a desktop-only application
  • Using Gmail through Google Workspace
  • Installing Mozilla Thunderbird as the primary email client for all employees
  • Deploying Microsoft Exchange as an on-premise email server

Gmail via Google Workspace is a cloud-based email system that syncs email and folders across all devices in real time, accessible from any browser or device. Desktop-only Outlook, Thunderbird, and on-premises Exchange are all locally bound solutions that do not inherently provide cross-device real-time cloud sync.

Question 6. How does cloud storage improve file accessibility and management compared to local storage?

  • It restricts file access to a single device for enhanced security.
  • It allows files to be accessed and synchronized across multiple devices with internet access.
  • It requires users to manually transfer files between devices for synchronization.
  • It eliminates the need for internet access to retrieve files stored in the cloud.

Cloud storage is accessible from any device with an internet connection and syncs automatically. Single-device restriction and manual file transfer both describe local storage limitations. Internet access is a requirement for cloud storage, not something it eliminates.

Question 7. How does a cloud-based email system differ from an on-premise email server?

  • On-premise email servers are managed entirely by the cloud service provider.
  • Cloud-based email systems require no internet connection to access emails.
  • Cloud-based email systems allow users to access their emails and folders from any device with an internet connection.
  • On-premise email servers automatically synchronize emails across multiple devices without additional configuration.

Cloud email is browser-accessible from anywhere and syncs across devices automatically. On-premises servers are managed by the organization's own IT staff. Internet access is required for cloud services. On-premises solutions like Exchange require additional configuration (e.g., ActiveSync, IMAP) to achieve cross-device sync.

Question 8. A company needs a storage solution that allows employees to access files from multiple devices, ensures files are always up-to-date, and provides an easy way to share files with external collaborators. Which solution BEST meets their needs?

  • A local file server that employees can access only when connected to the company network.
  • An email-based system where employees attach and send files to collaborators.
  • An external hard drive assigned to each employee for storing and sharing files.
  • A cloud storage solution like Microsoft OneDrive or Google Drive that supports synchronization and sharing.

Cloud storage satisfies all three requirements: multi-device access, automatic sync to keep files current, and built-in sharing for external collaborators. A local file server is network-bound. Email attachments create unsynced copies with no version control. External hard drives have no sync or external sharing capability.

Question 9. What is the primary benefit of using identity synchronization in a cloud-based environment?

  • It ensures that users have different permissions for cloud and on-premise systems.
  • It simplifies user sign-in by enabling a single set of credentials for cloud and on-premise resources.
  • It allows users to have multiple sets of credentials for different resources.
  • It eliminates the need for credentials entirely in enterprise environments.

Identity synchronization consolidates credentials so one set grants access to both cloud and on-premises environments, reducing burden on users and simplifying admin management. The goal is consistent permissions across both environments, not different ones. Multiple credential sets is the problem being solved. Authentication is still required; sync consolidates it, not eliminates it.

Question 10. Why are cloud-based collaboration tools beneficial for remote teams working on the same document?

  • They allow users to edit the same document in real-time, regardless of location.
  • They ensure that only one user can access the document at a time to prevent conflicts.
  • They require users to download the document locally before making edits.
  • They automatically delete older versions of the document to save storage space.

Cloud collaboration tools like Google Docs and Office 365 enable simultaneous multi-user editing with changes visible to all in real time. Single-user file locking describes a traditional local-file model, not cloud collaboration. Cloud tools edit documents directly without a separate download step. Most cloud platforms retain version history rather than deleting it.
