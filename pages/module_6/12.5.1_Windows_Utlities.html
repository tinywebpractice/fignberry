12.5.1 Windows Utilities

Starting Utilities

  • Search bar: type a keyword (e.g., "control", "system", "video") to locate the relevant utility.
  • Start menu: browse applications from the Start menu.
  • Right-click Start menu: displays a quick-access list of the most common utilities (Device Manager, System, etc.).

Control Panel

A long-standing repository of system configuration utilities. Viewable in large or small icon modes.

  • Power options
  • Windows Firewall
  • User accounts
  • Fonts
  • Date and time
  • Mouse settings (e.g., swapping primary button for left-handed users)

Settings

The modern replacement for Control Panel. Uses a flat icon style. Acts as a repository for other utilities, organized into categories:

  • System (display, sound, power/sleep, device info)
  • Security
  • User accounts
  • Gaming / applications

System Settings

Found within Settings. Displays hardware and OS information and serves as a jump-off point to other utilities.

  • RAM amount
  • Processor type
  • OS license key information
  • Display, sound, power, and sleep settings

Update Settings

Manages OS updates. Keeping the OS current is critical for security because patches close vulnerabilities that hackers actively exploit.

Environment Recommended Approach
Home / personal Enable automatic updates; optionally enable notifications before install.
Enterprise network Download updates to a local update server, test in a sandbox environment first, then point client computers to pull from the internal server.

Device Settings

Manages peripheral and hardware configuration. Key areas:

  • Bluetooth and other devices: keyboards, mice, USB flash drive behavior on connection.
  • Display settings: manage multiple monitors (resolution, arrangement, size). Multi-monitor setups are common in home and office environments.
  • Sound settings: configure microphone and speaker options per application (e.g., different settings for Zoom vs. general use). Especially important for video conferencing and remote work.

App Settings

Used to view, manage, install, and uninstall applications.

  • View disk space used by each installed application.
  • Uninstall applications no longer needed to reclaim storage.
  • Be cautious about what is installed because compromised websites can trigger background downloads without user awareness.
  • Applications can be reinstalled later if needed after removal.
