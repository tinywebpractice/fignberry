12.5.2 Windows Network Settings

Device Manager

Device Manager is the primary utility for managing and troubleshooting hardware, including network adapters. Modern computers often have multiple network adapters listed (wired, wireless, and virtual machine adapters).

  • Focus on physical (wired) and wireless adapters for real-world connectivity troubleshooting.
  • Visual indicators guide diagnosis:
Indicator Meaning
No icon Device working properly (per the OS)
Yellow exclamation point Driver or configuration issue
Yellow question mark Unknown / unrecognized device
"Device is disabled" Adapter has been manually disabled

Note: "Device is working properly" means the OS sees no hardware fault. It does not confirm a working network connection. A cable or upstream issue can still prevent connectivity.

Adapter Properties - Tabs

Tab Contents
General Device status (working properly, error codes)
Driver Driver version, update, roll back, and uninstall options
Details Advanced device and driver properties
Events Log of device-related system events

Driver Management

Drivers are written by third-party manufacturers and vary in quality. Common driver issues:

  • Incompatibility with specific Windows versions or applications.
  • OS updates can break previously working drivers.
  • New hardware drivers may not work with the current OS version out of the box.

Roll back driver: if a new or updated driver causes problems, use the Driver tab to revert to the previously installed version. Always check the manufacturer's website for version-specific compatibility notes.

Network Connections (Legacy Applet)

Accessed via Start > search "network connections." Lists all network adapters on the system, including disabled ones (e.g., Wi-Fi disabled, Bluetooth disabled).

  • Right-click any adapter and select Properties to view the services and protocols bound to it.
  • TCP/IPv4 must be present and enabled for internet connectivity. If missing, this is the cause of no internet access.
  • Click TCP/IPv4 and select Properties to manually configure IP address, subnet mask, gateway, and DNS settings.

Network Status Applet (Modern)

The newer Settings-based network status applet provides a quick overview of current connectivity, distinguishing between local network connection and internet access (a device can be connected to a network without reaching the internet).

  • Shows connection status to the internet at a glance.
  • Links to Wi-Fi settings, Ethernet settings, and the legacy network connections utility.
  • Useful first stop when troubleshooting connectivity issues.
