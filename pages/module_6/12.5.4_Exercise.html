12.5.4 Exercise: System Settings Hands-On Practice

This is a CompTIA CertMaster Learn exercise covering navigation and configuration of Windows System Settings across three practical scenarios. Exam objectives: A+ Core 2 (220-1202) 1.6 (configure Windows settings) and 1.10 (install applications according to requirements).

Scenario 1: Free Up Disk Space

Goal: Identify storage-heavy files and applications and free up disk space using Storage settings.

  1. Open Settings > System > Storage.
  2. Windows displays a breakdown of disk usage by category (Apps, Temporary files, Documents, etc.).
  3. Click Temporary files to see a list of cleanable items (Downloads, Recycle Bin, Windows Update cleanup, etc.). Check the desired items and select Remove files.
  4. To enable Storage Sense, toggle it on from the Storage page. Configure it to run automatically (e.g., when disk space is low) and set rules for deleting temp files and emptying the Recycle Bin on a schedule.
  5. To uninstall large applications, go to Settings > Apps, sort by size, and uninstall unneeded programs.
Storage Sense
An automated Windows feature that periodically removes temporary files, empties the Recycle Bin, and cleans up locally cached cloud files to reclaim disk space without manual intervention.

Scenario 2: Enable Remote Desktop Access

Goal: Enable Remote Desktop so a colleague can connect to the computer for remote troubleshooting, with appropriate security controls.

  1. Open Settings > System > Remote Desktop.
  2. Toggle Enable Remote Desktop to On. Confirm the prompt.
  3. Click Select users that can remotely access this PC and add only the specific user account(s) that need access. Do not leave access open to all users.
  4. Ensure Network Level Authentication (NLA) is required (enabled by default). NLA requires the connecting user to authenticate before a full remote session is established, reducing attack surface.
  5. Note the PC name shown on the Remote Desktop settings page; the colleague will need this to connect via the Remote Desktop Connection (mstsc) client.
  6. Disable Remote Desktop again after the session if ongoing access is not needed.
Network Level Authentication (NLA)
A security feature requiring users to authenticate before a full RDP session is established, preventing unauthorized access to the login screen and reducing exposure to credential attacks.

Scenario 3: Check for and Install Windows Updates

Goal: Ensure the OS is current with the latest security patches and feature updates.

  1. Open Settings > Windows Update.
  2. Click Check for updates. Windows queries Microsoft's update servers for available patches.
  3. If updates are found, click Download and install. A restart may be required to complete installation.
  4. Review Update history to confirm recently installed patches and identify any failed updates.
  5. Enable Automatic updates to ensure future patches are applied without manual intervention.
  6. On enterprise networks: updates are downloaded to a local update server (e.g., WSUS), tested in a sandbox, then pushed to client machines. They are not pulled directly from Microsoft to avoid untested conflicts.

Reflection

Challenges: Storage cleanup requires judgment about which files are safe to delete. Temporary file categories can include items that look disposable but may be needed. Enabling Remote Desktop requires balancing convenience with security; leaving it enabled indefinitely increases attack surface. Windows Update on a managed network requires coordination with IT policy rather than applying updates immediately.

Professional IT application: These three scenarios represent routine tasks in any IT support role. Disk space management prevents system slowdowns and application failures. Remote Desktop is a primary remote support tool, and configuring it correctly with NLA and scoped user permissions is essential to avoiding unauthorized access. Keeping systems updated is a foundational security control that directly reduces vulnerability exposure.

Importance of regular configuration checks: System settings drift over time. Storage fills, updates are missed, and remote access features may be left enabled unintentionally. Regular review ensures systems remain performant, secure, and compliant with organizational policy. In a professional environment, these checks are often enforced through Group Policy, MDM tools, or automated monitoring rather than manual review.
