12.5.5 Exercise: Hands-On Installation Practice

This is a CompTIA CertMaster Learn exercise covering safe software download, installation, and basic configuration of commonly used applications. Exam objectives: A+ Core 2 (220-1202) 1.6 (configure Windows settings) and 1.10 (install applications according to requirements).

General Installation Principles

  • Always download installers from the application's official website or a verified trusted source.
  • Verify installer integrity when possible (hash or digital signature check).
  • During installation, read each screen carefully and decline optional offers for bundled third-party software unless explicitly needed.
  • Document the trusted source URL and take screenshots of the installation process and configured settings.

Application 1: Web Browser (Google Chrome or Mozilla Firefox)

Item Detail
Trusted source https://www.google.com/chrome or https://www.mozilla.org/firefox
Set as default browser Settings > Default apps (Windows) or prompted during install; select the browser and set as default.
Language preferences Browser Settings > Languages; add or reorder preferred languages.
Bookmark a site Navigate to the site; click the star icon (Chrome) or bookmark icon (Firefox) to save.

Application 2: Productivity Tool (LibreOffice or Microsoft Office Trial)

Item Detail
Trusted source https://www.libreoffice.org or https://www.microsoft.com/microsoft-365
Default save location LibreOffice: Tools > Options > LibreOffice > Paths. Office: File > Options > Save > Default local file location.
Language / spell check LibreOffice: Tools > Options > Language Settings. Office: File > Options > Language.

Application 3: Antivirus Software (Avast Free or AVG Free)

Item Detail
Trusted source https://www.avast.com or https://www.avg.com
Initial system scan After installation, run a full system scan from the dashboard to establish a clean baseline.
Automatic definition updates Settings > Update; enable automatic virus definition updates to ensure protection against the latest threats.
Bundled offers Both free AV installers commonly offer additional tools (VPN, browser extensions). Decline unless needed.

Application 4: Media Player (VLC)

Item Detail
Trusted source https://www.videolan.org/vlc
Set as default player During install, check the option to associate VLC with audio and video file types. Or go to Windows Settings > Default apps and assign VLC for video/audio formats.
Subtitle settings Tools > Preferences > Subtitles/OSD; configure font size, encoding, and default subtitle track behavior.
Audio output Tools > Preferences > Audio; select the output device (e.g., headphones vs. speakers).

Application 5: Communication Tool (Zoom or Microsoft Teams)

Item Detail
Trusted source https://zoom.us/download or https://www.microsoft.com/microsoft-teams
Account setup Log in with an existing account or create a new one through the official portal.
Microphone test Settings > Audio; select the correct input device and use the test feature to confirm the microphone is detected and transmitting.
Camera test Settings > Video; select the correct camera and verify the preview image.
Test meeting Schedule or start a test meeting to confirm audio, video, and screen share functionality end-to-end. Note: permissions may need to be granted for microphone and camera access in Windows Settings > Privacy.

Reflection

Challenges: The most common installation challenge is managing bundled offers. Free software installers frequently include opt-out checkboxes for additional tools, browser extensions, or search engine changes. Missing these during a fast install can result in unwanted software. Additionally, setting default applications requires attention in both the installer itself and in Windows Settings, as installers do not always complete the default app assignment automatically. Communication tools often require explicit Windows permission grants for camera and microphone access that are separate from the application's own settings.

Professional IT application: In a professional environment, these installation and configuration steps map directly to deploying standard software packages for end users. A technician who understands how to configure default save locations, language settings, AV definition update schedules, and communication tool audio/video settings can onboard a new workstation efficiently and consistently. Knowing to decline bundled software and verify installers from trusted sources is a security habit that prevents unnecessary risk on managed systems.
