Exam objective: A+ Core 2 (220-1202) 1.11. Given a scenario, install and configure cloud-based productivity tools.

Applications Compared: Google Drive vs. Microsoft OneDrive

Category Google Drive Microsoft OneDrive
Primary function Cloud storage and file management integrated with Google Workspace (Docs, Sheets, Slides) Cloud storage and file management integrated with Microsoft 365 (Word, Excel, PowerPoint)
Free storage 15 GB shared across Drive, Gmail, and Google Photos 5 GB (personal); 1 TB included with Microsoft 365 subscriptions
Paid tiers Google One: 100 GB ($1.99/mo), 200 GB ($2.99/mo), 2 TB ($9.99/mo); Google Workspace Business from $6/user/mo (includes 30 GB to unlimited) Microsoft 365 Personal: $6.99/mo (1 TB + Office apps); Microsoft 365 Family: $9.99/mo (up to 6 users, 1 TB each); Business plans from $6/user/mo
Real-time collaboration Native real-time co-editing in Google Docs, Sheets, and Slides; no Office app required Real-time co-editing in Office apps (web and desktop); tighter integration with installed Office
Desktop sync Google Drive for Desktop app; selective folder sync; stream or mirror files OneDrive sync client built into Windows; Files On-Demand (cloud placeholder files without full download)
Integrations Google ecosystem (Gmail, Calendar, Meet, Classroom); third-party apps via Google Workspace Marketplace Microsoft ecosystem (Outlook, Teams, SharePoint, Azure AD); third-party apps via Microsoft AppSource
Sharing and permissions Share via link (viewer/commenter/editor) or specific accounts; expiration dates on shared links available Share via link or specific accounts; granular permissions; integration with Azure AD for enterprise access control
Version history 30 days (free); unlimited with some Workspace plans 30 days (personal); longer retention configurable in enterprise plans
Offline access Google Docs/Sheets/Slides available offline via Chrome extension; other files require download Files On-Demand allows selective offline availability; synced files available offline natively
Best for Students, educators, small teams, organizations already in the Google ecosystem, users who prefer browser-based workflows Organizations using Microsoft 365, Windows-heavy environments, enterprises requiring deep Active Directory integration and compliance controls

Recommendation Summary

Scenario: A mid-sized company running Windows workstations with Microsoft 365 licenses already deployed needs a cloud storage solution for its employees.

For this scenario, Microsoft OneDrive is the clear recommendation. Because the organization already holds Microsoft 365 licenses, each user receives 1 TB of OneDrive storage at no additional cost, making it the most economical choice. OneDrive is built directly into Windows and integrates natively with the Office applications employees are already using, minimizing training overhead and configuration complexity. The tight integration with Azure Active Directory enables IT administrators to enforce access policies, configure conditional access, and meet compliance requirements through tools they are already managing. Google Drive would be the stronger choice for an organization without existing Microsoft licensing or one with a preference for browser-first, platform-agnostic workflows.
