12.6 Module Quiz

Question 1. Which of the following options can be configured in the File Explorer Options in Windows?

  • Manage user accounts.
  • Adjust screen resolution.
  • Enable dark mode for File Explorer.
  • Hide extensions for known file types.

File Explorer Options (View tab) controls how files and folders are displayed, including toggling visibility of file extensions for known file types. User accounts are managed in Settings > Accounts. Screen resolution is in Settings > System > Display. Dark mode is a system-wide setting in Settings > Personalization > Colors.

Question 2. A project manager implements a new ticketing system that allows the helpdesk to record knowledge, streamline efficiencies, and automate solutions. Which of the following is the least concern for the support team?

  • Support
  • Licensing
  • Distribution method
  • Training

Distribution method is a procurement/IT concern handled before implementation and is not an ongoing concern for the support team using the system. Support, licensing, and training are all directly relevant to the team operating the ticketing system day to day.

Question 3. Your organization uses a cloud-based project management application under a business license. A team member stored project files in a personal cloud storage account. The license includes a clause about ownership of works created using the software. What should you infer?

  • Ownership of the project files is irrelevant as long as the files are accessible to the team.
  • The cloud storage provider automatically owns the project files once they are uploaded to personal storage.
  • The team member owns the project files because they created them, and storing them in personal cloud storage is acceptable.
  • The organization retains ownership of the project files, and they should not be stored in personal cloud storage.

Works created under a business license belong to the organization, not the individual employee. Storing them in personal cloud storage raises ownership and data security/compliance concerns. Uploading to a storage service does not transfer IP ownership to that provider.

Question 4. How does the Ease of Access settings menu in Windows help users with disabilities?

  • By allowing users to customize accessibility features like screen readers and magnifiers.
  • By offering tools to optimize system performance for faster processing.
  • By providing options to manage system updates and security patches.
  • By enabling users to install third-party accessibility software.

Ease of Access (Accessibility) provides built-in tools for users with visual, auditory, cognitive, or motor impairments: Narrator, Magnifier, high contrast mode, Sticky Keys, and closed captions. Performance optimization is handled elsewhere. System updates are managed in Windows Update. Ease of Access is not a software installation portal.

Question 5. A user is experimenting with the fast startup option to see if it really makes booting faster. What should they expect?

  • Apps will run in safe mode.
  • The computer will boot faster after being shut down.
  • The computer will restart faster.
  • This only applies to computers with SSDs.

Fast Startup saves the kernel session and drivers to a hibernation file (hiberfil.sys) on shutdown, allowing faster boot on next startup. It does not apply to restarts (which perform a full cold boot cycle), is not limited to SSDs, and has no connection to Safe Mode.

Question 6. Which of the following can be adjusted in the Privacy and Security Settings of the Windows operating system?

  • System date and time
  • User account passwords
  • Permissions for apps to access location data
  • Display resolution

Settings > Privacy & Security controls per-app hardware permissions including location, camera, microphone, and diagnostic/usage data collection. Date and time is in Settings > Time & Language. Passwords are managed in Settings > Accounts. Display resolution is in Settings > System > Display.

Question 7. A user's desktop is running slowly with multiple applications open. Investigation reveals the system prioritizes background processes and has visual effects set to best appearance. Which action would BEST address the issue?

  • Disable Windows Defender Firewall to free up system resources.
  • Configure the power options in System Settings to enable sleep mode when the system is idle.
  • Use the Device Manager to disable unused hardware devices.
  • Adjust the performance options in Advanced System Settings to prioritize foreground processes and optimize for best performance.

System Properties > Advanced > Performance Settings addresses both identified causes: processor scheduling can be set to favor foreground programs, and visual effects can be set to "Adjust for best performance." Disabling the firewall is a security risk with negligible performance benefit. Sleep mode affects idle power state, not active load. Disabling devices provides minimal performance gain.

Question 8. Which ACPI power state allows a system to start where it left off but turns all other components off?

  • Off
  • Standby
  • Hibernate
  • Working

Hibernate (ACPI S4) saves the entire RAM contents to disk (hiberfil.sys) and powers off all components. On next boot, Windows restores from the saved file. Off (S5) is a full shutdown with no session saved. Standby/Sleep (S1/S3) keeps RAM powered and requires continuous low power. Working (S0) is the normal fully powered-on state.

Question 9. An organization has inconsistent permissions between Google Cloud and on-premise Active Directory, with employees needing separate credentials for each. The IT team implements identity synchronization. Which outcome would BEST resolve the challenges?

  • Employees will use a single set of credentials, and permissions will be consistently applied across both environments.
  • Permissions will remain inconsistent, but employees will no longer need to authenticate to access resources.
  • Employees will still need separate credentials, but permissions will be synchronized between the environments.
  • Employees will use a single set of credentials, but permissions will need to be manually configured for each environment.

Identity synchronization consolidates credentials into a single set and propagates access control policies consistently across both cloud and on-premises environments. Authentication is never eliminated. The purpose is to unify both credentials and permissions, not just one or the other.

Question 10. Which of the following is a key consideration when deploying new applications in a corporate environment?

  • Ensuring the application is available in multiple languages
  • Ensuring the application has a built-in gaming mode
  • Verifying the application is compatible with all mobile devices
  • Assessing the impact on business operations and network devices

Before deploying any application in a corporate environment, IT must evaluate the impact on existing systems, network bandwidth, device compatibility, security posture, and business continuity. Language availability and mobile compatibility may be secondary concerns; gaming mode is irrelevant. Enterprise deployment practices include sandbox testing to prevent conflicts that could affect the entire network.

Question 11. A user reports incorrect monitor resolution and no sound from external speakers. The monitor does not appear in display settings and the speakers are not listed as an audio output option. What is the MOST likely cause?

  • The devices need to be manually added through the Devices and Printers applet.
  • The drivers for the monitor and speakers need to be updated in Device Manager.
  • The Bluetooth & Devices Settings page needs to be configured for these devices.
  • The devices are not properly connected or detected by the system.

If neither device appears in its respective settings at all, Windows is not detecting them, indicating a physical connection or hardware recognition failure. Driver issues would still show the device in Device Manager with an error indicator. Monitors and speakers are not manually added via Devices and Printers. Bluetooth settings apply to wireless peripherals, not typical wired monitors and speakers.

Question 12. Why is it important to understand the terms and conditions of a cloud-based application license?

  • To ensure compliance with usage limitations and ownership rights.
  • To avoid needing to renew the license in the future.
  • To allow unrestricted sharing of the application with other users.
  • To guarantee the application will work offline without an internet connection.

License terms define permitted use, installation limits, and ownership of works created. Violations carry legal and financial consequences. Reading terms does not exempt anyone from renewal obligations. License terms typically restrict sharing, not enable it. Offline capability is a technical specification, not something determined by the license agreement.

Question 13. A security-conscious user limits what usage data Windows permits to collect and controls what device functions are enabled for which apps. Where does the user accomplish this?

  • Privacy settings
  • VESA
  • User accounts
  • Instant Search

Settings > Privacy & Security controls both diagnostic/telemetry data collection and per-app hardware permissions (camera, microphone, location, etc.). VESA is a hardware standards organization for display interfaces. User Accounts manages passwords and account types. Instant Search is a Windows indexing/search feature.

Question 14. A user wants to quickly switch between multiple open application windows on Windows 10 without using the mouse. Which action should they take?

  • Use the keyboard shortcut Alt + Tab.
  • Press the Windows logo key to open the Start menu.
  • Right-click on the desktop and select "Switch Applications."
  • Open the Control Panel and navigate to "Task Manager."

Alt + Tab cycles through all open windows without mouse input. The Windows key opens the Start menu for launching apps, not switching between open ones. There is no "Switch Applications" option in the desktop right-click menu. Task Manager is not located in Control Panel and requires mouse interaction to switch applications.

Question 15. A company needs to deploy an open-source application across Linux-based systems, but no pre-compiled package is available for their specific Linux distribution. Which action would BEST ensure successful deployment?

  • Install the application without verifying compatibility, as Linux applications are universally compatible across distributions.
  • Compile the application from its source code to ensure compatibility with the specific Linux distribution.
  • Switch all systems to a Linux distribution that supports the pre-compiled package of the application.
  • Install the application using the package manager of a different Linux distribution.

Compiling from source on the target system ensures the binary is built against the correct libraries, kernel version, and architecture. Linux apps are not universally compatible across distros. Switching the entire OS infrastructure for one application is impractical. Package managers from different distros (e.g., RPM on Debian) are generally incompatible without additional tooling.

Question 16. You need to install a new application on multiple desktops from a shared network folder in an automated way that requires no manual intervention on each computer. Which method should you use?

  • Use Group Policy Objects (GPOs) to remotely install the application from the network folder.
  • Use a physical hardware token to authenticate the installation process.
  • Copy the setup file to each desktop manually and run the installation locally.
  • Distribute the setup file on USB drives and install it on each desktop individually.

GPOs enable centralized automated software deployment to all domain-joined machines by pointing to a network share, requiring no manual steps per machine. Hardware tokens are authentication devices, not deployment tools. Manual copying and USB distribution both require physical presence and manual execution at each machine.

Question 17. Which of the following is a key feature of cloud storage solutions?

  • Files stored in the cloud are automatically deleted after 30 days.
  • Cloud storage solutions allow files to be synchronized across multiple devices.
  • Cloud storage solutions do not support file sharing.
  • Files stored in the cloud can only be accessed from the device they were uploaded from.

Cross-device synchronization is the defining feature of cloud storage. Files are retained indefinitely until manually deleted (30 days may apply to trash/version history in some services, not stored files). File sharing is a primary feature of cloud storage platforms. Cloud files are accessible from any device with internet access and valid credentials.

Question 18. You need the latest version of your files accessible from both your home computer and office laptop, and you want to share some files with a colleague for collaboration. Which solution would BEST meet your needs?

  • Use a cloud storage solution like Google Drive or Microsoft OneDrive to synchronize and share files.
  • Store the files locally on your home computer and use remote desktop software to access them from your office laptop.
  • Email the files to yourself and your colleague every time you make an update.
  • Save the files on a USB drive and carry it between your home and office.

Cloud storage satisfies all requirements: automatic sync keeps files current on both devices, and built-in sharing enables collaboration. Remote desktop requires the home computer to always be on and does not provide offline access. Email creates unsynced copies with no version control. USB drives can be lost, cannot be shared remotely, and require physical transport.

Question 19. Why is it important for the IT department to maintain control and oversight of all third-party software installed on network hosts?

  • To ensure that applications are installed with administrator privileges only.
  • To guarantee that all applications are compatible with mobile devices.
  • To ensure that all applications are available for free to employees.
  • To prevent unsanctioned software from introducing operational and business risks.

Unauthorized or unvetted software can introduce malware, security vulnerabilities, software conflicts, licensing violations, and compliance issues. IT oversight ensures only tested and approved software runs on network hosts. Privilege management is a mechanism of control, not the primary reason. Mobile compatibility and cost are not the driving concerns behind IT software governance.

Question 20. What type of update introduces changes to OS features and tools in Windows Update?

  • Patch update
  • Driver update
  • Security update
  • Feature update

Feature updates introduce new OS features, tools, and functionality (e.g., Windows 11 23H2). Patch updates address specific bugs without adding features. Driver updates improve hardware device compatibility. Security updates close specific vulnerabilities and are focused solely on hardening the OS, not adding functionality.
