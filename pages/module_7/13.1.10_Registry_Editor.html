13.1.10 Registry Editor

Overview

The Windows registry is a remotely accessible binary database storing configuration information for the OS, devices, and applications. Use Registry Editor (regedit.msc) to view or edit it. The registry is organized into root keys, subkeys, and value entries, similar to drives, folders, and files.

Five Root Keys

Root Key Abbreviation Contents
HKEY_LOCAL_MACHINE HKLM System-wide settings for the computer, regardless of which user is logged in.
HKEY_USERS HKU Settings for all individual user profiles on the computer (e.g., desktop personalization).
HKEY_CURRENT_USER HKCU Subset of HKU; contains settings for the currently logged-in user only.
HKEY_CLASSES_ROOT HKCR Registered applications, file associations, and OLE object classes; determines which app opens each file type.
HKEY_CURRENT_CONFIG HKCC Current hardware profile used at startup; dynamically built at boot time.

Registry Hives (Storage)

The registry is stored in binary files called hives. Each hive consists of:

File Purpose
Main file (no extension) Primary hive data
.LOG Transaction log for crash recovery
.SAV Setup copy of the hive
.ALT Backup file for the system hive only
  • Most hive files are stored in C:\Windows\System32\Config.
  • Each user profile's hive (NTUSER.DAT) is stored in the user's profile folder (e.g., C:\Users\Username\).

Value Entry Data Types

Data Type Description
REG_SZ Fixed-length string (most common)
REG_EXPAND_SZ Expandable string with environment variable references (e.g., %SystemRoot%)
REG_MULTI_SZ Multi-string value (multiple strings in one entry)
REG_DWORD 32-bit binary/numeric value
REG_QWORD 64-bit binary/numeric value
REG_BINARY Raw binary data

Editing and Exporting

  • Use Edit > Find to search for keys, subkeys, or value entries by name.
  • Right-click a key to create new subkeys or value entries, rename, delete, or export.
  • To copy registry settings to another computer: File > Export Registry File. The exported .reg file can be merged into another registry by double-clicking it or calling it from a script.
  • Always back up the registry (or export the relevant key) before making changes. Incorrect edits can cause system instability or boot failure.
