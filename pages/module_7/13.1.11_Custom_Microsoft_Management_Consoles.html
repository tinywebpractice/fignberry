13.1.11 Custom Microsoft Management Consoles

Overview

A Microsoft Management Console (MMC) is a host container for administrative tools called snap-ins. Rather than opening each tool separately, a custom MMC lets you combine multiple snap-ins into a single saved console. Most snap-ins can manage both local and remote computers on the network.

Run command
mmc opens a blank MMC console to which snap-ins can be added.
Save format
Custom consoles are saved as .msc files, typically in the Administrative Tools folder.

Adding Snap-ins

In a blank MMC: File > Add/Remove Snap-ins. Select from the available snap-ins list and add them to the console root. Some snap-ins prompt for scope configuration (e.g., the Certificates snap-in asks whether it manages certificates for a user account, service account, or computer account).

Available snap-ins include (partial list):

  • ActiveX Control
  • Authorization Manager
  • Certificates (certmgr.msc / certlm.msc)
  • Component Services
  • Computer Management
  • Device Manager (devmgmt.msc)
  • Disk Management
  • Event Viewer
  • Folder
  • Group Policy Object (gpedit.msc)
  • Hyper-V Manager
  • Internet Information Services (IIS)
  • IP Security Monitor
  • Local Users and Groups (lusrmgr.msc)
  • Task Scheduler

Common Standalone .msc Files

File Tool
devmgmt.msc Device Manager
diskmgmt.msc Disk Management
gpedit.msc Local Group Policy Editor
secpol.msc Local Security Policy
