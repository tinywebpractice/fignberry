13.1.1 Device Manager

Overview

Device Manager (devmgmt.msc) is the central utility for viewing and managing installed hardware, device drivers, and device configuration. Device drivers are manufacturer-written software that enable hardware to function with a specific OS.

  • Access methods: Search "device" or "devmgmt.msc" in the Start search bar; or right-click the Start menu and select Device Manager.
  • Displays all hardware categories alphabetically (audio, batteries, cameras ... USB controllers).

Device Status Indicators

Indicator Meaning
No icon Device functioning normally
Yellow exclamation point (!) Driver or configuration error; device identified but driver not found or malfunctioning
Yellow question mark (?) Unknown device; Windows cannot identify device type or find a driver
Down arrow Device is disabled

Device Properties Tabs

Right-click a device and select Properties to access:

Tab Contents / Actions
General Device status message; basic error information
Driver Driver provider, date, version, digital signer; buttons: Driver Details, Update Driver, Roll Back Driver, Disable Device, Uninstall Device
Details Advanced hardware and driver properties
Events Log of device-related system events
Power Management Allow device to wake computer; allow OS to power off device to save power

Updating Drivers

  • Automatic search: Right-click device > Update driver > Search automatically. Windows checks locally and via Windows Update.
  • Manual install: Right-click device > Update driver > Browse my computer. Use when a driver has been downloaded from the manufacturer's website.
  • Manufacturer website: Provide the product make/model and OS version to download the correct driver. Execute the downloaded file to install.
  • Windows Update: Driver updates may appear as optional updates.
  • If a device never worked, verify compatibility of both the device and driver with the installed OS version before updating.

Rolling Back Drivers

If a driver update causes problems, use Roll Back Driver on the Driver tab to revert to the previously installed version. Roll Back Driver is grayed out if no previous driver version is stored.

Removing, Uninstalling, and Disabling Devices

Action Effect When to Use
Physical removal (hot-swap) Device removed; driver remains installed for future reconnection Plug and Play / hot-swappable devices (USB, etc.); use Safely Remove Hardware icon in taskbar for storage devices first
Uninstall Device Driver removed from system; device will be treated as new on next connection Driver is corrupt or conflicting; want a clean reinstall; right-click device > Uninstall device before unplugging
Disable Device Device stays physically installed but is deactivated by the OS; shown with down arrow Device is malfunctioning; restricting user access while awaiting replacement; device is hard to physically remove

Before removing a storage device, always use the Safely Remove Hardware icon in the system tray: close active applications, click the icon, and select the option to stop or eject the device.
