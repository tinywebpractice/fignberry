13.1.2 Disk Management Console

Overview

The Disk Management console summarizes all fixed and removable disks (HDDs, SSDs, optical drives) attached to the system. HDDs and SSDs can be divided into logical partitions, each represented as a volume in the top pane.

Partition
A defined region of an HDD or SSD storage space.
Volume
A logical storage unit for the OS, often mapped 1:1 with a partition. Can also span multiple devices/partitions via RAID.
Drive
In Windows, typically refers to a volume assigned a drive letter; can also mean the physical hardware storage device.

Disk 0 Standard Volumes

Disk 0 (the OS disk) typically contains at least three volumes:

Volume Contents Drive Letter
System Volume Boot files; uses EFI (Extensible Firmware Interface) None assigned
Boot Volume OS files (Windows) C:
Recovery Partition(s) Repair/factory reset tools (WinRE or PC vendor tool) None assigned

Disk Management Tasks

Initializing disks
New unformatted disks must be initialized before use. Choose a partition style: MBR (Master Boot Record) or GPT (GUID Partition Table). Both define how partition information is stored on the disk.
Partitioning
Each disk needs at least one partition. Right-click unpartitioned (unallocated) space and follow the wizard to create a new partition.
Formatting
Writes a file system to a partition so Windows can read/write files. Reformatting an existing partition deletes all data. Options include volume label and allocation unit size.
  • NTFS: standard for Windows volumes and boot/system partitions.
  • FAT32: used for small removable drives; required for the system partition during OS setup.
Repartitioning
Expand existing partitions into adjacent unallocated space, or shrink/remove partitions to free space. System and boot partitions cannot be formatted or deleted.

Sectors and Clusters

Concept Detail
Sector Smallest physical storage unit; traditionally 512 bytes. Advanced Format drives use 4K sectors.
Cluster (allocation unit) File system groups sectors into clusters of 2, 4, or 8 sectors. Smaller clusters = better capacity efficiency. Larger clusters = better I/O performance for large files.
4K Native mode Advanced Format disk uses 4K sectors natively if supported by the OS.
512e mode Advanced Format disk emulates 512-byte sectors for compatibility when native 4K is not supported.

Notes

  • During OS setup: boot partition must be NTFS; system partition must be FAT32.
  • Dynamic disks are deprecated. Software RAID is now handled by Storage Spaces.
