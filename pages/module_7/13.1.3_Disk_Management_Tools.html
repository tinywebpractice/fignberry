13.1.3 Disk Maintenance Tools

Three Main Disk Problems

Problem Description Threshold / Notes
Fragmentation Files become scattered across non-contiguous clusters on an HDD, reducing read performance. HDD-specific; SSDs are not affected in the same way.
Capacity More files created than deleted over time reduces available space. Performance suffers below 20% free space on boot volume; Low Disk Space warning appears below 200 MB.
Damage HDDs: physical damage from power cuts causes file corruption. SSDs: cell degradation causes bad blocks; vulnerable to impacts, overheating, and electrical issues. Regular maintenance helps detect and address damage early.

Run disk maintenance tools at least monthly and before software installations.

Defragment and Optimize Drives

The Defragment and Optimize Drives tool addresses both fragmentation and SSD maintenance. Windows Task Scheduler runs it automatically (default: weekly). Regularly check for unsuccessful scheduled runs.

Drive Type Operation Performed Effect
HDD Defragmentation Reorganizes file data into contiguous clusters; reduces controller seek time when reading files.
SSD TRIM operation Marks OS-deletable data blocks as writable, allowing the drive controller's wear-leveling routines to manage them efficiently.
SSD (OS drive with Volume Shadow Copy) TRIM + possible defragmentation May also perform defragmentation in addition to TRIM when Volume Shadow Copy is enabled on the OS drive.

Disk Clean-up

The Disk Clean-up tool identifies files safe for deletion to reclaim disk space.

  • Identifies: Recycle Bin contents, temporary files, downloaded program files, temporary internet files, and more.
  • Running in administrator mode with the Clean up system files option unlocks additional categories: Windows Update cache, Windows Defender cache, and other system-level temporary data.
  • Shows total disk space recoverable before committing to deletion.
