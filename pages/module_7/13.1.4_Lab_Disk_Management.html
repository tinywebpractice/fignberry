13.1.4 Lab: Disk Management

This is a CompTIA CertMaster Learn exercise. The scenario involves running Disk Cleanup and configuring scheduled defragmentation on a marketing manager's computer to address slow performance caused by disk issues.

Scenario

As IT administrator, run Disk Cleanup on C: to delete thumbnails (but not temporary files), then configure disk defragmentation to run monthly on C: only.

Both tools are accessible via: File Explorer > This PC > right-click Local Disk (C:) > Properties. Disk Cleanup is under the General tab; defragmentation is under the Tools tab.

Task 1: Run Disk Cleanup on C:

  1. From the taskbar, select File Explorer. Maximize the window.
  2. Select This PC.
  3. Right-click Local Disk (C:) and select Properties.
  4. On the General tab, select Disk Cleanup.
  5. Under Files to Delete:
    • Ensure Thumbnails is checked.
    • Uncheck Temporary files. (Note: this is distinct from Temporary Internet Files. Do not confuse the two.)
  6. Select OK, then confirm by selecting Delete Files.

Task 2: Configure Scheduled Defragmentation

  1. In the C: Properties dialog, select the Tools tab.
  2. Under Optimize and defragment drive, select Optimize.
  3. In the Optimize Drives window, select Change settings.
  4. Ensure Run on a schedule is checked.
  5. From the Frequency dropdown, select Monthly.
  6. Select Choose to configure which drives are included in the schedule.
  7. Uncheck Local Disk (D:) and Local Disk (E:). Leave only C: selected.
  8. Select OK to close the drive selection dialog.
  9. Select OK to save the schedule settings.
  10. Select Close to close the Optimize Drives window.

Key Concepts

Thumbnails vs. Temporary files
Thumbnails are cached preview images for files and folders; safe to delete and regenerated as needed. Temporary files are created by applications during operation; deleting them can occasionally cause issues if an application is still using them. These are separate categories in Disk Cleanup.
Scheduled optimization frequency
Windows supports Daily, Weekly, and Monthly schedules for the Optimize Drives tool. Monthly is appropriate for lower-use systems; Weekly is the default. Drives excluded from the schedule (D:, E:) can still be optimized manually.
Drive scope
Limiting scheduled optimization to C: (the OS drive) avoids unnecessary TRIM or defrag cycles on data drives that may not need regular attention, reducing wear on SSDs.
