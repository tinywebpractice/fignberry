13.1.5 Task Scheduler

Overview

Task Scheduler automates commands, scripts, and applications on a one-time or recurring basis. Many built-in Windows processes (e.g., Disk Optimizer, Windows Update) use predefined Task Scheduler entries. Tasks can run simple applications with switches, batch files, or scripts.

Key Features

Triggers
Tasks can be triggered by calendar date/time or by system events such as user sign-in, machine waking from sleep, or other Windows events.
Multiple Actions
Each task can chain multiple actions, enabling complex automation sequences.
Logging
All task activity is logged in the History tab, allowing investigation of failures and unsuccessful runs.
Organization
Tasks are stored in the Task Scheduler Library and can be organized into folders (e.g., Microsoft, Intel, Mozilla) for easier management.

Task Configuration Requirements

  • File/script path: the executable, batch file, or script to run.
  • Trigger: when or what event causes the task to run.
  • Credentials: the user account under which the task runs. If the account lacks sufficient permissions, the task will not execute. Options include "Run only when user is logged on" or "Run whether user is logged on or not." The "Run with highest privileges" option elevates the task to administrator level.

Task Scheduler Interface

Panel / Tab Contents
Left pane (Task Scheduler Library) Folder hierarchy of all scheduled tasks
Center pane (task list) Name, status, and trigger summary for each task in the selected folder
Lower pane (General tab) Task name, location, author, description, and security options
Triggers tab All configured triggers for the selected task
Actions tab Commands/scripts the task executes
Conditions tab Power, network, and idle conditions required for the task to run
Settings tab Behavior on failure, stop conditions, and execution time limits
History tab Log of past task runs and outcomes (may need to be enabled)
Right pane (Actions) Create Basic Task, Create Task, Import Task, Run, End, Disable, Export, Delete
