13.1.6 Local Users and Groups Console

Overview

The Local Users and Groups console (lusrmgr.msc) provides an advanced interface for managing local user accounts and security groups. Actions include creating, modifying, disabling, deleting accounts, and resetting passwords.

Security groups allow user accounts with similar permissions to be managed collectively. Default groups define the account types available through the Settings interface.

Default Security Groups

Group Description
Administrators Complete and unrestricted access to the computer. Members can perform all administrative tasks.
Users Standard user access; cannot make system-wide changes.
Guests Same access as Users by default; intended for temporary or limited access.
Backup Operators Can override security restrictions for backup and restore purposes.
Cryptographic Operators Authorized to perform cryptographic operations.
Device Owners Can change system-wide settings.
Event Log Readers Can read event logs from the local machine.
Access Control Assistance Operators Can remotely query authorization attributes and permissions.
Distributed COM Users Can launch, activate, and use Distributed COM objects.

PowerShell - Managing Users and Groups

PowerShell can perform the same tasks as the console, useful for scripting bulk user creation and group assignments.

Task Command
Create a new user account net user UserName Password /add
Force password change at next logon net user UserName Password /logonpasswordchg:yes
Add user to a local group net localgroup GroupName UserName /add
net user
Command for managing local user accounts. Switches include /add (create account) and /logonpasswordchg:yes (force password change at next logon).
net localgroup
Command for managing local group membership. The /add switch adds a specified user to a specified group (e.g., Administrators, Backup Operators).
