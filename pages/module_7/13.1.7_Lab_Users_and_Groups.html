13.1.7 Lab: Users and Groups

This is a CompTIA CertMaster Learn exercise. The scenario involves creating three local user accounts and assigning each to the appropriate security group based on their job responsibilities.

Scenario

Three employees need accounts on a support office computer. All users are automatically placed in the Users group upon account creation.

User Required Access Group(s) Password Force Change
Sylvia Perform all actions on the computer (full admin) Users, Administrators 0Clever1 Yes
Scott Back up and restore files; no other elevated rights Users, Backup Operators 0Clever1 Yes
Jed Normal access (start computer, run apps, save files) Users (no additional group) 0Clever1 Yes

Task 1: Create User Accounts

  1. Right-click Start and select Computer Management. Maximize the window.
  2. Expand Local Users and Groups.
  3. Right-click Users and select New User.
  4. Enter the username in the User Name field.
  5. Enter 0Clever1 in the Password field (0 is a zero).
  6. Re-enter 0Clever1 in the Confirm password field.
  7. Ensure User must change password at next logon is checked.
  8. Select Create.
  9. Repeat steps 3 through 8 to create accounts for all three users.
  10. Select Close when done.

Task 2: Add Users to Groups

  1. In the left pane of Computer Management, select Groups under Local Users and Groups.
  2. In the center pane, right-click the target group and select Add to Group.
  3. Select Add.
  4. Under Enter the object names to select, type the username, then select OK.
  5. Select OK to confirm.
  6. Repeat for each additional group assignment:
    • Add Sylvia to Administrators.
    • Add Scott to Backup Operators.
    • Jed requires no additional group assignment; Users membership is sufficient.

Key Concepts

Administrators group
Grants complete and unrestricted access to the local computer. Appropriate for users who need to install software, manage other accounts, and change system-wide settings.
Backup Operators group
Allows members to back up and restore files regardless of file permissions, without granting full administrative rights. Ideal for users with backup responsibilities only.
Users group
Default group for all new accounts. Provides standard access: log on, run applications, and save files. Cannot make system-wide changes.
User must change password at next logon
Forces the user to set their own password on first login, ensuring the administrator-assigned initial password is not retained.
