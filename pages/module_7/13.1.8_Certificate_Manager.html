13.1.8 Certificate Manager

Overview

A digital certificate verifies the identity of a user, computer, or service. Its validity is guaranteed by the issuing certification authority (CA). The Certificate Manager console displays installed certificates and allows requesting, importing, and removing them.

Console Scope
certmgr.msc Certificates for the current user account
certlm.msc Certificates for the local computer

Key Certificate Store Folders

Personal
Certificates issued to the current user account. Used for network authentication, data encryption, and digital signatures.
Trusted Root Certification Authorities
Certificates from all trusted issuers: Microsoft's CA root, local enterprise CAs, and third-party CAs. Mostly managed automatically via Windows Update. Each entry lists: Issued To, Issued By, and Expiration Date.
Third-Party Root Certification Authorities
Trusted issuers from non-Microsoft or non-local-enterprise providers.
Intermediate Certification Authorities
CAs that sit between the root CA and end-entity certificates in a certificate chain.
Trusted People
Certificates from individuals or organizations explicitly trusted by the user.
Untrusted Certificates
Certificates that have been explicitly revoked or flagged as untrusted.

Security Considerations

  • Trusting an unsafe CA creates critical security vulnerabilities. A rogue CA certificate could allow a malicious website to impersonate a legitimate service (e.g., a bank), and the browser would display it as trusted. This can trick users into submitting credentials.
  • Use Certificate Manager to identify and remove compromised or untrusted CA certificates when necessary.
  • Third-party browsers (e.g., Firefox) often maintain their own separate certificate store for personal certificates and trusted root CAs, independent of the Windows certificate store.
