13.2.1 Command Prompt

Overview

The command prompt processes legacy commands from early Windows versions. Any single command can be run from the Run dialog, but a command shell is preferred for running a series of commands or viewing output. Legacy commands also run at a modern Windows PowerShell prompt. In Windows 11, the command interface is redesigned as Windows Terminal.

Administrative Command Prompt

Some commands require elevated privileges. If elevation is needed, the error message displayed is: "The requested operation requires elevation."

Two methods to launch an elevated Command Prompt:

  • Right-click the Command Prompt shortcut, select Run as administrator, and confirm the UAC prompt.
  • Type cmd in the Instant Search box and press CTRL+SHIFT+ENTER.

When elevated, the title bar shows Administrator: Command Prompt and the default directory is C:\Windows\System32 rather than C:\Users\Username. This method can also open other utilities (e.g., Explorer, Notepad) with administrative privileges.

Command Syntax

Enter commands at the prompt (>) using the command name, switches, and arguments in proper order, then press ENTER to execute.

  • Switches are usually preceded by a forward slash (e.g., /all).
  • Arguments that include spaces must be enclosed in quotes.
  • Use cls to clear the screen.

Some commands (e.g., nslookup, telnet) operate in interactive mode: launching the command opens a sub-program that only accepts inputs relevant to that program. To exit interactive mode, use exit or quit, or press CTRL+C. Using exit outside of interactive mode closes the Command Prompt window entirely.

Getting Help

Command Result
help Lists all available commands
help <command> Shows syntax and switches for a specific command
<command> /? Displays command-specific help (e.g., netstat /?)
