13.2.3 File Management Commands

Moving and Copying Files

The move and copy commands transfer files using a three-part syntax:

command Source Destination

Source specifies the drive, path, and filename to move or copy. Destination specifies the target drive and path.

Copying Directory Structures: robocopy

robocopy ("robust copy") is the preferred file copy utility over xcopy. Microsoft recommends it for better handling of long file names and NTFS attributes. Use the /mov switch to move files instead of copying.

Switch Function
/xf Exclude files matching specified names or paths
/xd Exclude directories matching specified names or paths
/S Copy subdirectories, excluding empty ones
/E Copy all subdirectories, including empty ones
/L List files/directories that would be copied without actually copying
/mov Move files (delete from source after copying)

Creating a Directory: md / mkdir

Use md or mkdir to create a new directory.

  • md Data creates a directory named Data in the current directory.
  • md A:\Data\Docs creates Docs inside Data on the A drive, regardless of the current drive.

Reserved characters that cannot be used in folder or file names: \ / : * ? " < > |

Removing a Directory: rd / rmdir

Use rd Directory or rmdir Directory to delete a directory.

Switch Function
/s Remove directory even if it contains files or subdirectories
/q Quiet mode; suppress confirmation prompts
