13.2.5 Disk Management Commands

diskpart

diskpart is the command-line interface for the Disk Management tool. Unlike the GUI snap-in, it allows destructive actions such as deleting system or boot volumes; use with caution.

Basic workflow for inspecting disks and partitions:

  1. Run diskpart, then type select disk 0 (or the desired disk number).
  2. Enter detail disk to view disk configuration. Healthy partitions should be listed; if none appear, the partition table may be corrupted.
  3. Type select partition 0 or select volume 0 (or the desired number).
  4. Use detail partition or detail volume for more info. Available follow-up commands include assign (change drive letter), delete (remove the volume), and extend.
  5. Type exit to quit diskpart.

format

The format command creates a new file system on a drive, deleting all existing file references. Basic syntax:

format X: /fs:SYS (where X is the drive letter and SYS is the file system: NTFS, FAT32, or EXFAT)

By default, format scans for bad sectors. Use /q to skip that scan (quick format).

Format type Behavior
Standard / Quick Removes file references in the volume boot record; does not erase actual data. Recovery is possible with third-party tools.
Secure format Overwrites each sector with zeros (often multiple passes); prevents data recovery.

chkdsk

chkdsk scans the file system and disk sectors for faults and attempts to repair detected problems. The variant autochk runs automatically at boot when file system errors are detected.

Command Behavior
chkdsk X: Read-only mode; reports errors without making changes
chkdsk X: /f Attempts to fix file system errors
chkdsk X: /r Fixes file system errors and attempts to recover bad sectors; saves recoverable data as filennnn.chk in the root directory
  • chkdsk cannot fix open files; a scan may need to be scheduled for the next system restart.
  • /f and /r scans can take a long time; do not cancel mid-scan.
  • Run a read-only scan first to assess the situation before committing to a repair scan.
